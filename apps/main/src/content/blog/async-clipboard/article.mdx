# Clipboard APIでテキストや画像をコピー・ペーストする

<BrowserSupportStatus featureId="async-clipboard"></BrowserSupportStatus>

## はじめに

Clipboard APIは、`navigator.clipboard`からクリップボードを読み書きするJavaScriptのAPIです。テキストは`writeText()`と`readText()`で、画像は`ClipboardItem`に包んで`write()`と`read()`でコピーと貼り付けをします。画像で、どのブラウザでも書き込めるのはPNGだけです。Firefox 127が対応して、Baseline 2024に入りました。

ユーザーがキーボードやメニューでコピーや貼り付けをしたときの中身は、`copy`と`paste`イベントの`clipboardData`で差し替えられます。ボタンを押したときのコピーや、ボタンからのクリップボードの読み取りのように、ユーザーのコピー操作を待たない読み書きはClipboard APIで書きます。ボタンからのコピーには以前`document.execCommand('copy')`を使っていましたが、非推奨です。読み取りの`document.execCommand('paste')`は、`false`を返して何も貼り付けません。

## Clipboard API

`navigator.clipboard`は、次の4つのメソッドを持ちます。どれも非同期で、`Promise`を返します。

- `readText()`：クリップボードのテキストを読む
- `writeText()`：クリップボードにテキストを書き込む
- `read()`：クリップボードの中身を`ClipboardItem`の配列で読む
- `write()`：`ClipboardItem`の配列をクリップボードに書き込む

テキストは、`readText()`と`writeText()`で読み書きします。画像のようなテキスト以外の中身は、後で説明する`ClipboardItem`を通して`read()`と`write()`で扱います。

```js
// クリップボードのテキストを読む
const text = await navigator.clipboard.readText();

// クリップボードにテキストを書き込む
await navigator.clipboard.writeText('Hello, world!');
```

### 権限

クリップボードにはほかのアプリでコピーした中身も入るので、読み取りには制限があります。Chromeは、初めて読み取るときにユーザーに許可を求めます。SafariとFirefoxでは、ユーザーの操作を挟まずに`readText()`を呼ぶと、`NotAllowedError`で拒否されます。読み取りは、ボタンを押したときのようなユーザーの操作の中で呼びます。

### テキストのコピーと貼り付け

ボタンから`writeText()`と`readText()`を呼ぶデモです。

```html demo="text" allow="clipboard-read clipboard-write"
<label>
  テキスト
  <input id="text" type="text" />
</label>
<button id="copy" type="button">クリップボードにコピー</button>
<button id="paste" type="button">クリップボードからペースト</button>
```

```js demo="text"
const input = document.querySelector('#text');

document.querySelector('#copy').addEventListener('click', async () => {
  await navigator.clipboard.writeText(input.value);
});

document.querySelector('#paste').addEventListener('click', async () => {
  input.value += await navigator.clipboard.readText();
});
```

```css demo="text"
label {
  display: block;
  margin-block-end: 0.5rem;
}
```

入力欄に文字を入れてコピーのボタンを押すと、その文字がクリップボードに入ります。ペーストのボタンを押すと、クリップボードのテキストが入力欄の末尾に足されます。

## ClipboardItem

`ClipboardItem`は、クリップボードの中身1つ分を、MIMEタイプごとのデータで表すオブジェクトです。`read()`は読み取った中身を`ClipboardItem`の配列で返し、`write()`は渡した`ClipboardItem`の配列をクリップボードに書き込みます。

コンストラクタには、MIMEタイプをキーに、データを値にしたオブジェクトを渡します。値には、文字列か`Blob`、またはそれらで解決する`Promise`を渡せます。

```js
const item = new ClipboardItem({
  'text/plain': 'Hello, world!',
  'text/html': '<b>Hello, world!</b>',
});
await navigator.clipboard.write([item]);
```

`ClipboardItem`の`types`は、持っているMIMEタイプの配列です。`getType()`は、渡したMIMEタイプのデータを`Blob`で返す`Promise`を返し、持っていないMIMEタイプを渡すと`NotFoundError`で拒否されます。

```js
console.log(item.types); // ['text/plain', 'text/html']

const blob = await item.getType('text/html');
console.log(await blob.text()); // <b>Hello, world!</b>

await item.getType('image/png'); // NotFoundError
```

`read()`で読んだ中身も、同じように`types`と`getType()`で取り出します。

```js
const items = await navigator.clipboard.read();
for (const item of items) {
  for (const type of item.types) {
    const blob = await item.getType(type);
    console.log(type, blob);
  }
}
```

### ClipboardItem.supports()

<BrowserSupportStatus featureId="clipboard-supports"></BrowserSupportStatus>

`ClipboardItem.supports()`は、渡したMIMEタイプのデータをクリップボードに書き込めるかを、`true`か`false`で返す静的メソッドです。Safari 18.4が対応して、Baseline 2025に入りました。

`text/plain`と`text/html`、`image/png`は、どのブラウザでも`true`です。`text/uri-list`と`image/svg+xml`、`web `で始まる独自のMIMEタイプは、ブラウザによって結果が違います。

```js
// [!og]
ClipboardItem.supports('text/plain'); // true
ClipboardItem.supports('text/html'); // true
ClipboardItem.supports('image/png'); // true

ClipboardItem.supports('text/uri-list'); // true or false
ClipboardItem.supports('image/svg+xml'); // true or false
ClipboardItem.supports('web image/png'); // true or false

ClipboardItem.supports('application/json'); // false
```

結果が分かれる3つは、Chromeでは`image/svg+xml`と`web `で始まるタイプが`true`、`text/uri-list`が`false`です。Safariでは`text/uri-list`だけが`true`で、Firefoxでは3つとも`false`です。

画像のMIMEタイプで、どのブラウザでも`true`になるのは`image/png`だけです。JPEGやWebPの画像は、次の節のようにcanvasでPNGにしてから書き込みます。

### PNG画像のコピーと貼り付け

選んだ画像をPNGでクリップボードにコピーし、クリップボードのPNG画像を貼り付けるデモです。

```html demo="image" allow="clipboard-read clipboard-write"
<div class="columns">
  <div class="column">
    <label>
      画像を選択する
      <select id="picker">
        <option value="/demos/async-clipboard/mint.png">画像1</option>
        <option value="/demos/async-clipboard/coral.png">画像2</option>
      </select>
    </label>
    <!-- canvas から読み出せるよう、CORS で読む -->
    <img
      id="source"
      src="/demos/async-clipboard/mint.png"
      alt="コピーする画像"
      width="100"
      height="100"
      crossorigin="anonymous"
    />
    <button id="copy" type="button">PNG画像をコピーする</button>
  </div>
  <div class="column">
    <p>ペーストされた画像</p>
    <img id="pasted" alt="ペーストされた画像" width="100" height="100" hidden />
    <button id="paste" type="button">保存されたPNG画像を表示する</button>
  </div>
</div>
<p><output id="status"></output></p>
```

```js demo="image"
const source = document.querySelector('#source');
const pasted = document.querySelector('#pasted');
const status = document.querySelector('#status');

document.querySelector('#picker').addEventListener('change', (event) => {
  source.src = event.target.value;
});

const copyImage = async () => {
  const canvas = document.createElement('canvas');
  canvas.width = source.naturalWidth;
  canvas.height = source.naturalHeight;
  canvas.getContext('2d').drawImage(source, 0, 0);
  const blob = await new Promise((resolve, reject) => {
    canvas.toBlob((created) => {
      if (created === null) {
        reject(new Error('Blobが取得できませんでした'));
        return;
      }
      resolve(created);
    });
  });
  await navigator.clipboard.write([new ClipboardItem({ 'image/png': blob })]);
};

// クリップボードにPNG画像があれば表示して true を返す
const pasteImage = async () => {
  const items = await navigator.clipboard.read();
  for (const item of items) {
    if (!item.types.includes('image/png')) continue;
    pasted.src = URL.createObjectURL(await item.getType('image/png'));
    pasted.hidden = false;
    return true;
  }
  return false;
};

document.querySelector('#copy').addEventListener('click', async () => {
  try {
    await copyImage();
    status.textContent = 'クリップボードにPNG画像をコピーしました';
  } catch {
    status.textContent = 'クリップボードにPNG画像をコピーできませんでした';
  }
});

document.querySelector('#paste').addEventListener('click', async () => {
  try {
    status.textContent = (await pasteImage())
      ? 'クリップボードのPNG画像を貼り付けました'
      : 'PNG画像が見つかりませんでした';
  } catch {
    status.textContent = 'クリップボードからPNG画像を読み取れませんでした';
  }
});
```

画像を選んでコピーのボタンを押すと、その画像がPNGとしてクリップボードに入ります。表示のボタンを押すと、クリップボードにあるPNG画像がペーストされた画像の欄に出ます。

コピーする`copyImage`は、画像をcanvasに描き、`toBlob()`でPNGの`Blob`にしてから書き込みます。貼り付ける`pasteImage`は、`read()`で読んだ中身から`image/png`のデータを探して表示します。

```ts
const copyImage = async () => {
  const img = document.getElementById('source') as HTMLImageElement | null;
  if (!img) return;
  const canvas = document.createElement('canvas');
  canvas.width = img.naturalWidth;
  canvas.height = img.naturalHeight;
  const ctx = canvas.getContext('2d');
  if (!ctx) return;
  ctx.drawImage(img, 0, 0);
  const blob = await new Promise<Blob>((resolve, reject) => {
    canvas.toBlob((blob) => {
      if (!blob) {
        reject(new Error('Blobが取得できませんでした'));
        return;
      }
      resolve(blob);
    });
  });
  const file = new File([blob], 'image.png', { type: 'image/png' });
  const data = [new ClipboardItem({ 'image/png': file })];
  await navigator.clipboard.write(data);
};

const pasteImage = async () => {
  const img = document.getElementById('pasted') as HTMLImageElement | null;
  if (!img) return;
  const items = await navigator.clipboard.read();
  for (const item of items) {
    for (const type of item.types) {
      if (type === 'image/png') {
        const blob = await item.getType(type);
        const url = URL.createObjectURL(blob);
        img.src = url;
      }
    }
  }
};
```

幅と高さが0のcanvasでは、`toBlob()`のコールバックに`null`が渡ります。このときコールバックの中で`throw`すると、Promiseは拒否されずに待ち続け、エラーは`window`の`error`イベントに出ます。そのため、コールバックの中では`reject`を呼びます。

## おわりに

Clipboard APIを使うと、ボタンを押したときのようなユーザーの操作から、クリップボードを読み書きできます。テキストは`writeText()`と`readText()`で、画像は`ClipboardItem`に包んで`write()`と`read()`で扱い、書き込めるMIMEタイプは`ClipboardItem.supports()`で確かめられます。
