# URLPatternでURLのパスからパラメータを取り出す

<BrowserSupportStatus featureId="urlpattern" />

## はじめに

URLPattern APIは、`/blog/:id`のようなパターンでURLを照合し、`:id`に当たる部分を取り出せるAPIです。Safari 26が対応して、Baseline 2025に入りました。

パスが決まった文字列と同じかは、`url.pathname === "/blog"`や`startsWith()`で調べられます。`/blog/`の後ろの記事名を取り出したり、数字だけのIDに絞ったりするには、これまで正規表現を書いていました。URLPatternなら名前を付けたパラメータで書け、ホスト名やクエリも部品ごとに照合できます。

```js
const pattern = new URLPattern({ pathname: "/blog/:slug" });

console.log(pattern.exec("https://k8o.me/blog/urlpattern").pathname.groups);
console.log(pattern.test("https://k8o.me/talks"));
```

コンソールに貼ると、`slug`が`"urlpattern"`のオブジェクトと、`false`が出ます。`exec`は一致した部分を部品ごとに返し、`test`は一致したかどうかだけを返します。

## パターンを作る

パターンは、`URLPattern`のコンストラクタで作ります。

```ts
const pattern = new URLPattern(
  input,
  baseURL,
  options,
)
```

`input`は必須で、`baseURL`と`options`は省けます。`baseURL`だけを省いて、`input`と`options`を渡すこともできます。

```ts
// これはもちろんOK
new URLPattern(
  input,
)

// baseURLだけを省略可能
new URLPattern(
  input,
  options,
)
```

第1引数の`input`には、URLのパターンを文字列かオブジェクトで渡します。

```ts
const pattern1 = new URLPattern("https://k8o.me/blog/:id");
```

オブジェクトでは、`hostname`や`pathname`のようなURLの部品ごとのプロパティと、`baseURL`にパターンを書きます。

```ts
// [!og]
const pattern2 = new URLPattern({
  protocol: "https",
  hostname: "k8o.me",
  pathname: "/blog/:id",
});

const pattern3 = new URLPattern({
  pathname: "/blog/:id",
  baseURL: "https://k8o.me",
});
```

`pattern1`と`pattern3`は同じ意味になります。`pattern2`だけは`port`が`*`になるので、`https://k8o.me:8080/blog/a`のようにポート番号の付いたURLにも一致します。

書かなかったプロパティは`*`、つまりワイルドカードになります。ただし`baseURL`を書いたときは、書いたプロパティより前の部品を`baseURL`の値で埋めます。部品の順は、`protocol`、`hostname`、`port`、`pathname`、`search`、`hash`です。`baseURL`だけを渡せば、どの部品も`baseURL`の値になります。`https://k8o.me`なら`port`と`search`、`hash`が`''`に、`pathname`が`/`になります。`username`と`password`は`baseURL`から埋めず、`*`のままです。

```ts
// 同じ
const pattern1 = new URLPattern({
  protocol: "https",
  hostname: "k8o.me",
  pathname: "/blog/:id",
});
const pattern2 = new URLPattern({
  protocol: "https",
  username: "*",
  password: "*",
  hostname: "k8o.me",
  port: "*",
  pathname: "/blog/:id",
  search: "*",
  hash: "*",
});

// 同じ
const pattern3 = new URLPattern({
  baseURL: "https://k8o.me",
});
const pattern4 = new URLPattern({
  protocol: "https",
  username: "*",
  password: "*",
  hostname: "k8o.me",
  port: "",
  pathname: "/",
  search: "",
  hash: "",
});
```

第2引数の`baseURL`には、相対URLの基準になるURLを文字列で渡します。

```ts
// pattern1とpattern2は同じ意味になる
const pattern1 = new URLPattern("https://k8o.me/blog/:id");
const pattern2 = new URLPattern("/blog/:id", "https://k8o.me");
```

第3引数の`options`に渡せるのは、今は`ignoreCase`だけです。既定の`false`では大文字と小文字を区別し、`true`にすると区別しません。

```ts
const pattern = new URLPattern("/blog/:id", "https://k8o.me", { ignoreCase: true });
console.log(pattern.test("https://k8o.me/BLOG/urlpattern")); // ChromeとSafariはtrue、Firefoxはfalse
```

Firefoxでは、`:id`や`*`を含むパターンに`ignoreCase: true`を渡しても、大文字小文字を区別します。区別しなくなるのは、`/blog`のように固定の文字列だけのパターンのときです。

## execで照合する

`exec`は、渡したURLがパターンに一致するかを見て、一致したときは部品ごとの情報を返します。一致しなければ`null`です。

```ts
const pattern = new URLPattern("https://k8o.me/blog/:id");
const result = pattern.exec("https://k8o.me/blog/urlpattern?query=abc#section1");

// 一致しない場合はnullが返る
if (result) {
  console.log(result.inputs);  // ["https://k8o.me/blog/urlpattern?query=abc#section1"]
  console.log(result.pathname); // { input: "/blog/urlpattern", groups: { id: "urlpattern" } }
  console.log(result.search);   // { input: "query=abc", groups: { 0: "query=abc" } }
  console.log(result.hash);     // { input: "section1", groups: { 0: "section1" } }
  console.log(result.username); // { input: "", groups: { 0: "" } }
} else {
  console.log("パターンに一致しませんでした");
}
```

部品ごとのオブジェクトの`input`には一致した文字列が、`groups`には取り出した値が入ります。パターンが`*`の部品では、`*`に当たった文字列が`0`という名前で`groups`に入ります。戻り値には部品のほかに`inputs`もあり、渡した引数が配列で入ります。

`exec`の引数には、コンストラクタと同じく`input`と`baseURL`を渡せます。照合するURLを渡すので、`input`にオブジェクトを渡したときは、書かなかった部品は`''`として扱われます。

`groups`の値は、パスに日本語を含むURLでもパーセントエンコードされたまま入ります。`/blog/あ`なら`id`は`%E3%81%82`になるので、元の文字に戻すには`decodeURIComponent()`を通します。`:id`は`/`をまたがないので、`/blog/urlpattern/`のように末尾にスラッシュの付いたURLには一致しません。末尾のスラッシュを許すなら、`/blog/:id{/}?`と書きます。どのブラウザとNode.jsでも同じです。

パターンを並べて順に`exec`を呼べば、URLを振り分けるルーティングを正規表現なしで書けます。`:id(\d+)`のように、パラメータの後ろの括弧に正規表現を書けば、当てはまる文字を絞れます。

```ts
const routes = [
  { name: "blog", pattern: new URLPattern({ pathname: "/blog/:slug" }) },
  { name: "tag", pattern: new URLPattern({ pathname: "/tags/:id(\\d+)" }) },
  { name: "talks", pattern: new URLPattern({ pathname: "/talks{/}?" }) },
];

const matchRoute = (url: string) => {
  for (const { name, pattern } of routes) {
    const result = pattern.exec(url);
    if (result) return { name, params: result.pathname.groups };
  }
  return null;
};

console.log(matchRoute("https://k8o.me/blog/urlpattern")); // { name: "blog", params: { slug: "urlpattern" } }
console.log(matchRoute("https://k8o.me/tags/12"));         // { name: "tag", params: { id: "12" } }
console.log(matchRoute("https://k8o.me/tags/css"));        // null
console.log(matchRoute("https://k8o.me/talks/"));          // { name: "talks", params: {} }
```

## testで一致するかを見る

`test`は、渡したURLがパターンに一致するかを真偽値で返します。引数は`exec`と同じです。

```ts
const pattern = new URLPattern("/blog/:id", "https://k8o.me");
console.log(pattern.test("https://k8o.me/blog/urlpattern?query=abc#section1")); // true
console.log(pattern.test("https://k8o.me/blog")); // false
```

## 部品ごとのパターンを読む

`URLPattern`のオブジェクトは、部品ごとのパターンをプロパティに持ちます。どの部品にどのパターンが入ったかを、ここから読めます。

```ts
const pattern1 = new URLPattern("https://k8o.me");
console.log(pattern1.protocol); // "https"
console.log(pattern1.username); // "*"
console.log(pattern1.password); // "*"
console.log(pattern1.hostname); // "k8o.me"
console.log(pattern1.port);     // ""
console.log(pattern1.pathname); // "*"
console.log(pattern1.search);   // "*"
console.log(pattern1.hash);     // "*"

const pattern2 = new URLPattern({
  baseURL: "https://k8o.me",
});
console.log(pattern2.protocol); // "https"
console.log(pattern2.username); // "*"
console.log(pattern2.password); // "*"
console.log(pattern2.hostname); // "k8o.me"
console.log(pattern2.port);     // ""
console.log(pattern2.pathname); // "/"
console.log(pattern2.search);   // ""
console.log(pattern2.hash);     // ""

const pattern3 = new URLPattern({
  baseURL: "https://k8o.me",
  protocol: "https",
  hostname: "k8o.me",
});
console.log(pattern3.protocol); // "https"
console.log(pattern3.username); // "*"
console.log(pattern3.password); // "*"
console.log(pattern3.hostname); // "k8o.me"
console.log(pattern3.port);     // "*"
console.log(pattern3.pathname); // "*"
console.log(pattern3.search);   // "*"
console.log(pattern3.hash);     // "*"
```

第1引数の渡し方による違いも、このプロパティで確かめられます。文字列で`https://k8o.me`のようにホスト名まで書くと`port`が`''`になり、オブジェクトで`port`を省くと`*`になります。

## おわりに

URLPatternを使うと、正規表現で書いてきたURLの照合とルーティングを、`/blog/:id`のようなパターンで書けます。取り出した値はパーセントエンコードされたままで、Firefoxでは`ignoreCase`がパラメータを含むパターンに効かないことに気をつけます。
