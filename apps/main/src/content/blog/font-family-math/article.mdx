# font-family: mathで数式用のフォントを指定する

<BrowserSupportStatus featureId="font-family-math"></BrowserSupportStatus>

## はじめに

`font-family: math`は、数式の描画に向いたフォントをブラウザに選ばせる一般フォントファミリーです。MathMLの`<math>`要素には既定でこれが当たり、OSに入っている数式用フォントで分数や添字が組まれます。Firefox 149が対応して、Baseline 2026に入りました。

上付き文字（<math><msup><mi>x</mi><mn>2</mn></msup></math>）や下付き文字（<math><msub><mi>a</mi><mi>n</mi></msub></math>）、分数（<math><mfrac><mi>a</mi><mi>b</mi></mfrac></math>）、積分記号（<math><mo>∫</mo></math>）など、数学特有の表現には専用の字形が要ります。KaTeXやMathJaxで数式を描くなら、それぞれが自前のフォントを持つので、この指定は要りません。ブラウザがMathMLで描く式や、x²のようにUnicodeの記号で書いた式に数式用フォントを使うには、これまで`Cambria Math`や`STIX Two Math`のようにOSごとのフォント名を並べていました。`math`と書けば、その環境にある数式用フォントをブラウザが選びます。

## sans-serifとの見比べ

```css demo="compare"
dd {
  font-family: sans-serif;
}

body:has(#math:checked) dd {
  font-family: math;
}

dd {
  margin: 0 0 1rem;
  font-size: 1.5rem;
}
```

```html demo="compare"
<label>
  <input id="math" type="checkbox" checked />
  mathフォントを適用する
</label>
<dl>
  <dt>ピタゴラスの定理（上付き文字）</dt>
  <dd>x² + y² = z²</dd>
  <dt>等差数列（上付き・下付き文字）</dt>
  <dd>aₙ = a₁ + (n−1)d</dd>
  <dt>数の集合（Blackboard bold）</dt>
  <dd>ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ</dd>
  <dt>積分記号</dt>
  <dd>∫₀^∞ e⁻ˣ dx = 1</dd>
</dl>
```

チェックを外して`sans-serif`にすると、1行の中で字ごとに別のフォントが使われ、字の形がそろわなくなります。`math`のままなら、ほとんどの字が1つの数式用フォントで描かれます。

## font-family: mathとは

`math`に選ばれるのは、OpenTypeのMATHテーブルを持つフォントです。MATHテーブルには、次のような表現に要る字形や、添字をずらす量といった寸法が入っています。ブラウザはMathMLの数式を、この寸法を使って組みます。

- 上付き文字と下付き文字：<math><msup><mi>x</mi><mn>2</mn></msup></math>や<math><msub><mi>a</mi><mi>n</mi></msub></math>などの指数や添字
- 複数行にまたがる括弧：<math display="block"><mrow><mo>(</mo><mfrac><mi>a</mi><mi>b</mi></mfrac><mo>)</mo></mrow></math>
- 数式の入れ子：<math display="block"><mfrac><mfrac><mi>a</mi><mi>b</mi></mfrac><mi>c</mi></mfrac></math>
- Blackboard bold：<math><mi>ℕ</mi></math>、<math><mi>ℤ</mi></math>、<math><mi>ℝ</mi></math>など

この節の式はMathMLで書いてあり、`<math>`に当たる`font-family: math`のフォントで描かれています。

一般フォントファミリーは、特定のフォント名ではなく、フォントの種類を指定するキーワードです。`serif`（明朝体）や`sans-serif`（ゴシック体）、`monospace`（等幅）などがあり、`math`はその数式版です。

## 使い方

一般フォントファミリーなので、フォントを読み込む指定は要りません。x²のようにUnicodeの記号で書いた式を入れる要素に、次のように指定します。

```css
/* [!og] */
.math-expression {
  font-family: math;
}
```

`<math>`要素には、ブラウザの既定のスタイルで`font-family: math`が当たっています。どのブラウザでも、`<math>`の`font-family`の計算値は`math`です。

```html demo="integral"
<math display="block">
  <mrow>
    <msubsup>
      <mo>∫</mo>
      <mn>0</mn>
      <mn>1</mn>
    </msubsup>
    <msup><mi>x</mi><mn>2</mn></msup>
    <mi>dx</mi>
  </mrow>
  <mo>=</mo>
  <mfrac>
    <mn>1</mn>
    <mn>3</mn>
  </mfrac>
</math>
```

この`<math>`に`font-family: sans-serif`を当てると、MATHテーブルの無いフォントで組まれます。ChromeとSafariでは積分記号が大きくならず、式の高さが縮みます。Firefoxは積分記号を大きく描いたままで、数字と文字の形だけが変わります。

## 使われるフォント

どのフォントが選ばれるかは、ブラウザとOSの組み合わせで変わります。macOSでは、どのブラウザでもOSに入っている`STIX Two Math`が選ばれます。Windowsには数式用の`Cambria Math`が入っています。

## おわりに

`font-family: math`は、その環境にある数式用フォントをブラウザに選ばせる一般フォントファミリーです。MathMLの`<math>`には既定で当たっているので、自分で指定するのは、x²のようにUnicodeの記号で書いた式を入れる要素です。
