# font-family: mathで数式用のフォントを指定する

<BrowserSupportStatus featureId="font-family-math"></BrowserSupportStatus>

## はじめに

`font-family: math`は、数式の描画に向いたフォントをブラウザに選ばせる一般フォントファミリーです。MathMLの`<math>`要素には既定でこれが当たり、OSに入っている数式用フォントで分数や添字が組まれます。

上付き文字（$x^2$）や下付き文字（$a_n$）、分数（$\frac{a}{b}$）、積分記号（$\int$）など、数学特有の表現には専用のグリフが必要です。KaTeXやMathJaxで数式を描くなら、それぞれが自前のフォントを持つので、この指定は要りません。ブラウザがMathMLで描く式や、x²のようにUnicodeの記号で書いた式に数式用フォントを使うには、これまで`Cambria Math`や`STIX Two Math`のようにOSごとのフォント名を並べていました。`math`と書けば、その環境にある数式用フォントをブラウザが選びます。

Chrome 109で先に使えており、Safari 26.2とFirefox 149が対応してBaseline 2026に加わりました。

チェックを外して`sans-serif`にすると、macOSのChrome 156では1行の中で字ごとにフォントが変わります。ℕ・ℤ・ℝはMenlo、ℚ・ℂはHelvetica、⊂はApple Symbolsで描かれました。`math`のままなら、aₙのₙだけがシステムのフォント（.SF NS）になり、ほかの字はSTIX Two Mathで描かれました。

## font-family: mathとは

`math`に選ばれるのは、OpenTypeのMATHテーブルを持つフォントです。MATHテーブルには、次のような表現に要る字形や、添字をずらす量といった寸法が入っています。ブラウザはMathMLの数式を、この寸法を使って組みます。

- 上付き文字・下付き文字: $x^2$や$a_n$などの指数や添字
- 複数行にまたがる括弧: $$\left( \frac{a}{b} \right)$$
- 数式の入れ子構造: $$\frac{\frac{a}{b}}{c}$$
- Blackboard bold: $\mathbb{N}$、$\mathbb{Z}$、$\mathbb{R}$など

この節の式は、KaTeXが自前のフォントで描いたものです。`font-family: math`で描いた式は、次の節の`<math>`要素で見られます。

一般フォントファミリーとは、特定のフォント名ではなくフォントの種類を指定するキーワードです。
`serif`（明朝体）、`sans-serif`（ゴシック体）、`monospace`（等幅）などがあり、`math`はその数式版として追加されました。

## 使い方

一般フォントファミリーなので、フォントを読み込む指定は要りません。x²のようにUnicodeの記号で書いた式を入れる要素に、次のように指定します。

```css
/* [!og] */
.math-expression {
  font-family: math;
}
```

`<math>`要素には、ブラウザの既定のスタイルで`font-family: math`が当たっています。Chrome 156、Safari 27.2、Firefox 159のいずれでも、`<math>`の`font-family`の計算値は`math`でした。

<math display="block">
  <mrow>
    <msubsup>
      <mo>∫</mo>
      <mn>0</mn>
      <mn>1</mn>
    </msubsup>
    <msup><mi>x</mi><mn>2</mn></msup>
    <mi>dx</mi>
  </mrow>
  <mo>=</mo>
  <mfrac>
    <mn>1</mn>
    <mn>3</mn>
  </mfrac>
</math>

```html
<!-- 上記の数式を表示するHTML -->
<math display="block">
  <mrow>
    <msubsup>
      <mo>∫</mo>
      <mn>0</mn>
      <mn>1</mn>
    </msubsup>
    <msup><mi>x</mi><mn>2</mn></msup>
    <mi>dx</mi>
  </mrow>
  <mo>=</mo>
  <mfrac>
    <mn>1</mn>
    <mn>3</mn>
  </mfrac>
</math>
```

上の`<math>`に`font-family: sans-serif`を当てると、MATHテーブルの無いフォントで組まれます。文字サイズ60pxで比べると、Chrome 156では積分記号が大きくならず、式の高さが164pxから106pxに縮みました。Safari 27.2でも164pxから112pxに縮みました。Firefox 159は積分記号を大きく描いたままで、数字と文字の形だけが変わりました。

## 使われるフォント

`font-family: math`を指定すると、ブラウザが数式表示に適したフォントを自動的に選択します。
`serif`を指定したときに明朝体が選ばれるのと同じ仕組みです。

どのフォントが選ばれるかはブラウザとOSの組み合わせによって異なります。
macOS 27.2では、Chrome 156、Safari 27.2、Firefox 159のいずれでも、OSに入っている`STIX Two Math`が選ばれました。文字の幅が`font-family: "STIX Two Math"`と一致し、Chrome 156の開発者ツールでも描画に使われたフォントはSTIX Two Mathでした。Windowsには数式用の`Cambria Math`が入っています。

## おわりに

`font-family: math`は、その環境にある数式用フォントをブラウザに選ばせる一般フォントファミリーです。MathMLの`<math>`には既定で当たっているので、MathMLで書いた式はそのままでSTIX Two Mathのような数式用フォントで組まれます。x²のようにUnicodeの記号で書いた式も、`math`を指定すれば字の形がそろいます。KaTeXやMathJaxで描く式は、それぞれのフォントを使うので指定は要りません。
