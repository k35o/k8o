# font-family: mathで数式用のフォントを指定する

<BrowserSupportStatus featureId="font-family-math"></BrowserSupportStatus>

## はじめに

Webページで数式を表示する際、適切なフォントがないと正しく表示されないことがあります。
上付き文字（$x^2$）や下付き文字（$a_n$）、分数（$\frac{a}{b}$）、積分記号（$\int$）など、数学特有の表現には専用のグリフが必要です。

CSSではBaseline 2026より、`font-family`プロパティとして`math`を指定することで数式を適切に表示できるようになりました。

## font-family: mathとは

`math`は、数式の描画に向いたフォントを選ばせる一般フォントファミリーです。選ばれるのは、OpenTypeのMATHテーブルを持つフォントです。MATHテーブルには、次のような表現に要る字形や、添字をずらす量といった寸法が入っています。ブラウザはMathMLの数式を、この寸法を使って組みます。

- 上付き文字・下付き文字: $x^2$や$a_n$などの指数や添字
- 複数行にまたがる括弧: $$\left( \frac{a}{b} \right)$$
- 数式の入れ子構造: $$\frac{\frac{a}{b}}{c}$$
- Blackboard bold: $\mathbb{N}$、$\mathbb{Z}$、$\mathbb{R}$など

この節の式は、KaTeXが自前のフォントで描いたものです。`font-family: math`で描いた式は、次の節の`<math>`要素で見られます。

一般フォントファミリーとは、特定のフォント名ではなくフォントの種類を指定するキーワードです。
`serif`（明朝体）、`sans-serif`（ゴシック体）、`monospace`（等幅）などがあり、`math`はその数式版として追加されました。

## 使い方

一般フォントファミリーなので、フォントの読み込み指定は不要で、以下のように指定するだけで使用できます。

```css
/* [!og] */
.math-expression {
  font-family: math;
}
```

`<math>`要素には、ブラウザの既定のスタイルで`font-family: math`が当たっています。Chrome 156、Safari 27.2、Firefox 159のいずれでも、`<math>`の`font-family`の計算値は`math`でした。

<math display="block">

    <mn>1</mn>
    <mn>3</mn>
  </mfrac>


## 使われるフォント

`font-family: math`を指定すると、ブラウザが数式表示に適したフォントを自動的に選択します。
`serif`を指定したときに明朝体が選ばれるのと同じ仕組みです（実際に選ばれるフォントは環境によって異なります）。

どのフォントが選ばれるかはブラウザとOSの組み合わせによって異なります。
macOS 27.2では、Chrome 156、Safari 27.2、Firefox 159のいずれでも、OSに入っている`STIX Two Math`が選ばれました。文字の幅が`font-family: "STIX Two Math"`と一致し、Chrome 156の開発者ツールでも描画に使われたフォントはSTIX Two Mathでした。Windowsには数式用の`Cambria Math`が入っています。

`font-family: math`を紹介しました。
