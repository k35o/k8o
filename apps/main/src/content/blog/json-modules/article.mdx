# Import AttributesでJSONをimportする

<BrowserSupportStatus featureId="json-modules"></BrowserSupportStatus>

## はじめに

JSONモジュールは、`import`に`with { type: 'json' }`を付けて、JSONファイルをJavaScriptのオブジェクトとして読み込む仕組みです。`with`以降をImport Attributesと呼びます。Firefox 138が対応して、Baseline 2025に入りました。

読むたびにサーバーから最新の内容を取り直すなら、これまでどおり`fetch()`と`response.json()`で足ります。JSONモジュールは、同じURLを何度インポートしても最初に読んだオブジェクトを返します。設定や辞書のように、コードと一緒に読み込んで`await`なしで使いたいJSONを、ブラウザでもNode.jsでも同じ`import`文で読めるのがJSONモジュールです。

## Import Attributesの書き方

```js title="main.mjs"
// [!og]
import data from './data.json' with { type: 'json' };
console.log(data); // { name: 'k8o', tags: [ 'css', 'js' ] }
console.log(data.name); // k8o

const { default: sameData } = await import('./data.json', { with: { type: 'json' } });
console.log(sameData === data); // true
```

```json title="data.json"
{ "name": "k8o", "tags": ["css", "js"] }
```

Node.jsで動かすと、コメントのとおりに出ます。`data`は、data.jsonの中身をそのまま持つオブジェクトです。動的な`import()`では、第2引数の`with`に同じ属性を書きます。2回目に読み込んでも、最初に読んだのと同じオブジェクトが返ります。

`with { type: 'json' }`を外すと、ブラウザでもNode.jsでも読み込みは失敗します。Node.jsは`ERR_IMPORT_ATTRIBUTE_MISSING`のエラーを出します。ブラウザはJavaScriptのモジュールとして読み込もうとするので、Chromeのコンソールには`Expected a JavaScript-or-Wasm module script but the server responded with a MIME type of "application/json"`と出ます。

読み込めるのは`default`だけで、`import { name } from './data.json' with { type: 'json' }`のように名前を指定すると`SyntaxError`になります。返るオブジェクトは凍結されていないので、書き換えると、同じJSONをインポートしたほかの場所からも書き換えた値が見えます。以前の書き方の`assert { type: 'json' }`は、今は`SyntaxError`になります。

## JSON以外が返ったとき

`with { type: 'json' }`を付けると、ブラウザはレスポンスのMIMEタイプがJSONのものかを確かめます。Chromeで`text/html`を返すURLを読み込むと、コンソールに次のエラーが出ます。

> Failed to load module script: Expected a JSON module script but the server responded with a MIME type of "text/html". Strict MIME type checking is enforced for module scripts per HTML spec.

`text/javascript`を返すURLを読み込んでも、どのブラウザでも読み込みは失敗し、中のコードは実行されません。属性を付けずに読み込めば、返ってきたJavaScriptはモジュールとして実行されます。JSONを返すはずのURLがJavaScriptを返しても、属性があればページで動かずに済みます。

## おわりに

設定や辞書のように取り直す必要の無いJSONは、`with { type: 'json' }`を付けた`import`で読み込めます。ブラウザでもNode.jsでも同じ書き方ができ、JSON以外が返っても実行されません。
