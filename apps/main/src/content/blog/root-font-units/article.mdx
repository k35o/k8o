# rcap・rch・rex・ric単位でremのように文字数で幅を決める

## はじめに

`rcap`と`rch`、`rex`、`ric`は、ルート要素（`<html>`）のフォントを基準にしたCSSの長さの単位です。`rem`が`em`のルート版であるように、4つは`r`を取った単位のルート版で、どの要素の中で使っても同じ長さになります。Firefox 147が対応して、Baseline 2026に入りました。

要素自身の文字に合わせるなら、`ch`や`ic`で足ります。入力欄の幅を中の数字10桁に合わせるなら`10ch`です。見出しのように文字サイズの違う要素の中では、`ch`や`ic`の値も変わります。本文の文字を基準に同じ長さにそろえたいときは、`r`の付いた単位を使います。

```html
<p style="font-size: 32px">
  <span style="display: inline-block; width: 10ch; background: gold">10ch</span>
</p>
<p style="font-size: 32px">
  <span style="display: inline-block; width: 10rch; background: skyblue">10rch</span>
</p>
```

ブラウザで開くと、文字サイズが32pxの段落の中で、`10ch`の帯は32pxの数字10桁分に伸びます。`10rch`の帯はルートの文字サイズ（ブラウザの既定なら16px）の数字10桁分のままで、`10ch`の半分の長さです。

## 要素のフォントで測るcap、ch、ex、ic

`r`の付かない4つの単位は、要素自身のフォントで測ります。

- `cap`：大文字の高さ
- `ch`：`0`の幅
- `ex`：小文字の`x`の高さ
- `ic`：`水`の幅

要素に指定した文字サイズか、親から継承した文字サイズで測るので、入れ子の要素では値が変わります。

## ルートのフォントで測るrcap、rch、rex、ric

`r`の付いた4つの単位は、同じものをルート要素のフォントで測ります。どの要素の中で使っても値が変わらないので、ページ全体で同じ長さを書けます。行の高さの`lh`にも、Baseline 2023に入ったルート版の`rlh`があります。

`font-size`の値を変えると、`ch`のバーは文字サイズに合わせて伸び縮みし、`rch`のバーは長さが変わりません。

ルートに`font: 16px sans-serif`を指定し、`font-size: 32px`の要素の中で測ると、`ch`などの4つはルートで測った値の倍になり、`r`の付いた4つはルートの値のままです。Chromeなら、`1ch`は21.02px、`1rch`は10.51pxです。

基準になるのは、ルート要素に当たっているフォントです。`font-family`を`body`にだけ指定すると、本文の文字ではなく、`<html>`に当たるブラウザの既定のフォントで測られます。`lang="en"`のページで`body`にだけ`sans-serif`を指定すると、どのブラウザでも`body`の中の`1ch`は8.9px、`1rch`は既定のTimesの`0`の幅の8pxになります。本文の文字を基準にするなら、`font-family`は`html`に指定します。

### rcap

<BrowserSupportStatus featureId="rcap" />

ルート要素の大文字の高さを1とする単位です。

```css
.heading {
  /* 大文字の高さを基準にしたマージン */
  margin-bottom: 1rcap;
}
```

### rch

<BrowserSupportStatus featureId="rch" />

ルート要素の`0`の幅を1とする単位です。

```css
/* [!og] */
.input-number {
  /* 入力欄の文字サイズに関係なく、ルートの文字で数字10桁分の幅にそろえる */
  width: 10rch;
}
```

`10rch`は、入力欄の中の数字10桁が収まる幅ではありません。入力欄は既定で親のフォントを継承せず、Chromeでは13.33pxのArialで描かれます。`font-size: 24px`の入力欄に`width: 10rch`を指定すると、どのブラウザでも10桁の数字が収まりません（Chromeでは幅109pxに対して中身が137px）。中の数字に合わせるなら`10ch`を使います。

### rex

<BrowserSupportStatus featureId="rex" />

ルート要素の小文字の`x`の高さを1とする単位です。

```css
.inline-icon {
  /* どの文字サイズの中でも、ルートのxの高さにそろえる */
  height: 1rex;
  width: 1rex;
}
```

### ric

<BrowserSupportStatus featureId="ric" />

ルート要素の`水`の幅を1とする単位です。日本語の文章の幅を、全角の文字数で決めるときに使います。

```css
.japanese-text {
  /* 全角文字20文字分の幅 */
  max-width: 20ric;
}
```

## おわりに

`r`の付いた4つの単位は、`rem`と同じくルート要素を基準にするので、どの要素の中でも同じ長さになります。本文の文字の何文字分という長さをどこでもそろえたいときは`r`の付いた単位を、要素自身の文字に合わせるときは`ch`や`ic`を使います。
