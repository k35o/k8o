# light-dark()でダークモードの背景画像を切り替える

<BrowserSupportStatus featureId="light-dark-image" />

## はじめに

`light-dark()`は、ライト用とダーク用の2つの値を渡すと、要素に適用されている`color-scheme`に応じてどちらかを返すCSSの関数です。色だけでなく`url()`やグラデーションの画像も渡せるので、ダークモードで背景画像やアイコンを差し替える指定を1つの宣言で書けます。画像を渡す書き方は、Safari 27が対応して、Baseline 2026に入りました。

グラデーションの色だけを変えるときは、色を渡す`light-dark()`をグラデーションの中に書きます。グラデーションの形や画像のファイルそのものを替えるには、これまで`prefers-color-scheme`のメディアクエリで宣言を丸ごと書き直していました。

## 画像を渡す

引数に画像を2つ渡すと、`color-scheme`がライトなら1つ目、ダークなら2つ目が使われます。渡せるのは`url()`やグラデーションといった`<image>`型の値です。

```css
/* [!og] */
:root {
  color-scheme: light dark;
}

.hero {
  background-image: light-dark(
    linear-gradient(135deg, oklch(92% 0.06 250), oklch(68% 0.16 250)),
    linear-gradient(135deg, oklch(25% 0.04 250), oklch(15% 0.02 250))
  );
}

.logo {
  content: light-dark(url('/logo-light.svg'), url('/logo-dark.svg'));
}
```

`:root`の`color-scheme: light dark`を書き忘れると、OSがダークでもライト側の画像が出たままになります。`light-dark()`がOSの設定に従って切り替わるのは、`color-scheme`に`light`と`dark`の両方を書いた要素の中だけだからです。この条件は色を渡す場合と変わりません。どのブラウザでも、OSをダークにしたまま`color-scheme`を書かない要素では、ライト側の画像が使われます。

片方だけ画像を出したいときは`none`を渡します。ダークテーマでは背景の装飾を消したいなら、`light-dark(url('/pattern.svg'), none)`と書けます。`none`は透明な画像として扱われるので、`background-size`などの指定が残っていても崩れません。

どのブラウザでも、`getComputedStyle()`の`background-image`を読むと、`light-dark()`ではなく選ばれた側の画像が返ります。`none`が選ばれた要素では`image(rgba(0, 0, 0, 0))`、つまり透明な色の画像です。`light-dark(red, url('/a.png'))`のように色と画像を混ぜると、無効な値になります。

```css demo="scheme"
body:has([value='light']:checked) .hero {
  color-scheme: light;
}
body:has([value='dark']:checked) .hero {
  color-scheme: dark;
}

.hero {
  height: 8rem;
  background-image: light-dark(
    linear-gradient(135deg, oklch(92% 0.06 250), oklch(68% 0.16 250)),
    radial-gradient(
      circle at 50% 50%,
      oklch(65% 0.15 250),
      oklch(35% 0.08 250),
      oklch(15% 0.02 250) 60%
    )
  );
}
```

```html demo="scheme"
<p>
  <label><input type="radio" name="scheme" value="inherit" checked /> 指定なし</label>
  <label><input type="radio" name="scheme" value="light" /> light</label>
  <label><input type="radio" name="scheme" value="dark" /> dark</label>
</p>
<div class="hero"></div>
```

結果の欄で`dark`を選ぶと、背景が斜めの直線グラデーションから、中心が明るい放射状のグラデーションに変わります。指定なしでは、記事のテーマに従います。

## グラデーションの色をlight-dark()で書く場合との違い

色の数と角度がライトとダークで同じときは、グラデーションの色ごとに`light-dark()`を書きます。

```css
.hero {
  background-image: linear-gradient(
    135deg,
    light-dark(oklch(92% 0.06 250), oklch(35% 0.08 250)),
    light-dark(oklch(68% 0.16 250), oklch(15% 0.02 250))
  );
}
```

上の例のように、ライトは直線、ダークは放射状と形まで変えるには、これまで`prefers-color-scheme`のメディアクエリで宣言を丸ごと書き直していました。画像を渡す`light-dark()`なら、2つを1つの宣言に並べられます。

メディアクエリが見るのはOSやブラウザの設定で、`light-dark()`が見るのは要素の`color-scheme`です。そのため、サイトのトグルで`color-scheme`を書き換えたときや、ページの一部だけ配色を固定したときも、色と背景画像が同じ基準で切り替わります。埋め込みプレビューだけライトで見せるなら、その要素に`color-scheme: light`を書くだけです。

```css
.panel {
  background-image: light-dark(url('/paper.png'), url('/slate.png'));
}

/* 埋め込みプレビューはテーマに関係なくライトで見せる */
.preview {
  color-scheme: light;
}
```

## おわりに

`light-dark()`に画像を渡すと、テーマごとに変えたい背景やアイコンを、メディアクエリなしで書けます。色と同じく`color-scheme`の使用値で切り替わるので、`color-scheme`を上書きした領域にもそのまま追従します。
