# JSON.rawJSONでJSONの大きな数値を丸めずに扱う

<BrowserSupportStatus featureId="json-raw" />

`JSON.rawJSON`は、渡したテキストを`JSON.stringify`の出力にそのまま埋め込む値を作るメソッドです。`JSON.parse`のreviverに渡る`context.source`と合わせて、JSON source text accessと呼ばれます。JSONとJavaScriptの値を行き来すると丸められる数値を、元のテキストのまま扱えます。Safari 18.4が対応して、Baseline 2025に入りました。

扱う整数が`Number.MAX_SAFE_INTEGER`以下なら、これまでの`JSON.parse`と`JSON.stringify`で足ります。それを超える64ビット整数のIDを、1桁も変えずに`BigInt`で読み書きするときに、この機能が要ります。

## JSONの数値とJavaScriptの数値のずれ

JSONのテキストには、桁数の制限なく数値を書けます。一方、JavaScriptの数値はIEEE 754の倍精度の浮動小数点数なので、誤差なく扱える整数は`Number.MAX_SAFE_INTEGER`（2^53 - 1 = 9007199254740991）までです。

データベースの64ビット整数のIDやスノーフレークIDのように、この範囲を超える数値がJSONで届くと、`JSON.parse`した時点で丸められます。

```js
const json = '{"value": 12345678901234567890}';
console.log(JSON.parse(json).value); // 12345678901234567000
```

書き出す側も同じです。

```js
console.log(JSON.stringify({ value: 12345678901234567890 }));
// {"value":12345678901234567000}
```

`12345678901234567890`ちょうどの数値はJavaScriptに無く、コードに書いた数値リテラルの時点で丸められています。そのため、`JSON.stringify`でこのテキストを書き出す方法はありませんでした。

任意の桁数の整数を表す`BigInt`もありますが、これまでのJSONの読み書きでは使えませんでした。

- 読み取り：パース結果を加工するreviver関数が呼ばれる時点で、数値はもう丸められている
- 書き出し：`JSON.stringify`は`BigInt`を書き出せず、`TypeError`を投げる

そのため、サーバーが数値を文字列で送るようにレスポンスの形を変えるか、独自のJSONパーサーを持つライブラリを使っていました。

## 読み取り時に元のテキストを参照するreviverのcontext

`JSON.parse`は第2引数に、パース結果を加工するreviver関数を受け取ります。reviverは値ごとに`(key, value)`で呼ばれ、返した値がその位置の値になります。

```js
const doubled = JSON.parse('{"a": 1, "b": 2}', (key, value) =>
  typeof value === 'number' ? value * 2 : value,
);
console.log(doubled); // { a: 2, b: 4 }
```

このreviverに、第3引数の`context`が加わりました。`context`は呼び出しのたびに作られるオブジェクトで、今は`source`プロパティだけを持ちます。`source`には、処理中の値の元のJSONテキストが入っています。

```js
// [!og]
const json = '{"balance": 12345678901234567890}';
const data = JSON.parse(json, (key, value, context) =>
  key === 'balance' ? BigInt(context.source) : value,
);
console.log(data.balance); // 12345678901234567890n
```

コンソールに貼ると`12345678901234567890n`が出て、末尾の`890`まで残っています。`value`はすでに数値に変えられて丸められていますが、`context.source`には変換前のテキスト`'12345678901234567890'`が残っています。これを`BigInt`に渡せば、レスポンスの形を変えずに、桁を落とさず読み取れます。

fetchの`response.json()`にはreviverを渡せません。レスポンスに使うときは、`response.text()`で文字列として受け取ってから`JSON.parse`に渡します。

```js
const response = await fetch('/api/account');
const data = JSON.parse(await response.text(), (key, value, context) =>
  key === 'balance' ? BigInt(context.source) : value,
);
```

`source`があるのは、`value`がプリミティブ値（数値、文字列、真偽値、`null`）のときだけです。オブジェクトや配列は、中の値をreviverが書き換えられるので元のテキストと対応しなくなり、`source`の無い空のオブジェクトが渡されます。

```js
JSON.parse('{"a": 1, "b": [2, 3]}', (key, value, context) => {
  console.log(key, value, context);
  return value;
});
// a 1 { source: '1' }
// 0 2 { source: '2' }
// 1 3 { source: '3' }
// b [ 2, 3 ] {}
//  { a: 1, b: [ 2, 3 ] } {}
```

配列`[2, 3]`の要素にはそれぞれの`source`が渡りますが、配列の`b`と、最後に呼ばれるルートのオブジェクト（`key`は空文字列）では`context`が空です。

`source`には、書いたときのテキストがそのまま入ります。`1.0`や`1e2`は書いたとおりの文字列になり、文字列は前後のダブルクォートとエスケープを含みます。

```js
JSON.parse('{"a": 1.0, "b": 1e2, "c": "\\u0041"}', (key, value, context) => {
  if (key) console.log(key, value, context.source);
  return value;
});
// a 1 1.0
// b 100 1e2
// c A "\u0041"
```

## 書き出すテキストを直接指定するJSON.rawJSON

書き出す側で対になるのが`JSON.rawJSON`です。渡したテキストをそのままJSONに埋め込む、raw JSONオブジェクトを作ります。

```js
const raw = JSON.rawJSON('12345678901234567890');
console.log(JSON.stringify({ balance: raw }));
// {"balance":12345678901234567890}
```

数値をそのまま渡したときは`12345678901234567000`に丸められましたが、今度は桁がそのまま出ます。値が一度もJavaScriptの数値にならないので、丸められることがありません。

`JSON.rawJSON`が返すのは数値ではなく、専用のオブジェクトです。上の`raw`をNode.jsで表示すると、渡したテキストを持つ`rawJSON`プロパティだけがあります。

```js
console.log(raw); // [Object: null prototype] { rawJSON: '12345678901234567890' }
console.log(raw.rawJSON); // 12345678901234567890
```

プロトタイプは`null`で、オブジェクトは凍結されているので、あとから`rawJSON`を書き換えることはできません。

`JSON.rawJSON`に渡せるのは、プリミティブ値を表す正しいJSONテキストだけです。正しくないJSONも、オブジェクトや配列を表すテキストも`SyntaxError`になるので、出力するJSONの構造を壊すテキストは入れられません。

```js
JSON.rawJSON('12,3'); // SyntaxError
JSON.rawJSON('{"a": 1}'); // SyntaxError
JSON.rawJSON('[1, 2]'); // SyntaxError
JSON.rawJSON(' 1'); // SyntaxError（前後の空白も受け付けない）
```

### 数値以外の用途

プリミティブ値を表すテキストなら、数値でなくても渡せます。`JSON.stringify`は文字列の中の絵文字をそのまま書き出しますが、`JSON.rawJSON`に渡せばエスケープした形のまま書き出せます。

```js
const raw = JSON.rawJSON('"\\ud83d\\ude04"');
const json = JSON.stringify({ emoji: raw });
console.log(json); // {"emoji":"\ud83d\ude04"}
console.log(JSON.parse(json).emoji); // 😄
```

受け取る側がUnicodeをうまく扱えないときも、ASCIIだけでJSONを書けます。

### replacerでBigIntを書き出す

`JSON.stringify`は第2引数に、書き出す値を加工するreplacer関数を受け取ります。reviverと同じく値ごとに`(key, value)`で呼ばれ、返した値が書き出されます。

```js
const doubled = JSON.stringify({ a: 1, b: 2 }, (key, value) =>
  typeof value === 'number' ? value * 2 : value,
);
console.log(doubled); // {"a":2,"b":4}
```

replacerで`BigInt`をraw JSONオブジェクトに変えれば、書き出すときも桁を落としません。

```js
const json = JSON.stringify({ balance: 12345678901234567890n }, (key, value) =>
  typeof value === 'bigint' ? JSON.rawJSON(value.toString()) : value,
);
console.log(json); // {"balance":12345678901234567890}
```

## raw JSONオブジェクトを判定するJSON.isRawJSON

`JSON.isRawJSON`は、値が`JSON.rawJSON`で作ったraw JSONオブジェクトかどうかを返します。raw JSONオブジェクトには内部で印が付いているので、同じ形のオブジェクトを自分で作っても`true`にはなりません。

```js
console.log(JSON.isRawJSON(JSON.rawJSON('123'))); // true
console.log(JSON.isRawJSON({ rawJSON: '123' })); // false
```

`JSON.stringify`を包むライブラリで、受け取った値をraw JSONオブジェクトとして扱うかを見分けるときに使います。

## TypeScriptの型

TypeScriptには、`lib`を`esnext`にしても、`JSON.rawJSON`と`JSON.isRawJSON`、reviverの`context`の型がありません。`JSON.rawJSON`は`Property 'rawJSON' does not exist on type 'JSON'`（TS2339）になり、3つの引数を取るreviverはTS2345になります。使うときは、グローバルの`.d.ts`に型を足します。`source`はプリミティブ値のときだけあるので省略可能にしてあり、`BigInt`に渡すときは`context.source!`と書きます。

```ts title="json-source-text-access.d.ts"
interface JSON {
  parse(
    text: string,
    reviver: (this: any, key: string, value: any, context: { source?: string }) => any,
  ): any;
  rawJSON(text: string): { readonly rawJSON: string };
  isRawJSON(value: unknown): boolean;
}
```

## おわりに

読み取るときはreviverの`context.source`を、書き出すときは`JSON.rawJSON`を使うと、`Number.MAX_SAFE_INTEGER`を超える数値も元のテキストのまま扱えます。`BigInt`と組み合わせれば、レスポンスの形を変えたりライブラリを足したりせずに、64ビット整数のIDを丸めずに読み書きできます。
