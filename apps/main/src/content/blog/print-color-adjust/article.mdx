# print-color-adjustで背景色をそのまま印刷する

<BrowserSupportStatus featureId="print-color-adjust"></BrowserSupportStatus>

## はじめに

`print-color-adjust`は、印刷するときにブラウザが色を変えてよいかを指定するCSSプロパティです。`exact`を指定すると、印刷で省かれる背景色や、変えられる文字色をそのまま印刷できます。Chrome 136が接頭辞なしの名前に対応して、Baseline 2025に入りました。

ブラウザは印刷するとき、インクを節約し文字を読みやすくするために、背景色を省いたり文字色を変えたりします。ページ全体の背景を印刷するかは、ユーザーが印刷の設定（Chromeなら背景のグラフィック）で選べます。印刷のときだけ別の色にするなら、`@media print`で足ります。しかし、ページの側から、特定の要素の色を変えずに印刷するよう指示できるのは`print-color-adjust: exact`だけです。

紺の背景に白い文字のdivを2つ用意し、下のdivにだけ`print-color-adjust: exact`を指定します。

```html
<div style="background-color: navy; color: white;">指定なし</div>
<div style="background-color: navy; color: white; print-color-adjust: exact;">exact</div>
```

<PrintColorAdjustExample />

上の2つのdivは、このコードをそのまま置いたものです。Chromeでこのページの印刷プレビューを開き、背景のグラフィックを切ると、指定なしのdivは背景が消えて白い文字が灰色になり、exactのdivは紺の背景に白い文字のまま印刷されます。

## print-color-adjustプロパティ

値は`economy`（初期値）と`exact`の2つで、親要素から子要素へ継承されます。

接頭辞の付いた書き方は、ブラウザによって受け付けるものが違います。ChromeとSafariは`-webkit-print-color-adjust`も受け付けますが、Firefoxは受け付けません。`-moz-print-color-adjust`はどれも受け付けず、古い名前の`color-adjust`はSafariとFirefoxだけが受け付けます。接頭辞なしの`print-color-adjust`はどれも受け付けるので、今はこれだけを書けば足ります。

### economy

`economy`は、出力する機器に合わせて、ブラウザが色やスタイルを変えることを許します。

```css
.content {
  print-color-adjust: economy; /* 初期値 */
}
```

Chromeで背景のグラフィックを切ってPDFに印刷すると、`economy`の要素は背景色と背景画像が省かれ、白や黄色の文字は濃い色に変わります。インラインのSVGの塗りと枠線の色は、`economy`のままでも印刷されます。

### exact

`exact`は、ユーザーが指示したとき以外は、色やスタイルを変えないようブラウザに求めます。

```css
.preserve-design {
  print-color-adjust: exact;
}
```

ハイコントラストのような、ブラウザがユーザーに用意している設定は、`exact`より優先されます。

## 使う場面

### 道順の地図

[仕様](https://drafts.csswg.org/css-color-adjust/#print-color-adjust)は、`exact`が要る例として、道順の地図を印刷する場面を挙げています。

```css
.directions {
  print-color-adjust: exact;
}

.directions .step:nth-child(even) {
  background-color: var(--color-bg); /* 白 */
}

.directions .step:nth-child(odd) {
  background-color: var(--color-bg-light); /* ライトグレー */
}
```

道順の手順を白とライトグレーの背景で交互に分けていると、`economy`では背景が省かれてすべて白で印刷され、手順の区切りが分かりにくくなります。

### ブランドの色

ロゴやボタンを、サイトや会社を表す色で印刷したいときです。インラインのSVGの塗りは`economy`のままでも印刷されるので、背景色で塗った要素に指定します。

```css
/* [!og] */
.logo,
.brand-element {
  background-color: var(--color-primary); /* ブランドの色 */
  color: white;
  print-color-adjust: exact;
}
```

### グラフの色分け

グラフの系列を背景色で塗り分けているときです。同じ色で印刷されると、どの系列か分からなくなります。

```css
.chart {
  print-color-adjust: exact;
}

.chart .series-1 {
  background-color: var(--color-blue-700); /* 青 */
}
.chart .series-2 {
  background-color: var(--color-red-700); /* 赤 */
}
.chart .series-3 {
  background-color: var(--color-green-700); /* 緑 */
}
```

このように色で区別するときも、先に模様やラベルのような色以外の方法で区別できるかを考えます。WCAGの達成方法の[G111](https://www.w3.org/TR/WCAG20-TECHS/G111.html)が、色と模様を合わせて使う方法を説明しています。

## おわりに

`print-color-adjust: exact`を使うと、地図やグラフ、ブランドの色のように、印刷でも変えたくない色をそのまま印刷できます。ユーザーの設定が優先されることもあるので、色が変わっても読めるようにしておきます。
