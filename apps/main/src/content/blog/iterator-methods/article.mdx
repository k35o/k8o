# Iterator Helpersで配列にせずmapやfilterを使う

<BrowserSupportStatus featureId="iterator-methods" />

## はじめに

Iterator Helpersは、`map`や`filter`、`take`などのメソッドを`Iterator`オブジェクトに足す機能です。`Map`や`Set`の`values()`、ジェネレータが返すイテレータを、配列にせずにそのまま加工できます。Safari 18.4が対応して、Baseline 2025に入りました。

要素が手元にそろっていて数も多くないときは、`[...set.values()]`や`Array.from()`で配列にしてから、配列のメソッドを使います。終わりの無いジェネレータや、大きな並びから先頭のいくつかだけを取り出す処理は、配列にすると全部を取り出し終えるまで先へ進めません。必要な分だけを取り出して止められるのが、Iterator Helpersです。

```js
function* naturals() {
  let n = 0;
  while (true) yield n++;
}

console.log(naturals().filter((n) => n % 3 === 0).map((n) => n * n).take(4).toArray()); // [0, 9, 36, 81]
```

コンソールに貼ると`[0, 9, 36, 81]`が出ます。`naturals()`は0から1ずつ増える値を終わりなく返しますが、`take(4)`で4つ取った時点で止まります。

使えるメソッドは、`map`、`filter`、`take`、`drop`、`flatMap`、`reduce`、`toArray`、`forEach`、`some`、`every`、`find`と、静的メソッドの`from`です。

複数のイテラブルを1つのイテレータにつなぐ[`Iterator.concat()`](/blog/iterator-concat)は、Baseline 2026に入りました。

## Iteratorオブジェクト

`Iterator`オブジェクトは、データの並びを1つずつ取り出すオブジェクトです。`next()`を呼ぶたびに、次の値の`value`と、もう値が無いかを表す`done`を持つオブジェクトを返します。

組み込みのイテレータの多くは、`Iterator`を継承しています。`Array.prototype[Symbol.iterator]`や`Map.prototype.values`、`Set.prototype.values`の結果は、どれも`Iterator`オブジェクトを継承しています。`Intl.Segmenter.prototype.segment`の結果や`NodeList`は、それ自身は`Iterator`を継承していませんが、`[Symbol.iterator]()`で取り出したイテレータは継承しています。たとえば、`document.querySelectorAll('a') instanceof Iterator`は`false`、`document.querySelectorAll('a')[Symbol.iterator]() instanceof Iterator`は`true`です。

```js
const iterator = [1, 2, 3][Symbol.iterator]();
console.log(iterator.next()); // { value: 1, done: false }
console.log(iterator.next()); // { value: 2, done: false }
console.log(iterator.next()); // { value: 3, done: false }
console.log(iterator.next()); // { value: undefined, done: true }

const str = 'hello';
for (const char of str[Symbol.iterator]()) {
  console.log(char); // 'h' 'e' 'l' 'l' 'o'
}
```

## Iterator Helpers

これまで`Iterator`オブジェクトを加工するときは、`for...of`で処理を書くか、配列にしてから配列の`map`や`filter`を使っていました。

```js
const set = new Set([1, 2, 3]);
console.log([...set.values()].some((i) => i % 2 === 0)); // true

const segmenter = new Intl.Segmenter('ja', {
  granularity: 'grapheme',
});
[...segmenter.segment('あいうえお')].forEach((x) =>
  console.log(x.segment),
); // 'あ' 'い' 'う' 'え' 'お'

const nodeList = document.querySelectorAll('div');
Array.from(nodeList).forEach((x) => console.log(x.innerText)); // '...', '...'
```

`[...set.values()]`のように配列にすると、その時点で全部の値を取り出します。`Iterator`オブジェクトの、呼ばれたときに次の値を取り出す性質を生かせません。

Iterator Helpersを使えば、配列にせずにそのまま呼べます。

```js
const set = new Set([1, 2, 3]);
console.log(set.values().some((i) => i % 2 === 0)); // true

const segmenter = new Intl.Segmenter('ja', {
  granularity: 'grapheme',
});
segmenter
  .segment('あいうえお')
  [Symbol.iterator]()
  .forEach((x) => console.log(x.segment)); // 'あ' 'い' 'う' 'え' 'お'

const nodeList = document.querySelectorAll('div');
nodeList[Symbol.iterator]().forEach((x) => console.log(x.innerText)); // '...', '...'
```

`Iterator`オブジェクトのまま扱うので、`some`や`take`は必要な分だけ値を取り出して止まります（`forEach`は全部を取り出します）。100万要素の`Set`から、`map`と`filter`を通した先頭の10個を取り出す処理で比べます。

```js
const set = new Set(Array.from({ length: 1_000_000 }, (_, i) => i));
// 配列にしてから
[...set.values()].map((i) => i * 2).filter((i) => i % 3 === 0).slice(0, 10);
// Iterator Helpers
set.values().map((i) => i * 2).filter((i) => i % 3 === 0).take(10).toArray();
```

先頭の10個だけを取り出すときは、どのブラウザでもIterator Helpersの方がはっきり速くなります。一方で、`take(10)`を外して全部の要素を取り出すと、Iterator Helpersの方が遅くなります。全部の要素を使うなら、配列にしてから配列のメソッドを使う方が速いです。

### 使い方

`next()`を呼ぶと0から2までを順に返す、`Iterator`オブジェクトに似た`counter`で試します。`createCounter()`を呼ぶたびに、0から数え直す`counter`を作ります。

```js
const createCounter = () => ({
  count: 0,
  next() {
    if (this.count < 3) {
      return { value: this.count++, done: false };
    }
    return { value: undefined, done: true };
  },
});
const counter = createCounter();
```

`counter.next()`は、`value`が`2`になるまで、`done`が`false`のオブジェクトを返します。

```js
console.log(counter.next()); // { value: 0, done: false }
console.log(counter.next()); // { value: 1, done: false }
console.log(counter.next()); // { value: 2, done: false }
console.log(counter.next()); // { value: undefined, done: true }
```

一度数え終わった`counter`は`done: true`を返し続けるので、以降の例では`createCounter()`で作り直してから使います。

#### from

`from`は、`Iterator`オブジェクトの静的メソッドです。引数に渡した反復可能なオブジェクトや、`counter`のように`next`メソッドを持つオブジェクトから、新しい`Iterator`オブジェクトを生成します。

`counter`は`next`メソッドを持つだけで、`Iterator`を継承しておらず、`[Symbol.iterator]`も持ちません。そのままでは`for...of`で回せず、以後紹介するメソッドもありません。`Iterator.from`で包むと、どちらも使えるようになります。

```js
// for (const x of counter) {} はTypeErrorになる
const counterIter = Iterator.from(createCounter());
for (const x of counterIter) {
  console.log(x); // 0 1 2
}
console.log(counterIter instanceof Iterator); // true
```

このあとのメソッドは、`Iterator.from`で包んでから呼びます。`Set.prototype.values()`の結果のように、もとから`Iterator`を継承しているものは包まなくても呼べます。

#### map

`map`は、`Iterator`オブジェクトの各要素に対して指定した関数を適用し、新しい`Iterator`オブジェクトを返します。

```js
const counterIter = Iterator.from(createCounter());
const mappedIter = counterIter.map((x) => x * 2);
console.log(mappedIter.next()); // { value: 0, done: false }
console.log(mappedIter.next()); // { value: 2, done: false }
console.log(mappedIter.next()); // { value: 4, done: false }
console.log(mappedIter.next()); // { value: undefined, done: true }
```

関数が呼ばれるのは、`map`を呼んだときではなく、`next()`を呼んだときです。コールバックに`console.log`を入れると、呼ばれるタイミングが分かります。

```js
// [!og]
const counterIter = Iterator.from(createCounter());
const mappedIter = counterIter.map((x) => {
  console.log(x);
  return x * 2;
});
console.log(mappedIter.next()); // 0 { value: 0, done: false }
console.log(mappedIter.next()); // 1 { value: 2, done: false }
console.log(mappedIter.next()); // 2 { value: 4, done: false }
```

`console.log`は、`next()`を呼ぶたびに1回ずつ出ます。ほかのメソッドも、ほとんどは同じように`next()`のたびに評価します。以下では、全部を取り出すメソッドと、取り出し方が分かりにくいメソッドだけ、その点を書きます。

#### filter

`filter`は、`Iterator`オブジェクトの各要素に対して指定した関数を適用し、真となる要素だけを含む新しい`Iterator`オブジェクトを返します。

```js
const counterIter = Iterator.from(createCounter());
const filteredIter = counterIter.filter((x) => x % 2 === 0);
console.log(filteredIter.next()); // { value: 0, done: false }
console.log(filteredIter.next()); // { value: 2, done: false }
console.log(filteredIter.next()); // { value: undefined, done: true }
```

`filter`は、関数が偽を返した値を飛ばし、真になる値が出るまで取り出し続けます。

```js
const counterIter = Iterator.from(createCounter());
const filteredIter = counterIter.filter((x) => {
  console.log(x);
  return x % 2 === 0;
});
console.log(filteredIter.next()); // 0 { value: 0, done: false }
console.log(filteredIter.next()); // 1 2 { value: 2, done: false }
console.log(filteredIter.next()); // { value: undefined, done: true }
```

#### take

`take`は、`Iterator`オブジェクトから指定した数の要素を取り出し、新しい`Iterator`オブジェクトを返します。

```js
const counterIter = Iterator.from(createCounter());
const takenIter = counterIter.take(2);
console.log(takenIter.next()); // { value: 0, done: false }
console.log(takenIter.next()); // { value: 1, done: false }
console.log(takenIter.next()); // { value: undefined, done: true }
```

#### drop

`drop`は、`Iterator`オブジェクトから指定した数の要素をスキップし、新しい`Iterator`オブジェクトを返します。

```js
const counterIter = Iterator.from(createCounter());
const droppedIter = counterIter.drop(2);
console.log(droppedIter.next()); // { value: 2, done: false }
console.log(droppedIter.next()); // { value: undefined, done: true }
```

#### flatMap

`flatMap`は、`Iterator`オブジェクトの各要素に対して指定した関数を適用し、得られた値をフラットにした新しい`Iterator`オブジェクトを返します。

```js
const counterIter = Iterator.from(createCounter());
const flatMappedIter = counterIter.flatMap((x) => [x, x * 2]);
console.log(flatMappedIter.next()); // { value: 0, done: false }
console.log(flatMappedIter.next()); // { value: 0, done: false }
console.log(flatMappedIter.next()); // { value: 1, done: false }
console.log(flatMappedIter.next()); // { value: 2, done: false }
console.log(flatMappedIter.next()); // { value: 2, done: false }
console.log(flatMappedIter.next()); // { value: 4, done: false }
console.log(flatMappedIter.next()); // { value: undefined, done: true }
```

関数が返した配列は、そのまま`value`になるのではなく、要素が1つずつ`next()`のたびに返ります。

#### reduce

`reduce`は、`Iterator`オブジェクトの各要素に対して指定した関数を適用し、最終的な値を返します。

```js
const counterIter = Iterator.from(createCounter());
const reducedValue = counterIter.reduce((acc, x) => {
  return acc + x;
}, 0);
console.log(reducedValue); // 3
```

`reduce`は、全部の要素を取り出してから値を返します。対象を絞るときは、先に`take`や`drop`を通します。

#### toArray

`toArray`は、`Iterator`オブジェクトの全ての要素を配列に変換します。

```js
const counterIter = Iterator.from(createCounter());
const array = counterIter.toArray();
console.log(array); // [ 0, 1, 2 ]
```

`toArray`も、全部の要素を取り出します。

#### forEach

`forEach`は、`Iterator`オブジェクトの各要素に対して指定した関数を適用します。

```js
const counterIter = Iterator.from(createCounter());
counterIter.forEach((x) => {
  console.log(x);
});
// 0
// 1
// 2
```

`forEach`も、全部の要素を取り出します。

#### some

`some`は、`Iterator`オブジェクトの各要素に対して指定した関数を適用し、真となる要素が1つでもあれば`true`を返します。

```js
const counterIter = Iterator.from(createCounter());
const hasEven = counterIter.some((x) => x % 2 === 0);
console.log(hasEven); // true
```

`some`は、真になる要素が見つかった時点で取り出すのをやめます。見つからなければ、最後まで取り出して`false`を返します。

```js
const counterIter = Iterator.from(createCounter());
const hasOdd = counterIter.some((x) => {
  console.log(x);
  return x % 2 === 1;
});
console.log(hasOdd); // 0 1 true
```

#### every

`every`は、`Iterator`オブジェクトの各要素に対して指定した関数を適用し、全ての要素が真であれば`true`を返します。

```js
const counterIter = Iterator.from(createCounter());
const allEven = counterIter.every((x) => x % 2 === 0);
console.log(allEven); // false
```

`every`は、偽になる要素が見つかった時点で取り出すのをやめます。

```js
const counterIter = Iterator.from(createCounter());
const allEven = counterIter.every((x) => {
  console.log(x);
  return x % 2 === 0;
});
console.log(allEven); // 0 1 false
```

#### find

`find`は、`Iterator`オブジェクトの各要素に対して指定した関数を適用し、真となる要素を返します。

```js
const counterIter = Iterator.from(createCounter());
const found = counterIter.find((x) => x === 1);
console.log(found); // 1
```

`find`は、真になる要素が見つかった時点で取り出すのをやめます。

```js
const counterIter = Iterator.from(createCounter());
const found = counterIter.find((x) => {
  console.log(x);
  return x === 1;
});
console.log(found); // 0 1 1
```

## おわりに

Iterator Helpersを使うと、`Map`や`Set`の`values()`やジェネレータを配列にせずに、`map`や`filter`、`take`で加工できます。途中で止められる処理では必要な分だけ取り出すので速くなり、全部の要素を使う処理では配列にした方が速いこともあります。
