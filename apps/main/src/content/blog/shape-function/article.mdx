# CSS shape()で曲線のある図形をレスポンシブに描く

<BrowserSupportStatus featureId="shape-function" />

## はじめに

`shape()`は、`clip-path`で要素を切り抜く図形を、直線やベジェ曲線、円弧のコマンドを並べて描くCSS関数です。座標に`%`や`calc()`、CSS変数を使えるので、要素の大きさに合わせて伸び縮みする図形を作れます。Firefox 148が対応して、Baseline 2026に入りました。

円や楕円、直線だけの多角形なら、今までどおり`circle()`や`ellipse()`、`polygon()`で足ります。曲線を含む図形は`path()`でも描けますが、SVGのパス構文を使うため単位なしのピクセル値しか指定できず、`%`や`calc()`が使えません。要素のサイズに応じて図形を変化させるには、SVGに頼る必要がありました。

```css demo="path-fixed"
.triangle {
  width: 300px;
  height: 100px;
  background-color: teal;
  /* path()は固定のピクセル値しか使えない */
  clip-path: path('M 50 0 L 100 100 L 0 100 Z');
}
```

```html demo="path-fixed"
<div class="triangle"></div>
```

要素の幅は300pxでも、三角形は`path()`に書いた100pxの大きさのままで、左に寄ります。

SVGを用意せずにCSSだけで、曲線のある図形を要素の大きさに合わせて描けるのが`shape()`です。

## shape()

`shape()`は、主に`clip-path`と`offset-path`に書きます。`clip-path`に書くと、図形の内側だけが表示され、外側は切り取られます。

```css demo="shape-triangle"
.triangle {
  width: 200px;
  height: 100px;
  background-color: teal;
  /* shape(<fill-rule>? from 開始点, <shape-command>, ...) */
  clip-path: shape(from 50% 0%, line to 100% 100%, line to 0% 100%, close);
}
```

```html demo="shape-triangle"
<div class="triangle"></div>
```

`class="triangle"`の要素は、幅200px、高さ100pxの長方形から、上辺の中央を頂点とする三角形に切り抜かれます。`width`を400pxにしても、三角形のまま横に伸びます。切り抜いた外側の左上と右上の隅で`document.elementFromPoint()`を呼ぶと、切り抜いた要素ではなく下にある要素が返ります。

`from`で開始点を指定し、カンマで区切って描画のコマンドを並べます。座標は、参照ボックス（`clip-path`の既定は`border-box`）の左上の隅を原点にして、長さか`%`で指定します。

先頭には`<fill-rule>`（`nonzero`か`evenodd`）も書けますが、`polygon()`や`path()`と違い、後ろにカンマを置きません。`shape(evenodd, from 0 0, ...)`は無効な値になり、`shape(evenodd from 0 0, ...)`なら有効です。

## 描画のコマンド

描画のコマンドは次の8つです。

- `move`：描かずに現在位置を動かす
- `line`：直線を描く
- `hline`：水平の直線を描く
- `vline`：垂直の直線を描く
- `curve`：ベジェ曲線を描く
- `smooth`：前の曲線になめらかにつながる曲線を描く
- `arc`：楕円の弧を描く
- `close`：パスを閉じる

### toとby

`close`以外のコマンドは、座標を`to`（絶対座標）か`by`（相対座標）で指定します。

```css
.to {
  /* to: 参照ボックスの左上隅からの絶対座標 */
  clip-path: shape(from 0% 0%, line to 100% 100%);
}

.by {
  /* by: 直前のコマンドの終点からの相対座標 */
  /* 終点は(100px, 100px)になる */
  clip-path: shape(from 50px 50px, line by 50px 50px);
}
```

### close

`close`は座標を取らず、現在位置から`from`で指定した開始点（または直前の`move`の位置）まで直線を引いて、パスを閉じます。

### line、hline、vline

直線を描きます。`line`はどの方向にも、`hline`は水平にだけ、`vline`は垂直にだけ動きます。

```css demo="line"
/* [!og] */
.shape {
  height: 128px;
  background-color: teal;
  clip-path: shape(
    from 0% 0%,        /* 左上から開始 */
    line to 100% 0%,   /* → 右上へ */
    line to 100% 50%,  /* ↓ 右端の中央へ */
    hline to 0%,       /* ← 左端へ（水平のみ） */
    vline to 100%,     /* ↓ 下端へ（垂直のみ） */
    line to 100% 100%, /* → 右下へ */
    close              /* 左上に戻って閉じる */
  );
}
```

```html demo="line"
<div class="shape"></div>
```

### move

描かずに現在位置を動かします。`close`の後に、新しいサブパスを始めるときに使います。

```css demo="move"
.shape {
  height: 128px;
  background-color: teal;
  clip-path: shape(
    from 5% 10%,     /* 左上から開始 */
    hline to 45%,    /* → 右上へ */
    vline to 90%,    /* ↓ 右下へ */
    hline to 5%,     /* ← 左下へ */
    close,           /* 左上に戻って閉じる */
    move to 55% 10%, /* 描画せずに右側へ移動 */
    hline to 95%,    /* → 右上へ */
    vline to 90%,    /* ↓ 右下へ */
    hline to 55%,    /* ← 左下へ */
    close            /* 左上に戻って閉じる */
  );
}
```

```html demo="move"
<div class="shape"></div>
```

### curve

ベジェ曲線を描きます。`with`の後に制御点を書いて、曲がり具合を決めます。制御点が1つなら2次ベジェ曲線、`/`で区切って2つ書くと3次ベジェ曲線になります。

```css demo="curve"
.shape {
  height: 128px;
  background-color: teal;
  clip-path: shape(
    from 0% 0%,                 /* 左上から開始 */
    hline to 100%,              /* → 右端へ */
    vline to calc(100% - 48px), /* ↓ 突起の始点へ */
    /* 2次ベジェ曲線: 右側の突起 */
    curve to 50% 95% with 75% 95%,
    /* 3次ベジェ曲線: 左側の突起 */
    curve to 0% calc(100% - 48px) with 40% 95% / 25% calc(100% - 48px),
    close                       /* 左上に戻って閉じる */
  );
}
```

```html demo="curve"
<div class="shape"></div>
```

この例は、ツールチップのような吹き出しの形です。底辺の突起の高さは`48px`で固定し、全体の幅と高さは要素に追従させています。固定の長さと`%`を混ぜた図形は、`path()`では描けません。

### smooth

直前の`curve`や`smooth`の制御点を反転させた点を制御点にして、なめらかにつながる曲線を描きます。直前が曲線のコマンドでなければ、現在位置を制御点にします。

```css demo="smooth"
.shape {
  height: 128px;
  background-color: teal;
  clip-path: shape(
    from 0% 50%,                 /* 左端の中央から開始 */
    curve to 25% 0% with 10% 0%, /* 最初の山 */
    smooth to 50% 50%,           /* 滑らかに谷へ */
    smooth to 75% 0%,            /* 滑らかに次の山へ */
    smooth to 100% 50%,          /* 滑らかに右端へ */
    close
  );
}
```

```html demo="smooth"
<div class="shape"></div>
```

### arc

楕円の弧を描きます。`of`の後に楕円の半径を書きます。1つ目が横（rx）、2つ目が縦（ry）の半径で、1つだけ書くと円の弧になります。

```css demo="arc"
.shape {
  width: 200px;
  height: 128px;
  background-color: teal;
  clip-path: shape(
    from 50% 15%,                       /* 上端の中央から開始 */
    arc to 50% 85% of 60px 55px cw, /* rx=60px, ry=55pxの楕円に沿って時計回りに弧を描く */
    close
  );
}
```

```html demo="arc"
<div class="shape"></div>
```

ほかに、次のキーワードを書けます。

- `cw`か`ccw`：時計回りか反時計回り。既定は`ccw`
- `large`か`small`：大きい弧か小さい弧。既定は`small`
- `rotate <angle>`：楕円の回転角度。既定は`0deg`

`large`を書くと、同じ2点のあいだでも大きい方の弧を描きます。

```css demo="arc-large"
.shape {
  width: 200px;
  height: 128px;
  background-color: teal;
  clip-path: shape(
    from 50% 15%,
    arc to 50% 85% of 60px 55px large cw,
    close
  );
}
```

```html demo="arc-large"
<div class="shape"></div>
```

`rotate`を書くと、楕円そのものを回転させます。

```css demo="arc-rotate"
.shape {
  width: 200px;
  height: 128px;
  background-color: teal;
  clip-path: shape(
    from 50% 15%,
    arc to 50% 85% of 80px 50px cw rotate 45deg,
    close
  );
}
```

```html demo="arc-rotate"
<div class="shape"></div>
```

## path()との比較

`path()`と`shape()`で、同じ三角形を書き比べます。

```css
.path-triangle {
  /* path()では固定のピクセル値しか使えない */
  clip-path: path('M 0 0 L 200 64 L 0 128 Z');
}

.shape-triangle {
  /* shape()ならパーセンテージが使える */
  clip-path: shape(from 0% 0%, line to 100% 50%, line to 0% 100%, close);
}
```

`path()`の座標は固定のピクセル値なので要素の大きさに追従せず、`shape()`の座標は要素の幅と高さに追従します。

<PlaygroundEmbed demo="path()とshape()の比較" headingLevel="h4" sectionId="shape-function" />

スライダーで幅を変えても、`path()`の三角形は幅200pxのままで、枠が200pxより狭くなると先が切れて台形になります。`shape()`の三角形は、幅に合わせて伸び縮みします。

## おわりに

`shape()`を使うと、`%`や`calc()`、CSS変数を座標に使って、要素の大きさに追従する曲線のある図形をCSSだけで描けます。`path()`の固定のピクセル値では合わせられなかった図形を、`line`や`curve`、`arc`のコマンドを組み合わせて描きます。
