# scrollendイベントでスクロール終了を検知する

<BrowserSupportStatus featureId="scrollend"></BrowserSupportStatus>

## はじめに

`scrollend`イベントは、スクロールが止まったときに1回だけ発火するイベントです。指やホイール、キーボードでのスクロールでも、`scrollTo()`やscroll-snapによる移動でも、位置が動き終わった時点で届きます。Safari 26.2が対応して、Baseline 2025に入りました。

スクロール中の位置に合わせて表示を変えるときは、`scroll`イベントを使います。一方で、止まった位置をURLに反映するといった、止まったときに1回だけ行う処理には、終了を知らせるイベントがありませんでした。`scroll`イベントから、止まったころあいを推し量るしかありませんでした。

```html
<div id="list" style="height: 120px; overflow: auto">
  <div style="height: 1000px">スクロールしてください</div>
</div>
<script>
  const list = document.getElementById('list');
  list.addEventListener('scrollend', () => {
    console.log('止まった位置', list.scrollTop);
  });
</script>
```

枠の中をスクロールして止めると、止まったところでコンソールに位置が出ます。

## setTimeoutで推し量る書き方

これまでは、`scroll`イベントと`setTimeout`を組み合わせて、スクロールの終わりを推し量っていました。

```ts
let scrollTimeout;

element.addEventListener('scroll', () => {
  // 前回のタイマーをクリア
  clearTimeout(scrollTimeout);

  // 一定時間後にスクロール終了と判定
  scrollTimeout = setTimeout(() => {
    console.log('スクロールが終了しました');
  }, 150);
});
```

待つ時間を短くすると、スクロールの途中で終わったと判定し、長くすると反応が遅れます。指とホイールではスクロールの動き方が違うので、ちょうどよい時間は入力の仕方でも変わります。指で押さえたまま動きを止めると、`scroll`イベントが途切れてタイマーが切れ、まだ指を離していないのに終わったと判定します。

## scrollendイベント

`scrollend`イベントなら、スクロールが終わったかをブラウザが判定します。指で操作しているときは、指を離して慣性のスクロールも止まってから届きます。

```javascript
// [!og]
element.addEventListener('scrollend', () => {
  console.log('スクロールが終了しました');
});
```

待つ時間を決める必要はありません。

### 発火条件

`scrollend`イベントは、指やホイール、キーボードでのスクロールが終わったときに発火します。`scrollTo()`や`scrollBy()`による移動や、scroll-snapでスナップ位置へ動き終わったときにも発火します。スクロール位置が変わらなかったときは発火しません。

<PlaygroundEmbed demo="発火条件" headingLevel="h5" sectionId="scrollend" />

要素の`scrollTo({ top: 500, behavior: 'smooth' })`を呼ぶと、`scroll`イベントは何度も届き、`scrollend`イベントは止まったときに1回だけ届きます。`scrollTop`に続けて3回代入したときも、`scroll`と`scrollend`は1回ずつです。すでにその位置にいるときの`scrollTo()`では、どちらも発火しません。

要素の`scrollend`イベントはバブリングしません。`document`に登録したリスナーには、要素のスクロールの`scrollend`イベントは届かず、ページ全体のスクロールのものだけが届きます。要素のスクロールを見るなら、その要素に登録します。

### 止まった位置をURLに残す

scroll-snapで1枚ずつ止まるカルーセルなら、`scrollend`イベントで何枚目に止まったかを求め、URLのハッシュに残せます。

```js
const carousel = document.querySelector('.carousel');

carousel.addEventListener('scrollend', () => {
  const index = Math.round(carousel.scrollLeft / carousel.clientWidth);
  history.replaceState(null, '', `#slide-${index + 1}`);
});
```

```css
.carousel {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
}

.carousel > * {
  flex: 0 0 100%;
  scroll-snap-align: start;
}
```

幅200pxのカルーセルを`scrollTo({ left: 130 })`で途中の位置へ動かすと、`scrollend`イベントはスナップし終えた200pxの位置で1回だけ届き、ハッシュは`#slide-2`になります。

## おわりに

`scrollend`イベントを使うと、`setTimeout`で待つ時間を決めずに、スクロールが止まったときに1回だけ処理を走らせられます。要素のスクロールを見るときは、`document`ではなくその要素にリスナーを登録します。
