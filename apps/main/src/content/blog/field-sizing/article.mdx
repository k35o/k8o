# field-sizingでtextareaの高さを内容に合わせる

<BrowserSupportStatus featureId="field-sizing" />

## はじめに

`field-sizing`は、`input`や`textarea`、`select`の大きさを、入力された内容に合わせて伸び縮みさせるかを決めるCSSプロパティです。`field-sizing: content`を指定すると、改行するたびに`textarea`の高さが伸び、文字を打つたびに`input`の幅が広がります。Firefox 152が対応して、Baseline 2026に入りました。

大きさが決まっている入力欄は、`width`や`rows`で大きさを決めます。入力に合わせて伸ばしたいときは、これまで`input`イベントで`scrollHeight`を読んで`height`を書き換えるJavaScriptが要りました。`field-sizing: content`なら、その処理をCSSだけで書けます。

## デモ

```css demo="content-fixed"
.content {
  input,
  textarea,
  select {
    field-sizing: content;
  }
}

textarea {
  max-height: 10lh;
}

input,
textarea,
select {
  max-width: 100%;
  box-sizing: border-box;
}

label {
  display: block;
  margin-block-end: 0.5rem;
}
```

```html demo="content-fixed"

    <option>fixed</option>
  </select>
</label>
<div id="fields" class="content">

    テキスト入力
    <input type="text" value="短いテキスト" />
  </label>

```

```js demo="content-fixed"
const fields = document.querySelector('#fields');

  fields.className = event.target.value;

```

`content`のまま、テキストエリアで改行すると高さが伸び、セレクトボックスで選択肢を選ぶと幅がその選択肢に合います。`fixed`に切り替えると、どのコントロールも入力に関わらず大きさが変わらなくなります。

## textareaの高さを内容に合わせる

`textarea`の高さを入力に合わせたいときは、幅を決めて、高さだけを内容に追従させます。高さの範囲は`min-height`と`max-height`で決めます。`lh`単位を使うと、行数で書けます。

```css
textarea {
  field-sizing: content;
  width: 100%;
  min-height: 3lh;
  max-height: 10lh;
}
```

空のときは3行分の高さで表示され、改行するたびに1行ずつ伸び、10行分に達するとそれ以上は伸びずにスクロールバーが出ます。`content`では`rows`属性が効かないので、初期の高さは`min-height`で決めます。

幅を決めていない`textarea`は、改行するまで横に伸び続けます。幅を指定せず`height`だけを固定した`textarea`に、文字サイズ16pxで全角25文字を入れると、折り返さずに幅が約400pxまで広がります。高さを内容に合わせる用途では、幅を先に決めておきます。

## field-sizingの値

`field-sizing`が取る値は`fixed`と`content`の2つです。

```css
input {
  /* [!callout: 既定値。最初に決まったサイズで固定される] */
  field-sizing: fixed;
}

input {
  /* [!callout: 入力内容に合わせてサイズが変わる] */
  field-sizing: content;
}
```

`fixed`が既定値で、これまでどおりの大きさで表示されます。`content`を指定すると、コントロールが内容を包むように縮み、テキストが増えると広がります。

## 対象となる要素

`field-sizing`が効くのは、内容に関わらず決まった大きさで表示されるフォームコントロールです。

- `type`が`text`や`email`、`number`のような、テキストを直接入力する`input`
- `file`の`input`
- `textarea`
- `select`

`textarea`は、幅の上限に達するまでは1行のまま横に伸び、上限に達すると行が増えて高さが伸びます。高さの上限にも達すると、スクロールバーが出ます。ドロップダウンの`select`は、選んでいる選択肢の幅に合います。選択肢が7つの`multiple`の`select`なら、`fixed`では4つ分ほどの高さでスクロールしますが、`content`では7つすべてが見える高さになります。

`file`の`input`は、ブラウザによって結果が分かれます。Chromeでは`content`にすると選んだファイル名に合わせて幅が変わり、Safariでは`content`にしても幅が変わりません。Firefoxでは`fixed`のままでもファイル名に合わせて幅が変わります。`file`の`input`の幅は、`field-sizing`ではブラウザの間でそろいません。

## min/maxと組み合わせる

`field-sizing: content`だけを指定すると、`input`は最小でテキストカーソルの幅まで縮みます。`min-width`と`max-width`で、伸び縮みの範囲を決めておきます。

```css
/* [!og] */
input {
  field-sizing: content;
  min-width: 8rem;
  max-width: 20rem;
}
```

`placeholder`を指定した`input`は、値が空のあいだはプレースホルダー全体が見える幅で表示されます。フォーカスしても幅は変わらず、1文字入れた時点で内容の幅まで縮みます。上の例なら`min-width`の8remが下限になるので、短い値で細くなりすぎることはありません。

`width`や`height`を固定値で指定すると、その軸は内容に追従しなくなります。止まるのは固定した軸だけで、幅を固定した`textarea`では高さが内容に追従します。

固定値の`width`のほかに、レイアウトの側でコントロールが幅いっぱいに引き伸ばされる場合も、内容に合わせて縮みません。たとえば`flex-direction: column`のFlexアイテムやGridアイテムは、既定でコンテナの幅まで広がります。引き伸ばしを止めれば`field-sizing: content`が効くので、コントロールの側で`align-self`（Flex）や`justify-self`（Grid）を`start`にします。

## 属性との関係

`field-sizing: content`を指定すると、大きさに関わる一部の属性は効かなくなります。`input`の`size`と、`textarea`の`rows`と`cols`は、どれも既定の大きさを決める属性なので、大きさが内容に合わせて変わる`content`では効きません。`rows="8"`の`textarea`は空のとき1行分の高さになり、`size="40"`の`input`も空のときは数pxの幅まで縮みます。

伸びる上限を内容の側から決めたいときは、`maxlength`が使えます。文字数の上限に達すると、コントロールはそれ以上大きくなりません。

```html
<input type="tel" maxlength="15" />
```

## おわりに

`textarea`の高さをJavaScriptで調整していた処理は、幅を決めて`field-sizing: content`と`min-height`、`max-height`を組み合わせれば、CSSだけで書けます。`input`の幅を内容に合わせるときは、`min-width`と`max-width`で伸び縮みの範囲を決めます。
