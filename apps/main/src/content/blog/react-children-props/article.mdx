# Reactのchildrenにpropsを渡す方法

## はじめに

`children`は、コンポーネントのタグの間に書いた要素を受け取るpropsです。TypeScriptでは、propsの型を`PropsWithChildren`で包むと`children`の型（`ReactNode`）が足されます。

`children`として受け取った要素に、親コンポーネントからpropsを渡したいことがあります。たとえば、受け取ったボタンに親が`onClick`を足したい場面です。呼び出し側で`children`の要素にpropsを書けるなら、それで足ります。親が持つ値や関数を、呼び出し側を通さずに`children`へ渡したいときに、この記事の方法が要ります。

```tsx
import { FC, PropsWithChildren } from 'react';

const ParentComponent: FC<PropsWithChildren> = ({
  children,
}) => (
  <div>
    {/* childrenにonClick等のpropsを親から付与したい */}
    {children}
  </div>
);
```

この記事では、これを実現する2つの方法を紹介します。

## cloneElement

最初に紹介する方法は`cloneElement`です。`cloneElement`は対象の`ReactElement`を複製する際に、第2引数で`props`を上書きできます。
子コンポーネントに`onClick`を付与する例は以下のようになります。

```tsx
import { cloneElement, FC, isValidElement, PropsWithChildren } from 'react';

const ParentComponent: FC<PropsWithChildren> = ({ children }) => {
  const cloneChildren = cloneElement(
    isValidElement(children) ? children : <button>{children}</button>,
    {
      onClick: () => alert('親から付与されたclickイベントです。'),
    }
  );

  return <div>{cloneChildren}</div>;
};
```

`cloneElement`の第1引数は`ReactElement`を渡したいので、`ReactNode`から`isValidElement`を用いて`ReactElement`を抽出しました。
`children`が`ReactElement`ではなかった場合は`button`要素で囲んだものを渡すようにしています。

`<ParentComponent><button>押す</button></ParentComponent>`と書くと、ボタンを押したときに親のアラートが出ます。`<ParentComponent>押す</ParentComponent>`のように文字列を渡すと、`<button>押す</button>`として描かれます。

第2引数には上書きしたい`props`をオブジェクトで渡します。上書きされるのは第2引数に渡したキーだけで、`children`が元々持っていたほかの`props`は残ります。React 19.3.1で`className`と`type`と`onClick`を持つ`button`要素を複製し、`onClick`だけを渡すと、`className`と`type`は残りました（Node.js 26.13.0の`renderToStaticMarkup`で確認）。ただし、`children`が`onClick`を持っていた場合、その`onClick`は親の`onClick`に置き換わって呼ばれなくなります。
子の`onClick`も呼びたい場合は、`isValidElement`の型引数で`props`の型を決め、親の`onClick`の中から子の`onClick`を呼びます。

```tsx
const onClick = () => alert('親から付与されたclickイベントです。');
const cloneChildren = isValidElement<{ onClick?: () => void }>(children)
  ? cloneElement(children, {
      onClick: () => {
        // 子のonClickも呼ぶ
        children.props.onClick?.();
        onClick();
      },
    })
  : <button onClick={onClick}>{children}</button>;
```

`@types/react` 19の`isValidElement`は、型引数を省くと`props`の型が`unknown`になります。`...children.props`のように広げると、`Spread types may only be created from object types.`という型エラーになります。

### Slotで隠蔽する

`cloneElement`はレガシーAPIですが、[Radix Primitives](https://www.radix-ui.com/primitives)が提供する[`Slot`](https://www.radix-ui.com/primitives/docs/utilities/slot)コンポーネントを使うことで、アプリケーションコードから直接呼び出すことを避けられます。

`Slot`は内部で`cloneElement`を使用していますが、より宣言的なAPIを提供します。

```tsx
import { Slot } from '@radix-ui/react-slot';
import { FC, PropsWithChildren } from 'react';

const ParentComponent: FC<PropsWithChildren> = ({ children }) => {
  return (
    <Slot onClick={() => alert('親から付与されたclickイベントです。')}>
      {children}
    </Slot>
  );
};
```

`Slot`は子要素に自身の`props`をマージして渡します。これにより、`cloneElement`を直接使用するよりも可読性が高いコードを書けます。

`@radix-ui/react-slot` 1.5.0で試すと、マージの決まりはpropsによって違いました。`onClick`のようなイベントハンドラーは、子のものと`Slot`のものが子、`Slot`の順に両方呼ばれます。`className`はつながり、`style`は合わさり、それ以外のpropsは子の値が残ります。`cloneElement`と違って子の`onClick`が消えないので、上の両方を呼ぶコードは要りません。

`children`に文字列だけを渡すと、`Slot failed to slot onto its children.`というエラーになります。`Slot`の`children`には要素を1つだけ渡します。

## render propパターン

続いては[render propパターン](https://ja.react.dev/reference/react/cloneElement#passing-data-with-a-render-prop)と呼ばれる`props`を利用した実装です。
親コンポーネントは`renderItem`という関数を`props`として受け取り、渡したい`props`を引数にしてその関数を呼び出します。

```tsx
import { FC, ReactElement } from 'react';

type Props = {
  renderItem: (props: { onClick: () => void }) => ReactElement;
};

const ParentComponent: FC<Props> = ({ renderItem }) => {
  return (
    <div>
      {renderItem({
        onClick: () => alert('親から付与されたclickイベントです。'),
      })}
    </div>
  );
};
```

`renderItem`は`props`を引数に取り、`ReactElement`を返す関数です。利用側は受け取った`props`を要素に適用して返します。

```tsx
<ParentComponent
  renderItem={(props) => (
    <button {...props}>
      親コンポーネントから渡ってきたonClickを付与したbutton要素
    </button>
  )}
/>
```

この方法では指定したい`props`を子コンポーネント側に明示的に渡せることや子コンポーネントの実装を自身でハンドリングできるところに利点があります。

## おわりに

この記事では、`children`にpropsを渡す方法として`cloneElement`とrender propパターンを紹介しました。

`cloneElement`はレガシーAPIのため、新しく実装するなら、型安全で明示的なrender propパターンをおすすめします。`children`を受け取る形を保ちたいときは、`cloneElement`を直接使用せずに`@radix-ui/react-slot`の`Slot`で隠蔽してください。
