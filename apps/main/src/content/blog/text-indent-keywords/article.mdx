# text-indentのhangingで2行目以降をインデントする

## はじめに

`text-indent`は、段落の1行目の先頭に字下げを入れるCSSプロパティです。値に`hanging`を付けると字下げする行が反転して2行目以降が下がり、`each-line`を付けると`<br>`で改行した後の行も1行目と同じように下がります。

段落の1行目を下げるだけなら、今までどおり`text-indent: 2em`のように長さだけを書けば足ります。2行目以降を下げるぶら下げインデントは、これまで`padding-left`と負の`text-indent`を組み合わせて書いていましたが、`hanging`なら値1つで書けます。要素を分けずに、`<br>`や改行文字で区切った行ごとに字下げするのは、`each-line`でしかできません。

Chrome 146が対応して、`each-line`と`hanging`はどちらもBaseline 2026に入りました。

## each-lineキーワード

<BrowserSupportStatus featureId="text-indent-each-line"></BrowserSupportStatus>

`each-line`を付けると、1行目に加えて`<br>`で改行した後の行も下がりますが、幅に収まらずに折り返した行は下がりません。

```css
p {
  text-indent: 2em each-line;
}
```

`<br>`のほかに、`white-space: pre-line`で残した改行文字の後の行も下がるので、フォームに入力された改行入りの文章をそのまま表示するときも、段落ごとに字下げできます。

```css
.comment {
  white-space: pre-line;
  text-indent: 1em each-line;
}
```

## hangingキーワード

<BrowserSupportStatus featureId="text-indent-hanging"></BrowserSupportStatus>

`hanging`を付けると、1行目は左端のままで、2行目以降のすべての行が下がります。

```css
p {
  text-indent: 2em hanging;
}
```

ぶら下げインデントと呼ばれる組み方で、参考文献や用語集のように1行目を目立たせたいときに使います。これまでの`padding-left: 2em; text-indent: -2em;`から置き換えても、行の位置は変わりません。

`※`で始まる注記なら、`※`の幅の1emだけ下げると、2行目以降が`※`の後ろの文字と揃います。

```css
.note {
  text-indent: 1em hanging;
}
```

ただし、`※`が1emの幅になるのは日本語のフォントで描いたときです。`lang="ja"`の無いページでは、ブラウザの言語の設定によって`※`が日本語ではないフォントで半分ほどの幅に描かれ、2行目以降の頭とずれます。`<html lang="ja">`を書いておけば、日本語のフォントで描かれて揃います。

## キーワードの組み合わせ

`each-line`と`hanging`を組み合わせると、1行目と`<br>`で改行した直後の行が左端に出て、それ以外の行が下がります。

```css
/* [!og] */
p {
  text-indent: 2em hanging each-line;
}
```

キーワードと長さは順番を問わず、`2em each-line hanging`や`hanging 2em`とも書けます。

## おわりに

ぶら下げインデントは`hanging`を付けた値1つで書け、`<br>`や改行文字で区切った段落ごとの字下げは`each-line`で付けられます。参考文献や注記、フォームに入力された文章の表示に使ってみてください。
