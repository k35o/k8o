# text-indentのhangingで2行目以降をインデントする

## はじめに

`text-indent`は、段落の1行目の先頭に字下げを入れるCSSプロパティです。値に`hanging`を付けると字下げする行が反転して2行目以降が下がり、`each-line`を付けると`<br>`で改行した後の行も1行目と同じように下がります。

段落の1行目を下げるだけなら、今までどおり長さだけを書けば足ります。2行目以降を下げるぶら下げインデントは、これまで`padding-left`と負の`text-indent`を組み合わせて書いていましたが、`hanging`なら値1つで書けます。要素を分けずに、`<br>`や改行文字で区切った行ごとに字下げするのは、`each-line`でしかできません。

Chrome 146のリリースにより、`each-line`と`hanging`の2つのキーワードが主要ブラウザすべてで利用可能になりBaseline 2026に加わりました。

インデント量を選び、`each-line`や`hanging`にチェックを入れると、`<br>`で区切った3つの段落の字下げが変わります。`hanging`だけを入れると、左端に出るのは全体の1行目だけで、`<br>`の後の行も下がります。`each-line`も入れると、`<br>`で区切った段落ごとに1行目が左端に出るぶら下げインデントになります。

## text-indentプロパティのおさらい

`text-indent`プロパティは、ブロックコンテナの最初の行の先頭にインデント（字下げ）を追加します。

```css
p {
  text-indent: 2em;
}
```

この指定では、段落の最初の行だけが2em分インデントされます。

## each-lineキーワード

<BrowserSupportStatus featureId="text-indent-each-line"></BrowserSupportStatus>

`each-line`キーワードを指定すると、最初の行に加えて`<br>`などによる改行の後の各行にもインデントが適用されます。
自動折り返しによる改行には適用されません。

```css
p {
  text-indent: 2em each-line;
}
```

これにより、`<br>`で区切られた各段落の先頭にインデントが入るようになります。

`<br>`のほかに、`white-space: pre-line`で残した改行文字の後の行も下がります。Chrome 156、Safari 27.2、Firefox 159で試すと、改行文字で区切った段落ごとに、`<br>`で区切ったときと同じく1行目だけが下がりました。フォームに入力された改行入りの文章をそのまま表示するときに、段落ごとの字下げを付けられます。

```css
.comment {
  white-space: pre-line;
  text-indent: 1em each-line;
}
```

## hangingキーワード

<BrowserSupportStatus featureId="text-indent-hanging"></BrowserSupportStatus>

`hanging`キーワードはインデントの対象を反転させます。
通常は最初の行だけがインデントされますが、`hanging`を指定すると最初の行以外のすべての行がインデントされます。

```css
p {
  text-indent: 2em hanging;
}
```

いわゆるぶら下げインデントと呼ばれるレイアウトで、参考文献リストや用語集などで最初の行を目立たせたい場合に活用できます。

これまでの`padding-left: 2em; text-indent: -2em;`と見た目は変わりません。Chrome 156、Safari 27.2、Firefox 159で両方の書き方の行の位置を比べると、どちらも1行目が左端、2行目以降が2em（32px）の位置に並びました。

`※`で始まる注記なら、`※`の幅の1emだけ下げると、2行目以降が`※`の後ろの文字と揃います。

```css
.note {
  text-indent: 1em hanging;
}
```

ただし、`※`が1emの幅で描かれるのは日本語のフォントのときです。`lang="ja"`の無いページでは、Chrome 156とSafari 27.2で`※`の幅が16pxの文字に対して9pxほどになり、2行目以降の頭とずれました（Firefox 159は16px）。`<html lang="ja">`を書いておけば、3つのブラウザとも揃いました。

## キーワードの組み合わせ

`each-line`と`hanging`は組み合わせて使用できます。

```css
/* [!og] */
p {
  text-indent: 2em hanging each-line;
}
```

この場合、最初の行と`<br>`による改行直後の行以外のすべての行にインデントが適用されます。

キーワードと長さは順番を問いません。Chrome 156、Safari 27.2、Firefox 159のいずれでも、`CSS.supports()`は`2em each-line hanging`や`hanging 2em`にも`true`を返しました。

## おわりに

`text-indent`の`each-line`と`hanging`キーワードを紹介しました。

従来、ぶら下げインデントを実現するには`padding-left`と`text-indent`の負の値を組み合わせるなどのテクニックが必要でした。
`hanging`キーワードにより、意図が明確なシンプルな記述で同じレイアウトを実現できるようになりました。
`each-line`は、`<br>`や改行文字で区切った段落ごとに字下げしたいときに使います。
