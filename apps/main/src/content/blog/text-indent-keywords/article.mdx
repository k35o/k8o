# text-indentのhangingで2行目以降をインデントする

## はじめに

`text-indent`は、段落の1行目の先頭に字下げを入れるCSSプロパティです。値に`hanging`を付けると字下げする行が反転して2行目以降が下がり、`each-line`を付けると`<br>`で改行した後の行も1行目と同じように下がります。

段落の1行目を下げるときは、`text-indent: 2em`のように長さだけを書きます。2行目以降を下げるぶら下げインデントは、これまで`padding-left`と負の`text-indent`を組み合わせて書いていましたが、`hanging`なら値1つで書けます。要素を分けずに、`<br>`や改行文字で区切った行ごとに字下げするのは、`each-line`でしかできません。

Chrome 146が対応して、`each-line`と`hanging`はどちらもBaseline 2026に入りました。

## each-lineキーワード

<BrowserSupportStatus featureId="text-indent-each-line"></BrowserSupportStatus>

`each-line`を付けると、1行目に加えて、`<br>`や`white-space: pre-line`で残した改行文字の後の行も下がります。フォームに入力された改行入りの文章をそのまま表示するときに、段落ごとに字下げできます。

```css
.comment {
  white-space: pre-line;
  text-indent: 1em each-line;
}
```

<EachLineExample />

改行で区切った段落ごとに1行目が1文字下がり、折り返した行は左端から始まります。

## hangingキーワード

<BrowserSupportStatus featureId="text-indent-hanging"></BrowserSupportStatus>

`hanging`を付けると、1行目は左端のままで、2行目以降のすべての行が下がります。ぶら下げインデントと呼ばれる組み方で、参考文献や用語集、注記のように1行目の頭を目立たせたいときに使います。

下げる幅は`text-indent`に書いた長さで決まります。日本語のフォントでは全角の文字が1文字1emの幅で描かれるので、頭の記号の文字数と同じemを書くと、2行目以降が記号の次の文字と揃います。`※`は1文字なので1em、`注：`は2文字なので2emを書きます。

```css
.note {
  text-indent: 1em hanging;
}
```

<HangingExample />

2行目以降の頭が`※`の次の文字と揃い、これまでの`padding-left: 1em; text-indent: -1em;`で書いたときと同じ位置に並びます。

## キーワードの組み合わせ

`each-line`と`hanging`を組み合わせると、1行目と改行した直後の行が左端に出て、それ以外の行が下がります。改行で区切って入力された注記を、1つずつぶら下げて表示できます。

```css
/* [!og] */
.notes {
  white-space: pre-line;
  text-indent: 1em hanging each-line;
}
```

<HangingEachLineExample />

注記ごとに`※`が左端に出て、折り返した行は`※`の次の文字と揃います。キーワードと長さは順番を問わず、`each-line 1em hanging`や`hanging 1em`とも書けます。

## おわりに

ぶら下げインデントは`hanging`を付けた値1つで書け、`<br>`や改行文字で区切った段落ごとの字下げは`each-line`で付けられます。参考文献や注記、フォームに入力された文章の表示に使ってみてください。
