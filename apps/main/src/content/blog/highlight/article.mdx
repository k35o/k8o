# CSS Custom Highlight APIでテキストをハイライト

<BrowserSupportStatus featureId="highlight" />

## はじめに

`CSS Custom Highlight API`は、JavaScriptの`Range`で指定した文字列の範囲に、CSSの`::highlight()`で色を付けるAPIです。DOMに要素を足さずに、ページ内の検索語やスペルミスをハイライトできます。Firefox 149が対応して、Baseline 2026に入りました。

決まった文字列を強調するだけなら、HTMLに`<mark>`を書けば足り、ユーザーが選んだ範囲は`::selection`で装飾できます。しかし、検索語のように実行時に決まる範囲を`<mark>`で囲むには、テキストノードを分けてDOMを書き換える必要があり、`<b>`などの要素をまたぐ範囲は1つの`<mark>`では囲めません。DOMに手を触れずに任意の範囲を装飾できるのは、このAPIだけです。

## CSS Custom Highlight APIとは

`CSS Custom Highlight API`では、ハイライトする範囲を`Range`で表し、範囲のまとまりを`Highlight`にして、`CSS.highlights`に名前を付けて登録します。登録した名前を`::highlight()`に渡すと、その範囲を装飾できます。`::selection`や`::target-text`のように、ブラウザが決めた範囲を装飾する擬似要素を、JavaScriptで決めた範囲にも使えるようにしたものです。

デモでは、文の後半の6文字（これ知るなり）だけに背景色が付きます。ハイライトしても`<p>`の子はテキストノード1つのままで、要素は増えません。

### 特徴

- DOMを書き換えずに、任意のテキストの範囲をハイライトできる
- JavaScriptから、ハイライトを足したり、変えたり、消したりできる
- 重なったハイライトの優先度を決められる
- 支援技術に、ハイライトの意味（スペルミスなど）を伝えられる

## 利用方法

まず、`Range`オブジェクトで、ハイライトしたいテキストの範囲を決めます。

```ts
// ハイライトするテキストを持つ要素の、中のテキストノードを取得
const textNode = document.getElementById('target-text')!.firstChild!;

// Rangeオブジェクトを作成
const range = new Range();

// テキストノードの開始位置と終了位置を設定（例では最初の2文字）
range.setStart(textNode, 0);
range.setEnd(textNode, 2);
```

`setStart`と`setEnd`に要素を渡すと、位置は文字ではなく子ノードの番号として数えられるので、子がテキストノード1つだけの要素に`setEnd(要素, 2)`を渡すと`IndexSizeError`になります。文字の位置で指定するには、テキストノードを渡します。

次に、`Range`から`Highlight`オブジェクトを作り、`CSS.highlights`（`HighlightRegistry`）に名前を付けて登録します。

```ts
// Highlightオブジェクトを作成
const highlight = new Highlight(range);

// HighlightRegistryにHighlightオブジェクトをmy-highlightとして登録
CSS.highlights.set('my-highlight', highlight);
```

最後に、`::highlight(my-highlight)`で、登録した範囲のスタイルを書きます。

```css
/* [!og] */
::highlight(my-highlight) {
  background-color: yellow;
  color: black;
}
```

これで、指定した範囲に背景色と文字色が付きます。

### 検索語をすべてハイライトする

ページ内の検索語をすべてハイライトするなら、`TreeWalker`でテキストノードをたどり、見つかった位置ごとに`Range`を作って1つの`Highlight`にまとめます。

```ts
function highlightAll(root: Node, word: string): void {
  const ranges: Range[] = [];
  const walker = document.createTreeWalker(root, NodeFilter.SHOW_TEXT);
  for (let node = walker.nextNode(); node; node = walker.nextNode()) {
    const text = node.textContent ?? '';
    for (let i = text.indexOf(word); i !== -1; i = text.indexOf(word, i + word.length)) {
      const range = new Range();
      range.setStart(node, i);
      range.setEnd(node, i + word.length);
      ranges.push(range);
    }
  }
  CSS.highlights.set('search', new Highlight(...ranges));
}

highlightAll(document.body, 'highlight');
```

色は`::highlight(search)`に書きます。消すときは`CSS.highlights.delete('search')`を呼ぶだけで、DOMを元に戻す処理は要りません。

```css
::highlight(search) {
  background-color: yellow;
  color: black;
}
```

2000段落にある4000か所をこの関数で登録すると、次の描画まではChromeで約30ms、Safariで約60ms、Firefoxで約33msでした。同じ箇所を`<mark>`で囲むと、それぞれ約330msと約550ms、約820msかかり、要素が4000個増えました。

## APIへの理解を深める

### Highlightオブジェクト

`Highlight`オブジェクトは、同じ見た目でハイライトする`Range`をまとめます。

#### オブジェクトの作成

`new Highlight()`に`Range`を渡して作ります。複数の`Range`を渡すと、1つのハイライトで複数の範囲を装飾できます。

```ts
const highlight = new Highlight(range1, range2, range3);
```

#### オブジェクト作成後の操作

作ったあとも、`Range`を足したり消したりできます。持っている`Range`の数は、`size`プロパティで分かります。

```ts
console.log(highlight.size); // 持っているRangeの数
highlight.add(newRange); // Rangeを足す
highlight.delete(range1); // 特定のRangeを消す
highlight.clear(); // すべてのRangeを消す
```

`Highlight`は`Range`だけを持つ`Set`のように振る舞い、`has`や`forEach`、`entries`のような`Set`のメソッドも使えます。

#### 優先度の設定

ハイライトが重なったときにどれを上に描くかは、`priority`プロパティで決めます。

```ts
const highPriorityHighlight = new Highlight(range1);
highPriorityHighlight.priority = 10;

const lowPriorityHighlight = new Highlight(range1);
lowPriorityHighlight.priority = 1;

const defaultPriorityHighlight = new Highlight(range1);

console.log(highPriorityHighlight.priority); // 10
console.log(lowPriorityHighlight.priority); // 1
console.log(defaultPriorityHighlight.priority); // 0
```

`priority`の既定は0で、上の例では`highPriorityHighlight`、`lowPriorityHighlight`、`defaultPriorityHighlight`の順に優先されます。

<PlaygroundEmbed demo="優先度ベースハイライト" headingLevel="h6" sectionId="highlight" />

上の例では、`Imagination`に優先度1の青と黄、優先度0の赤の3つのハイライトを、この順に登録しています。優先度が同じときは`CSS.highlights`に後から登録したほうが優先されるので、黄色で表示されます。

#### ハイライトの意味を指定

`type`プロパティには、ハイライトの意味を指定します。スクリーンリーダーのような支援技術は、この意味をハイライトと一緒にユーザーへ伝えられます。

```ts
const spellErrorHighlight = new Highlight(errorRange);
spellErrorHighlight.type = 'spelling-error';
```

値は、特別な意味の無い既定の`highlight`と、スペルミスを表す`spelling-error`、文法の誤りを表す`grammar-error`の3つです。

### HighlightRegistry

`HighlightRegistry`は、名前を付けた`Highlight`をまとめるオブジェクトで、`CSS.highlights`から使います。`Highlight`が`Set`のように振る舞うのに対して、`HighlightRegistry`は、ハイライトの名前をキー、`Highlight`を値にした`Map`のように振る舞います。

```ts
CSS.highlights.set('my-highlight', highlight); // Highlightオブジェクトを登録
CSS.highlights.get('my-highlight'); // Highlightオブジェクトを取得
CSS.highlights.has('my-highlight'); // Highlightオブジェクトが存在するか確認
CSS.highlights.delete('my-highlight'); // Highlightオブジェクトを削除
CSS.highlights.clear(); // すべてのHighlightオブジェクトを削除
```

`set`メソッドは`HighlightRegistry`自体を返すので、続けて呼べます。

```ts
CSS.highlights
  .set('my-highlight', highlight1)
  .set('another-highlight', highlight2);
```

### ::highlight擬似要素

`::highlight()`擬似要素は、`HighlightRegistry`に登録した名前のハイライトにスタイルを当てます。

```css
::highlight(my-highlight) {
  background-color: yellow;
  color: black;
}
```

使えるプロパティは、`color`と`background-color`、`text-decoration`、`text-shadow`などに限られます。`-webkit-`から始まる一部のプロパティも使えます。

## おわりに

`CSS Custom Highlight API`を使うと、検索語やスペルミスのように実行時に決まる範囲を、DOMを書き換えずに装飾できます。`<mark>`で囲む方法より速く、消すときにDOMを元に戻す処理も要らないので、ページ内検索のハイライトから使ってみてください。
