# View Transitionのtypesで進む・戻るの動きを変える

<BrowserSupportStatus featureId="active-view-transition"></BrowserSupportStatus>

## はじめに

`:active-view-transition-type()`は、`startViewTransition()`の`types`オプションで渡したタイプのView Transitionが進んでいる間だけ、ルート要素（`<html>`）に当たる疑似クラスです。同じView Transitionでも、進むと戻るのようにタイプごとに別のアニメーションを書き分けられます。Firefox 147が対応して、Baseline 2026に入りました。

アニメーションが1種類で済むなら、`::view-transition-old()`と`::view-transition-new()`に直接書けば足ります。進むと戻るで向きを変えるように遷移ごとにアニメーションを切り替えたい場合、これまでは遷移の前にJavaScriptで`<html>`へクラスを付け、終わったら外していました。`types`と`:active-view-transition-type()`を使うと、この付け外しをブラウザに任せられます。

View Transition APIそのものは、[View Transition APIの記事](/blog/view-transitions)で書いています。

## 進むと戻るで向きを変える

進むと戻るのボタンで、新しい画面が入ってくる向きを変える例です。

```html
<p id="page">1</p>
<button id="prev">戻る</button>
<button id="next">進む</button>

<style>
  @keyframes from-right { from { translate: 100% 0; } }
  @keyframes from-left { from { translate: -100% 0; } }

  html:active-view-transition-type(forwards)::view-transition-new(root) {
    animation: from-right 0.4s;
  }
  html:active-view-transition-type(backwards)::view-transition-new(root) {
    animation: from-left 0.4s;
  }
</style>

<script>
  const page = document.querySelector('#page');
  const go = (type, diff) => {
    document.startViewTransition({
      update: () => {
        page.textContent = Number(page.textContent) + diff;
      },
      types: [type],
    });
  };
  document.querySelector('#next').addEventListener('click', () => go('forwards', 1));
  document.querySelector('#prev').addEventListener('click', () => go('backwards', -1));
</script>
```

進むを押すと、数字の増えた新しい画面が右から滑り込みます。戻るを押すと、数字の減った画面が左から入ってきます。どのブラウザでも、進むと`::view-transition-new(root)`に`from-right`が、戻ると`from-left`が当たります。

当たるのはルート要素だけです。遷移の間に`.card:active-view-transition-type(forwards)`と`:active-view-transition-type(forwards) .card`の2つの書き方を試すと、どのブラウザでもスタイルが当たるのは後者だけです。ルートの外の要素を切り替えるときは、`html:active-view-transition-type(forwards) .card`のように子孫セレクタで書きます。

## タイプの設定方法

### 同一Document内（SPA）

```js
// [!og]
document.startViewTransition({
  update: () => {
    // DOMの更新処理
  },
  types: ['forwards'], // タイプを指定
});
```

返り値の`ViewTransition`の`types`は、`add()`や`delete()`を持つSetに似たオブジェクトです。遷移の途中に`forwards`を消して`backwards`を足すと、Chromeではその場で、Safariでは次の描画から、当たるアニメーションが`backwards`のものに切り替わります。Firefoxでは、`<html>`は`:active-view-transition-type(backwards)`に当たるのに、アニメーションは`forwards`のまま変わりません。

`startViewTransition`があるかだけを見ると、`types`を受け取らない古い実装（Chrome 124まで、Safari 18.1まで、Firefox 146まで）を見分けられません。デモでは、同時に実装された疑似クラスに対応しているかを`CSS.supports('selector(:active-view-transition-type(forwards))')`で確かめてから呼び、対応していなければアニメーションなしでDOMだけを書き換えています。Reactで状態を変えるときは、`update`の中の更新を`flushSync()`で包みます。`update`が終わった時点のDOMが新しい画面として撮られるからです。

### 異なるDocument間（MPA）

```css
@view-transition {
  navigation: auto;
  types: slide;
}
```

ページをまたぐ遷移では、移る前と後の両方のページのCSSに`@view-transition`を書きます。ChromeとSafariはこの規則を`CSSViewTransitionRule`として読み、`types`に`slide`が入ります。Firefoxは規則ごと読み捨てるので、ページをまたぐ遷移そのものが動きません。

## カードのアニメーションを書き分ける

進むと戻るで、カードに別のアニメーションを付ける例です。遷移の間だけカードに`view-transition-name`を付け、タイプごとに古いカードと新しいカードのアニメーションを書き分けます。

```css
/* カードのView Transition設定 */
html:active-view-transition {
  .card-content {
    view-transition-name: card;
  }
}

/* 進む：弾けて散る */
html:active-view-transition-type(forwards) {
  &::view-transition-old(card) {
    animation: 500ms ease-out explode-out;
  }
  &::view-transition-new(card) {
    animation: 500ms ease-out gather-in;
  }
}

/* 戻る：集まってくる */
html:active-view-transition-type(backwards) {
  &::view-transition-old(card) {
    animation: 500ms ease-out shrink-out;
  }
  &::view-transition-new(card) {
    animation: 500ms ease-out expand-in;
  }
}

@keyframes explode-out {
  0% { transform: scale(1) rotate(0deg); opacity: 1; }
  100% { transform: scale(1.5) rotate(10deg); opacity: 0; }
}
@keyframes gather-in {
  0% { transform: scale(0.3) rotate(-10deg); opacity: 0; }
  100% { transform: scale(1) rotate(0deg); opacity: 1; }
}
@keyframes shrink-out {
  0% { transform: scale(1) rotate(0deg); opacity: 1; }
  100% { transform: scale(0.3) rotate(-10deg); opacity: 0; }
}
@keyframes expand-in {
  0% { transform: scale(1.5) rotate(10deg); opacity: 0; }
  100% { transform: scale(1) rotate(0deg); opacity: 1; }
}
```

このデモでは、次のことを確かめられます。

- 進むを押すと、`:active-view-transition-type(forwards)`が当たり、古いカードが拡大しながら消えて、新しいカードが小さい状態から現れる
- 戻るを押すと、`:active-view-transition-type(backwards)`が当たり、古いカードが縮みながら消えて、新しいカードが大きい状態から収まる
- 左上の丸は`html:active-view-transition`で遷移の間だけ点く

## おわりに

`:active-view-transition-type()`を使うと、`<html>`のクラスを付け外しせずに、進むと戻るのように遷移のタイプごとにアニメーションを書き分けられます。同じDocumentの中の遷移ならどのブラウザでも`types`を渡せますが、ページをまたぐ遷移の`@view-transition`の`types`は、Firefoxでは動きません。
