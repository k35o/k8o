# caretPositionFromPointでクリック位置の文字を取得

<BrowserSupportStatus featureId="document-caretpositionfrompoint"></BrowserSupportStatus>

## はじめに

`document.caretPositionFromPoint`は、画面上の座標を渡すと、そこにキャレット（テキストカーソル）を置いたときのノードと文字の位置を返すメソッドです。クリックやドロップの座標が、テキストの何文字目にあたるかが分かります。Safari 26.2が対応して、Baseline 2025に入りました。

マウスを重ねただけのときやドロップしたときは、クリックと違って選択範囲が動きません。そうした座標の下の文字の位置は、このメソッドで求めます。

```js demo="click"
const output = document.querySelector('output');
document.querySelector('p').addEventListener('click', (event) => {
  const caretPosition = document.caretPositionFromPoint(
    event.clientX,
    event.clientY,
  );
  if (caretPosition?.offsetNode.nodeType !== Node.TEXT_NODE) return;

  const { offsetNode, offset } = caretPosition;
  const rect = caretPosition.getClientRect();
  // 文字の右半分を押すと、offset はその文字の後ろを指す
  const index = rect && event.clientX < rect.x ? offset - 1 : offset;
  output.textContent = `offset: ${offset}、クリックした文字: ${offsetNode.textContent[index]}`;
});
```

```html demo="click"
<p>吾輩は猫である。名前はまだ無い。どこで生れたかとんと見当がつかぬ。</p>
<output>文章の好きな文字をクリックしてください</output>
```

結果の欄で文字をクリックすると、`offset`とクリックした文字が出ます。文字の右半分を押すと`offset`はその文字の後ろを指すので、`getClientRect()`の`x`とクリックした`x`を比べ、クリックした点が左にあれば1つ前の文字を取っています。行の右の余白を押すと、文字は`undefined`になります。

## 引数と返り値

```ts
document.caretPositionFromPoint(x, y);
document.caretPositionFromPoint(x, y, options);
```

座標は`clientX`と`clientY`と同じビューポートの座標で、スクロールしたページで`pageY`を渡すと違う位置が返ります。返り値は`CaretPosition`オブジェクトで、座標がビューポートの外か負の値のときは`null`です。テキストの無い空の`div`の上では、`null`ではなくその`div`と0が返ります。

- `offsetNode`：キャレット位置を含むノード。ふつうはテキストノードで、`input`や`textarea`の上ではその要素になる
- `offset`：`offsetNode`の中の位置。テキストノードなら文字の位置、`input`や`textarea`なら`value`の中の文字の位置、それ以外の要素なら子ノードの位置
- `getClientRect()`：キャレットの立つ位置の矩形。テキストノードでは幅0で、高さは文字の高さほどになる

画像の上では、ChromeとSafariは親の要素と画像の位置を、Firefoxは`img`要素と0を返します。`offsetNode`が要素のとき、`getClientRect()`は`null`ではなく、`x`と`y`と幅と高さがすべて0の矩形を返します。Safariは、`input`と`textarea`の中を指したときも0の矩形を返します。

### Shadow DOMの中を指すとき

第3引数の`options`には、中の位置まで返してよいShadowRootを`shadowRoots`で渡せます。

```ts
const caretPosition = document.caretPositionFromPoint(x, y, {
  shadowRoots: [shadowRoot],
});
```

座標がShadow DOMの中を指すとき、そのShadowRootを渡していれば、中のテキストノードと文字の位置が返ります。渡していなければ、ホスト要素の親と、その中でのホスト要素の位置が返ります。たとえば`<div>before<span id="host"></span>after</div>`の`span`にShadow DOMを付けて中を指すと、渡さないときは`div`と1が返ります。閉じたShadow DOMでも、渡せば中の位置が返ります。

## ドロップした位置に文字を入れる

```js demo="drop"
const text = document.querySelector('#text');
for (const word of document.querySelectorAll('[draggable]')) {
  word.addEventListener('dragstart', (event) => {
    event.dataTransfer.setData('text/plain', word.textContent);
  });
}

const dropZone = document.querySelector('#drop-zone');
dropZone.addEventListener('dragover', (event) => event.preventDefault());
dropZone.addEventListener('drop', (event) => {
  event.preventDefault();
  const caretPosition = document.caretPositionFromPoint(
    event.clientX,
    event.clientY,
  );
  // ヒントの文の上に落としたときは入れない
  if (
    caretPosition?.offsetNode.nodeType !== Node.TEXT_NODE ||
    !text.contains(caretPosition.offsetNode)
  ) {
    return;
  }

  const word = event.dataTransfer.getData('text/plain');
  caretPosition.offsetNode.insertData(caretPosition.offset, word);
});
```

```html demo="drop"
<p>
  <span draggable="true">素敵な</span>
  <span draggable="true">可愛い</span>
  <span draggable="true">立派な</span>
</p>
<div id="drop-zone">
  <p id="text">吾輩は猫である。名前はまだ無い。</p>
  <p>上の単語をドラッグして、文章の好きな位置に落とす</p>
</div>
```

```css demo="drop"
[draggable] {
  padding: 0.25rem 0.5rem;
  border: 1px solid gray;
  border-radius: 0.25rem;
  cursor: grab;
}
#drop-zone {
  padding: 0 1rem;
  border: 1px dashed gray;
}
```

結果の欄で単語を文章の好きな位置へドラッグして落とすと、その位置に単語が入ります。ドロップ先の中にヒントの文のような別のテキストがあると、そこに落としたときはそのテキストノードに入るので、`offsetNode`が本文の要素の中にあるかを`contains()`で確かめています。

## おわりに

`document.caretPositionFromPoint`を使うと、座標からテキストの中の位置が分かり、クリックした文字を調べたり、ドロップした位置に文字を入れたりできます。似た名前の`caretRangeFromPoint`は仕様にないメソッドなので、新しく書くコードではこちらを使います。
