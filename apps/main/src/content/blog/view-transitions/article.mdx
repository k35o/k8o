# View Transitions APIでページ遷移をアニメーション

<BrowserSupportStatus featureId="view-transitions" />

<BrowserSupportStatus featureId="view-transition-class" />

## はじめに
View Transition API（View Transitions API）は、DOMを書き換える前の画面から後の画面へ、アニメーションで切り替えるAPIです。並び替えやSPAのページ遷移のように、DOMを書き換えて画面が変わる場面で使えます。Firefox 144が対応して、Baseline 2025に入りました。

1つの要素の色や大きさを変えるだけなら、CSSの`transition`で足ります。しかし、並び替えで要素の位置が変わったり、要素を足したり消したりする変化は、`transition`では動かせません。View Transition APIなら、こうした変化もアニメーションにできます。

```html
<button id="reverse">並びを逆にする</button>
<ul id="list">
  <li style="view-transition-name: a">A</li>
  <li style="view-transition-name: b">B</li>
  <li style="view-transition-name: c">C</li>
</ul>
<script>
  document.getElementById('reverse').addEventListener('click', () => {
    document.startViewTransition(() => {
      const list = document.getElementById('list');
      list.append(...[...list.children].reverse());
    });
  });
</script>
```

ボタンを押すと、AとCが互いの位置へ0.25秒かけて滑るように動きます。以下では、View Transition APIで動くアニメーションを遷移アニメーションと呼びます。

## startViewTransition
遷移アニメーションは、`document.startViewTransition()`にDOMを書き換える関数を渡して始めます。

```js
const reverseList = () => {
  const list = document.getElementById('list');
  list.append(...[...list.children].reverse());
};

document.startViewTransition(reverseList);
```

引数にオブジェクトを渡すと、DOMを書き換える関数を`update`に、遷移の種類を表す名前を`types`に書けます。種類ごとに、遷移アニメーションのスタイルを変えられます。

```js
// [!og]
document.startViewTransition({
  update: reverseList,
  types: ['reverse'],
});
```

`types`を渡した遷移の間は、ルート要素が`:active-view-transition-type()`に当たるので、種類ごとのスタイルはこの擬似クラスに続けて書きます。

```css
/* reverseの遷移だけ、1秒かけて動かす */
:root:active-view-transition-type(reverse)::view-transition-group(*) {
  animation-duration: 1s;
}
```

`startViewTransition`が返す`ViewTransition`オブジェクトは、遷移の進み具合を表す3つのPromiseを持ちます。`updateCallbackDone`、`ready`、`finished`の順に解決します。

```js
const transition = document.startViewTransition(reverseList);

transition.updateCallbackDone.then(() => {
  // DOMの書き換えが終わったら解決する
});

transition.ready.then(() => {
  // 遷移アニメーションが始まる直前に解決する
});

transition.finished.then(() => {
  // 遷移アニメーションが終わったら解決する
});
```

`skipTransition()`を呼ぶと、遷移アニメーションを飛ばして書き換えた後の画面にします。

```js
const transition = document.startViewTransition(reverseList);

const timeoutId = setTimeout(() => {
  // 1秒経ったら遷移アニメーションを飛ばす
  transition.skipTransition();
}, 1000);

transition.finished.then(() => {
  // 1秒より前に終わったら、飛ばす処理を取り消す
  clearTimeout(timeoutId);
});
```

## 関連するCSS
### view-transition-name
`view-transition-name`は、前と後の画面で同じ要素として扱う要素に付ける名前です。同じ名前を持つ要素どうしが、前の位置と大きさから後の位置と大きさへ動きます。はじめにの例では、`li`に`a`と`b`、`c`の名前を付けたので、並びを逆にするとAとCが入れ替わるように動きました。

初期値は`none`で、名前の無い要素は個別には動かず、画面全体の一部として切り替わります。ブラウザの既定のスタイルで、`:root`に`view-transition-name: root`が付いているためです。`:root`に`none`を指定すると画面全体が対象から外れ、名前を付けた要素だけが動きます。

同じ画面に同じ`view-transition-name`の要素が2つあると、遷移アニメーションは飛ばされます。DOMの書き換えは行われ、`ready`は`InvalidStateError`で拒否されます。リストの要素に名前を付けるときは、`item-1`のように要素ごとに違う名前にします。

### view-transition-class
`view-transition-class`は、名前の違う複数の要素に、遷移アニメーションのスタイルをまとめて当てるための分類です。

```css
li {
  view-transition-class: item;
}

::view-transition-group(.item) {
  animation-duration: 0.5s;
}
```

はじめにの例の`li`にこう書くと、`a`、`b`、`c`の3つの遷移がまとめて0.5秒になります。`::view-transition-group()`は、後で説明する擬似要素です。

### :active-view-transition
`:active-view-transition`擬似クラスは、遷移アニメーションが進んでいる間、文書のルート要素（`<html>`）に当たります。ほかの要素には当たらないので、遷移中のスタイルは`:root:active-view-transition`の子孫として書きます。

```css
/* 遷移中は、押せないことが伝わるようにボタンを薄く表示する */
:root:active-view-transition .transition-button {
  opacity: 0.8;
}
```

### 遷移アニメーションの擬似要素
遷移アニメーションの間、ページの上には次の擬似要素が、上から順に入れ子になって重なります。括弧の中には、`view-transition-name`の名前か、`.`から始まる`view-transition-class`の名前を書きます。名前の無い要素をまとめた`root`と、すべてを表す`*`も使えます。

- `::view-transition`：ビューポート全体を覆う、すべての遷移の入れ物
- `::view-transition-group()`：名前ごとの入れ物で、前の位置と大きさから後の位置と大きさへ動く
- `::view-transition-image-pair()`：前と後の画像を重ねる入れ物
- `::view-transition-old()`と`::view-transition-new()`：前の画面と後の画面の画像。既定では、前の画像が消えながら後の画像が現れる

## おわりに
View Transition APIを使うと、`startViewTransition`でDOMを書き換えるだけで、画面の変化にアニメーションが付きます。動かす要素は`view-transition-name`で選び、動き方は`::view-transition-group()`などの擬似要素で変えられます。

`@view-transition`による別のページへ移るときの遷移がBaselineに入れば、複数のページからなるサイトでも同じアニメーションを付けられるようになります。その日が来るのを楽しみにしています。
