# Popover APIでツールチップやドロップダウンをJSなしで作る

<BrowserSupportStatus featureId="popover"></BrowserSupportStatus>

## はじめに

Popover APIは、`popover`属性を付けた要素を、`popovertarget`属性を付けたボタンで開閉するHTMLの仕組みです。開いた要素はほかの要素より手前に出て、外側のクリックやESCキーで閉じます。2025年にBaselineに入りました。

ページの流れの中で中身を開閉するだけなら、`details`要素で足ります。ツールチップやドロップダウンメニューのように、ほかの要素の上に重ねて出し、外側のクリックで閉じるUIは、これまでJavaScriptやライブラリで作っていました。Popover APIを使うと、重ねて出すことと閉じることを、HTMLの属性だけで書けます。

```html
<button popovertarget="hello">開く</button>
<div id="hello" popover>外側をクリックするかESCキーで閉じます</div>
```

ボタンを押すと、画面の中央に枠の付いた箱が出ます。外側をクリックするか、ESCキーを押すか、もう一度ボタンを押すと閉じます。

## Popover APIの全体像

Popover APIで作ったポップオーバーは、次の性質を持ちます。

- 外側をクリックすると閉じる
- ESCキーを押すと閉じる
- 中の要素に`autofocus`を付けておくと、開いたときにそこへフォーカスが移る
- Top layer（重ね合わせコンテキストの最上位のレイヤー）に置かれる

`autofocus`が無いときは、開いてもフォーカスはポップオーバーを開いたボタンに残ります。

Popover APIで使うのは、HTMLの`popover`と`popovertarget`、`popovertargetaction`の3つの属性と、CSSの`::backdrop`と`:popover-open`です。

### HTML属性

`popover`属性は、ポップオーバーとして出す要素に付けます。

```html
<p id="popover1" popover>ポップオーバーで表示されるコンテンツ</p>
```

値を書かないときは`auto`になります。値を`manual`にすると、ESCキーや外側のクリックでは閉じなくなるので、主にJavaScriptで開閉するときに使います。

ポップオーバーを開閉するボタンには`popovertarget`属性を付け、値にポップオーバーの要素の`id`を書きます。

```html
<!-- [!og] -->
<button popovertarget="popover1">
  ポップオーバーの表示を管理する要素
</button>
```

`popovertargetaction`属性は、ボタンを押したときにポップオーバーをどうするかを決めます。

```html
<button popovertarget="popover1" popovertargetaction="show">
  クリックでポップオーバーを表示
</button>
```

既定は開閉を切り替える`toggle`で、ほかに開くだけの`show`と、閉じるだけの`hide`があります。

### CSS機能

ポップオーバーの後ろには、画面全体を覆う`::backdrop`擬似要素が置かれます。これにスタイルを当てると、ポップオーバーの後ろを暗くできます。

```css
::backdrop {
  background-color: #00000080;
}
```

`::backdrop`はPopover APIだけのものではなく、`dialog`要素のようにTop layerに置かれる要素の背景にも使います。

`:popover-open`擬似クラスは、開いているポップオーバーに当たります。

```css
.popover:popover-open {
  min-width: 50vw;
}
```

### サンプル

次の例では、3つのボタンにそれぞれ別の`popovertargetaction`を付け、`:popover-open`と`@starting-style`で、開くときに少しずつ現れるようにしています。

<PlaygroundEmbed demo="基本的なポップオーバー" headingLevel="h5" sectionId="popover" />

```html
<div class="wrapper">
  <button popovertarget="popover1" popovertargetaction="toggle">
    popovertargetaction: toggle
  </button>
  <button popovertarget="popover1" popovertargetaction="show">
    popovertargetaction: show
  </button>
  <button popovertarget="popover1" popovertargetaction="hide">
    popovertargetaction: hide
  </button>
</div>
<p id="popover1" popover>
  このポップオーバーはPopover APIによって表示されました。
  ESCキーやこのコンテンツの外側のクリック、toggleまたはhideボタンで閉じられます。
</p>
```

```css
.wrapper {
  display: flex;
  flex-wrap: wrap;
  gap: 2rem;
}

#popover1 {
  border-radius: 0.5rem;
  margin: auto;
  padding: 1rem;
  max-width: calc(1 / 3 * 100%);
  opacity: 0;
  transition: opacity 0.5s cubic-bezier(0.4, 0, 0.2, 1);
}

#popover1:popover-open {
  opacity: 1;
}

@starting-style {
  #popover1:popover-open {
    opacity: 0;
  }
}

::backdrop {
  background-color: #00000080;
}
```

## おわりに

Popover APIでは、ポップオーバーにする要素に`popover`属性を、開閉するボタンに`popovertarget`属性を付けるだけで、外側のクリックやESCキーで閉じるツールチップやドロップダウンメニューをJavaScriptなしで作れます。
