# RegExp.escapeで正規表現の特殊文字をエスケープする

<BrowserSupportStatus featureId="regexp-escape"></BrowserSupportStatus>

## はじめに

`RegExp.escape`は、文字列の中の正規表現の特殊文字をエスケープして返す静的メソッドです。ユーザーが入力した語句のように、中身の分からない文字列を`new RegExp()`に渡して、文字通りに検索するときに使います。Chrome 136が対応して、Baseline 2025に入りました。

文字列をそのまま探すときは、`includes()`や`indexOf()`、`replaceAll()`を使います。大文字と小文字を区別しない`i`フラグや、前後の文字の条件と組み合わせるときは、正規表現の中に文字列を埋め込むのでエスケープが要ります。これまでは`replace()`で特殊文字の前に`\`を付ける関数を書いていましたが、それでは防げない場合があります。

## RegExp.escape

`new RegExp(str)`に文字列をそのまま渡すと、文字列の中の特殊文字が正規表現の構文として読まれ、文字通りには検索できません。

```ts
const str = 'abc*';
const regexp = new RegExp(str);
console.log(regexp.test('abc')); // true
console.log(regexp.test('abc*')); // true
console.log(regexp.test('ab')); // true
```

`*`は直前の文字の0回以上の繰り返しを表す構文なので、この正規表現は`abc*`だけでなく、`abc`や`ab`にもマッチします。`RegExp.escape`でエスケープしてから渡すと、`abc*`という並びだけにマッチします。

```ts
// [!og]
const str = 'abc*';
// \x61bc\*
const escapedStr = RegExp.escape(str);
const regexp = new RegExp(escapedStr);
console.log(regexp.test('abc')); // false
console.log(regexp.test('abc*')); // true
console.log(regexp.test('ab')); // false
```

`abc*`は`\x61bc\*`に変換され、`ab`や`abc`にはマッチしません。

ユーザーが入力した語句を、大文字と小文字を区別せずに探して囲む例です。

```ts
const query = 'C++';
const text = 'c++とC++';
const regexp = new RegExp(RegExp.escape(query), 'gi');
console.log(text.replace(regexp, (match) => `[${match}]`)); // [c++]と[C++]
```

`new RegExp(query, 'gi')`のままでは、`+`が繰り返しの構文と読まれ、`SyntaxError`（nothing to repeat）になります。

### 変換の規則

#### 先頭の英数字

先ほどの例で、`RegExp.escape('abc*')`は`\x61bc\*`になりました。`*`が`\*`になるだけでなく、先頭の`a`も`\x61`に変わっています。

先頭の文字が数字か英字のときは、`\x`に続く16進数の文字コードに変換されます（`a`の文字コードは16進数で61なので`\x61`）。別の文字列の後ろにつないだときに、前の文字列と合わせて1つの構文として読まれないようにするためです。

```ts
const str = '0';
const regexp = new RegExp('(.)\\1' + str);
console.log(regexp.test('aa0')); // false
const escapedStr = RegExp.escape(str);
const escapedRegexp = new RegExp('(.)\\1' + escapedStr);
console.log(escapedRegexp.test('aa0')); // true
```

上の例では、`(.)\\1`の後ろに`0`を連結しています。`0`をエスケープしない場合、正規表現は`/(.)\10/`となり、`\10`がひとまとまりに読まれます。グループは1つしか無いので、`\10`は10番目のグループの後方参照にもならず、8進数のエスケープとしてU+0008（バックスペース）の1文字に解釈されます。そのため`aa0`にはマッチしません。`RegExp.escape`を使うと、`0`は`\x30`に変換され、正規表現は`/(.)\1\x30/`となります。1番目のグループの後方参照と`0`に分けて解釈されるので、意図した通りに`aa0`がマッチします。

特殊文字の前に`\`を付けるだけの手作りのエスケープでは、`0`は変わらないので、この例は`false`のままです。

```ts
const manualEscape = (str: string) => str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
console.log(new RegExp('(.)\\1' + manualEscape('0')).test('aa0')); // false
```

#### 特殊文字

正規表現の構文に使う記号（`^$\.*+?()[]{}|/`）は、前に`\`を付けてエスケープされます。構文として読まれないようにするためです。

```ts
const str = '^$\\.*+?()[]{}|/';
// \^\$\\\.\*\+\?\(\)\[\]\{\}\|\/
console.log(RegExp.escape(str));
```

カンマやハイフン、引用符などの記号は、`\x`に続く16進数の文字コードに変換されます。

```ts
const str = ',-=<>#&!%:;@~`"';
// \x2c\x2d\x3d\x3c\x3e\x23\x26\x21\x25\x3a\x3b\x40\x7e\x60\x22
console.log(RegExp.escape(str));
```

改行やタブのような制御文字は、`\n`や`\t`のように、正規表現で同じ文字を表すエスケープに変換されます。

```ts
const str = '\f\n\r\t\v';
// \f\n\r\t\v
console.log(RegExp.escape(str));
```

#### その他の文字

空白文字は、`\x`か`\u`に続く16進数の文字コードに変換されます。半角スペースは`\x20`、全角スペースは`\u3000`になります。タブは制御文字として扱われ、`\t`になります。

```ts
const str = '　';
// \u3000
console.log(RegExp.escape(str));
```

対になっていないサロゲート（孤立サロゲート）も、`\u`に続くUTF-16のコード単位に変換されます。文字列が孤立サロゲートを含むかは、`isWellFormed()`で確かめられます。

```ts
const str = 'ab\uD800 \uDFFFab';
// \x61b\ud800\x20\udfffab
console.log(RegExp.escape(str));
```

## おわりに

`RegExp.escape`を使うと、正規表現に埋め込む文字列を、構文として読まれない形に変換できます。特殊文字の前に`\`を付けるだけの手作りのエスケープと違い、先頭の英数字や空白、孤立サロゲートまで変換します。
