# revert-ruleでCSSの上書きを取り消して前の値に戻す

<BrowserSupportStatus featureId="revert-rule" />

## はじめに

`revert-rule`は、プロパティの値を、自身が書かれたスタイルルールがなかった場合の値に戻すCSSのキーワードです。後から書いたルールの宣言だけを取り消し、前のルールで決めた値に戻せます。Safari 27が対応して、Baseline 2026に入りました。

取り消したい値が分かっているなら、その値をもう一度書けば足ります。基本のルールを書き換えられるなら、既定値を`var()`のフォールバックに入れておく方法もあります。前のルールの値を知らないまま、後のルールの宣言だけを条件付きで取り消せるのは`revert-rule`です。

ボタンの背景色を基本のルールで決めておき、カスタムプロパティが渡されたときだけ別のルールで差し替えたいとします。素直に書くと、`--tint`を渡さなかったボタンの背景は`royalblue`ではなく透明になります。

```css
.button {
  background-color: royalblue;
}

.button.tinted {
  background-color: var(--tint); /* --tint が無いと → transparent */
}
```

`.button.tinted`の宣言が選ばれた時点で、`.button`の`royalblue`は使われません。`--tint`が無いと値が無効になり、初期値の`transparent`になります。基本のルールを`background-color: var(--tint, royalblue)`と書き換えられるなら、それで足ります。

## revertとrevert-layerとの違い

3つのキーワードは巻き戻す単位が違います。`revert`はオリジン、`revert-layer`はカスケードレイヤー、`revert-rule`はスタイルルールを単位にします。同じ`components`レイヤーに3つのキーワードを書き、背景色がそれぞれどの値になるかをコメントに示します。

```css demo="keywords"
@layer base {
  .highlight {
    background-color: lightgray;
  }
}

@layer components {
  .highlight {
    background-color: royalblue;
  }

  .highlight.rule {
    background-color: revert-rule; /* → royalblue */
  }

  .highlight.layer {
    background-color: revert-layer; /* → lightgray */
  }

  .highlight.origin {
    background-color: revert; /* → transparent */
  }
}

/* 例の見た目 */
p {
  padding: 1rem;
  background-color: white;
  color: black;
}
span {
  padding: 0.25rem 0.5rem;
}
```

```html demo="keywords"
<p>
  <span class="highlight">.highlight</span>
  <span class="highlight rule">revert-rule</span>
  <span class="highlight layer">revert-layer</span>
  <span class="highlight origin">revert</span>
</p>
```

`revert-rule`だけが同じレイヤーの`.highlight`に戻り、ほかの2つはレイヤーやオリジンごと飛ばします。結果の欄では、`revert-rule`の要素は`royalblue`に、`revert-layer`の要素は前のレイヤーの`lightgray`になり、`revert`の要素は背景が無くなります。

`revert`の`transparent`は、ブラウザの既定のスタイルで背景を持たない`span`や`div`の場合です。`<mark>`のように既定のスタイルで背景を持つ要素では、`revert`はその背景に戻り、どのブラウザでも`rgb(255, 255, 0)`の黄色になります。

## 変数が無いときだけ宣言を取り消す

はじめにの例は、`var()`のフォールバックに`revert-rule`を書けば解決します。フォールバックにはCSS全体キーワードを書けます。

```css
/* [!og] */
.button {
  background-color: royalblue;
}

.button.tinted {
  background-color: var(--tint, revert-rule);
}
```

`--tint`が未定義なら、このルールの宣言はなかったことになり、`.button`の`royalblue`が当たります。どのブラウザでも、`--tint`の無いボタンは`royalblue`に、`--tint: green`を渡したボタンは緑になります。

`--tint: revert-rule`と変数のほうに書くと、戻るのは`--tint`自体です。親から`--tint: orange`を継承していると、`--tint`は継承したオレンジに戻り、背景もオレンジになります。継承する値が無ければ`--tint`は無効になり、背景は`transparent`です。

## 同じルールの宣言には戻らない

`revert-rule`は、同じルールで先に書いた宣言にも戻りません。

```css
.highlight.quiet {
  color: red;
  color: revert-rule;
}
```

`color`は`red`ではなく前のルールの値になります。[仕様](https://drafts.csswg.org/css-cascade-5/#revert-rule-keyword)では、そのスタイルルールが存在しなかったものとして値を計算し直すからです。

入れ子のルールは別のスタイルルールとして数えられます。`.highlight.quiet { color: red; & { color: revert-rule; } }`と書くと、どのブラウザでも外側のルールの`red`に戻ります。`style`属性に`color: revert-rule`と書いた場合も、`style`属性が無いときの値、つまりスタイルシートのルールの値になります。

## おわりに

`revert-rule`を使うと、ルールの宣言だけをなかったことにできます。`var()`のフォールバックと組み合わせれば、変数が無いときだけ宣言を取り消せます。
