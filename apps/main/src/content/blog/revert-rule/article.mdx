# revert-ruleでCSSの上書きを取り消して前の値に戻す

<BrowserSupportStatus featureId="revert-rule" />

## はじめに

`revert-rule`は、プロパティの値を、自身が書かれたスタイルルールがなかった場合の値に戻すCSSのキーワードです。後から書いたルールの宣言だけを取り消し、前のルールで決めた値に戻せます。

取り消したい値が分かっているなら、その値をもう一度書けば足ります。基本のルールを書き換えられるなら、既定値を`var()`のフォールバックに入れておく方法もあります。前のルールの値を知らないまま、後のルールの宣言だけを条件付きで取り消せるのは`revert-rule`です。

ボタンの背景色を基本のルールで決めておき、カスタムプロパティが渡されたときだけ別のルールで差し替えたいとします。素直に書くと、`--tint`を渡さなかったボタンの背景は`royalblue`ではなく透明になります。

```css
.button {
  background-color: royalblue;
}

.button.tinted {
  background-color: var(--tint); /* --tint が無いと → transparent */
}
```

`.button.tinted`の宣言が選ばれた時点で、`.button`の`royalblue`は使われません。`--tint`が無いと値が無効になり、初期値の`transparent`になります。基本のルールを`background-color: var(--tint, royalblue)`と書き換えられるなら、それで足ります。

`revert-rule`は、Firefox 150とChrome 148に続いてSafari 27が対応し、Baseline 2026に加わりました。

## revert・revert-layerとの違い

3つのキーワードは巻き戻す単位が違います。`revert`はオリジン、`revert-layer`はカスケードレイヤー、`revert-rule`はスタイルルールを単位にします。同じ`components`レイヤーに3つのキーワードを書き、背景色がそれぞれどの値になるかをコメントに示します。

```css
@layer base {
  .highlight {
    background-color: lightgray;
  }
}

@layer components {
  .highlight {
    background-color: royalblue;
  }

  .highlight.rule {
    background-color: revert-rule; /* → royalblue */
  }

  .highlight.layer {
    background-color: revert-layer; /* → lightgray */
  }

  .highlight.origin {
    background-color: revert; /* → transparent */
  }
}
```

`revert-rule`だけが同じレイヤーの`.highlight`に戻り、ほかの2つはレイヤーやオリジンごと飛ばします。`revert`の`transparent`は、ブラウザの既定のスタイルで背景を持たない`span`や`div`の場合です。

`revert-rule`を選ぶと、`.rr-quiet`の付いた要素も`.rr-highlight`と同じ色になります。`revert-layer`では前のレイヤーの色に戻ります。デモの要素は`<mark>`なので、`revert`ではブラウザの既定のスタイルの黄色い背景になります。Chrome 156、Safari 27.2、Firefox 159で、`<mark>`の`revert`は3つとも`rgb(255, 255, 0)`でした。

## 変数が無いときだけ宣言を取り消す

冒頭の例は、`var()`のフォールバックに`revert-rule`を書けば解決します。フォールバックにはCSS全体キーワードを書けます。

```css
/* [!og] */
.button {
  background-color: royalblue;
}

.button.tinted {
  background-color: var(--tint, revert-rule);
}
```

`--tint`が未定義なら、このルールの宣言はなかったことになり、`.button`の`royalblue`が当たります。Chrome 156、Safari 27.2、Firefox 159で、`--tint`の無いボタンは`royalblue`に、`--tint: green`を渡したボタンは緑になりました。

`--tint: revert-rule`と変数のほうに書くと、戻るのは`--tint`自体なので注意してください。親から`--tint: orange`を継承していると、`--tint`は継承したオレンジに戻り、背景もオレンジになりました。継承する値が無ければ`--tint`は無効になり、背景は`transparent`です。

## 同じルールの宣言には戻らない

`revert-rule`は、同じルールで先に書いた宣言にも戻りません。

```css
.highlight.quiet {
  color: red;
  color: revert-rule;
}
```

`color`は`red`ではなく前のルールの値になります。[仕様](https://drafts.csswg.org/css-cascade-5/#revert-rule-keyword)では、そのスタイルルールが存在しなかったものとして値を計算し直すからです。

入れ子のルールは別のスタイルルールとして数えられます。`.highlight.quiet { color: red; & { color: revert-rule; } }`と書くと、3つのブラウザとも外側のルールの`red`に戻りました。`style`属性に`color: revert-rule`と書いた場合も、3つとも`style`属性が無いときの値、つまりスタイルシートのルールの値になりました。

## おわりに

`revert-rule`を使うと、ルールの宣言だけをなかったことにできます。`var()`のフォールバックと組み合わせれば、変数が無いときだけ宣言を取り消せます。
