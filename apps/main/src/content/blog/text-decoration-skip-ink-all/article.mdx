# text-decoration-skip-inkで下線を文字に重ねない

<BrowserSupportStatus featureId="text-decoration-skip-ink-all" />

## はじめに

`text-decoration-skip-ink`は、下線や上線が文字の形と重なる箇所で、線を途切れさせるかを決めるCSSプロパティです。既定の`auto`では、英字の`g`や`p`、`y`の下に出る部分を避けて線が切れます。`all`を指定すると、ChromeとFirefoxでは漢字の下端にかかる線も切れます。Chrome 148が`all`に対応して、Baseline 2026に入りました。

英字の下線なら、何も指定しない`auto`のままで足ります。日本語の下線を漢字に重ねたくないだけなら、`text-underline-offset`で線を下へ離す方法もあります。`text-underline-offset: 0.1em`にすると、どのブラウザでも漢字と線が重ならなくなります。線の位置を変えずに、漢字にかかる箇所だけを切るのが`all`です。

## 3つの値

`text-decoration-skip-ink`に指定できる値は、次の3つです。

- `auto`（既定値）：線を切るかをブラウザが決める。英字の下に出る部分は避けるが、漢字の下では切らないブラウザが多い
- `none`：線を切らず、常に1本につなげる
- `all`：文字の形と重なる箇所で、必ず線を切る

```css
/* [!og] */
p {
  text-decoration: underline;
  text-decoration-skip-ink: all;
}
```

セレクトで`auto`と`none`、`all`を切り替えると、下線の切れ方が変わります。英文の`j`や`p`の下は`auto`と`all`で切れ、`none`にすると切れずにつながります。日本語の部分は、このページの書体（M PLUS 2）で描いています。`all`を選ぶと、Chromeでは漢字に加えて`く`や`ぐ`、`ゆ`のようなかなの下でも線が切れます。Firefoxで切れるのは、`章`など数文字の下だけです。

## 漢字の下での切れ方

英字の下線では、`auto`でもほとんどのブラウザが下に出る部分を避けるので、`auto`と`all`の差は見えません。差が出るのは、漢字を含む日本語の下線です。

ヒラギノ角ゴシックで`漢字の下端やぐ・ゆ jumping`に下線を引くと、`auto`ではどのブラウザも英字の`j`と`p`、`g`の下だけで線が切れ、漢字の下端には線が重なります。かなの`ぐ`や`ゆ`は下線まで届かず、どの値でも線と重なりません。

同じ文で`all`にすると、ChromeとFirefoxでは漢字の下端にかかる箇所で線が切れます。切れるのは字の形が下線にかかる箇所だけで、この書体ではかなの下で線はつながったままです。Safariでは`all`にしても漢字の下で線が切れず、`auto`と同じ見た目になります。上のデモの書体では、Chromeはかなの下でも線を切るので、どの字で切れるかは書体でも変わります。

日本語の文章に`all`を当てると、線が細かく途切れて、かえって読みにくく感じることもあります。漢字に線を重ねたくないだけなら、線をつなげたまま離せる`text-underline-offset`のほうが向いています。

## おわりに

`text-decoration-skip-ink: all`を指定すると、ChromeとFirefoxでは漢字の下端にかかる下線も切れます。どの字で切れるかはブラウザと書体で変わるので、実際の文章で見え方を確かめてから使います。
