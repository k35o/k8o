# text-decoration-skip-inkで下線を文字に重ねない

<BrowserSupportStatus featureId="text-decoration-skip-ink-all" />

## はじめに

`text-decoration-skip-ink`は、underline（下線）やoverline（上線）が文字の形と重なる箇所で、線を途切れさせるかを決めるCSSプロパティです。既定の`auto`では英字の`g`や`p`、`y`のディセンダを避けて線が切れ、`all`を指定すると、Chrome 156とFirefox 159では漢字の下端にかかる線も切れます。

英字の下線なら、何も指定しない`auto`のままで足ります。日本語の下線を漢字に重ねたくないだけなら、`text-underline-offset`で線を下へ離す方法もあります。`text-underline-offset: 0.1em`にすると、Chrome 156、Safari 27.2、Firefox 159のいずれでも漢字と線が重ならなくなりました。線の位置を変えずに、漢字にかかる箇所だけを切るのが`all`です。

これまでは`auto`と`none`の2つの値で、ブラウザに任せるか一切途切れさせないかを選べました。2026年5月のChrome 148が`all`に対応し、3つ目の値がBaseline 2026に揃いました。

## プロパティの基本と3つの値

`text-decoration-skip-ink`はunderlineやoverlineをグリフのインク（実際にレンダリングされる字の形）と交差させるかどうかを制御します。値は3つあります。

- `auto`（既定値） - ブラウザの判断でグリフを避けるかどうかを決める。ラテン文字のディセンダは通常避けるが、CJK文字には適用しないユーザーエージェントが多い
- `none` - 途切れさせない。常に1本の線として描画する
- `all` - すべてのグリフのインクと交差する箇所で必ず途切れさせる

`auto`では仕様上ブラウザに裁量があり、どこを避けてどこを避けないかは実装次第です。仕様では、`all`を指定すると裁量が無くなり、グリフがあれば必ず線を切ることになります。

```css
/* [!og] */
p {
  text-decoration: underline;
  text-decoration-skip-ink: all;
}
```

セレクトで`auto`・`none`・`all`を切り替えると、下線の切れ方が変わります。英文の`j`や`p`の下は`auto`と`all`で切れ、`none`にすると切れずにつながります。日本語の部分で`all`が線を切るかは、次の節のとおりブラウザで変わります。このページの書体（M PLUS 2）のデモで`all`を選ぶと、Chrome 156では漢字に加えて`く`・`ぐ`・`ゆ`のようなかなの下でも線が切れました。Firefox 159で切れたのは、`章`など数文字の下だけです。

## auto と all の挙動の差

ラテン文字のunderlineは`auto`でも実用上ほとんどのブラウザがディセンダを避けてくれるので、`auto`と`all`の差は目に見えません。差が出るのは主にCJKテキストのunderlineです。

[仕様](https://drafts.csswg.org/css-text-decor-4/#text-decoration-skip-ink-property)上、`auto`は

> UAs may interrupt underlines and overlines where the line would cross glyph ink

とUAに裁量を与えているだけです。CJKに対しては多くのUAが線を途切れさせない実装になっており、結果として日本語の文章にunderlineを引くと、漢字の下端に線が重なった見た目になります。Chrome 156、Safari 27.2、Firefox 159で、macOSのsans-serifで40pxの`漢字の下端やぐ・ゆ jumping`に下線を引いて描画を比べると、`auto`ではどれも英字の`j`・`p`・`g`の下だけで線が切れ、漢字の下端には線が重なりました。かなの`ぐ`や`ゆ`は下線まで届かず、どの値でも線と重なりません。

`all`は

> UAs must interrupt underlines and overlines where the line would cross glyph ink

と義務になります（`may`と`must`の部分が異なります）。同じ文で`all`にすると、Chrome 156とFirefox 159では漢字の下端にかかる箇所で線が切れました。切れるのは字の形が下線にかかる箇所だけで、かなの下では線はつながったままです。Safari 27.2では`all`にしても漢字の下で線が切れず、`auto`と同じ見た目でした。`auto`の連続したunderlineを前提に組んだデザインに後付けで入れると、印象が大きく変わる点には注意してください。

## おわりに

`text-decoration-skip-ink: all`はChromiumに長く欠けていた値がようやく揃ったというだけのもので、CJK混じりのunderlineが必ず読みやすくなるとは限りません。グリフの周りで線が大きく途切れることで、かえって途切れが目立って違和感が出る場面もあります。また、Safari 27.2では日本語の下線は`all`でも切れません。`auto`の挙動が物足りない箇所だけを狙って、実際の文章で見栄えを確認しながら使うかどうか決めるのがよさそうです。
