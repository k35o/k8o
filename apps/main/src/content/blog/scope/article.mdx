# @scopeでCSSのスタイルを特定の要素の中だけに効かせる

<BrowserSupportStatus featureId="scope"></BrowserSupportStatus>

## はじめに

`@scope`は、CSSのスタイルが当たる範囲を、ある要素（スコープルート）の中に限るアットルールです。`@scope (.card) { h2 { ... } }`と書くと、`.card`の中の`h2`にだけスタイルが当たります。Safari 26.4が対応して、Baseline 2026に入りました。

要素の中だけにスタイルを当てるのは、子孫セレクタの`.card h2`でもできます。クラス名の衝突は、BEMやCSS Modulesでも避けられます。`@scope`でしかできないのは、内側に下限を設けて入れ子の部分を外すことと、詳細度が同じときに近いスコープのスタイルを勝たせることです。クラス名を付けずに、`<style>`要素の親の中だけにスタイルを当てることもできます。

## 基本的な構文

`@scope`は、スタイルシートにも`<style>`要素の中にも書けます。

### スタイルシート形式

スタイルシートに書くときは、`@scope`の後の括弧にスコープルートのセレクタを書きます。

```css
/* [!og] */
@scope (.card) {
  /* .card内のh2要素にのみ適用 */
  h2 {
    color: var(--color-primary);
  }
  /* .card内のp要素にのみ適用 */
  p {
    color: var(--color-text);
  }
}
```

### インライン形式

`<style>`要素の中に括弧を付けずに`@scope`と書くと、`<style>`要素の親要素がスコープルートになります。

```html
<div class="card">
  <style>
    @scope {
      /* .card内のh2要素にのみ適用 */
      h2 {
        color: red;
      }
    }
  </style>
  <h2>カードのタイトル</h2>
</div>
<h2>カードの外のタイトル</h2>
```

開くと、カードのタイトルだけが赤くなり、カードの外のタイトルは黒のままです。

## ドーナツスコープ

`to`の後にセレクタを書くと、スコープに下限（スコープリミット）を設けられます。スコープルートからスコープリミットの手前までの、穴の開いた範囲にだけスタイルが当たるので、ドーナツスコープと呼ばれます。

```css
@scope (.article) to (.nested-content) {
  img {
    border: 2px solid var(--color-border);
    border-radius: var(--radius-md);
  }
}
```

次のHTMLでは、`.article`の中の`<img>`にスタイルが当たり、`.nested-content`の中の`<img>`には当たりません。

```html demo="donut"
<label><input type="checkbox" id="scoped" checked /> @scopeを使う</label>
<div class="container">
  <article class="article">
    <p>この記事の内容</p>
    <!-- スタイルが反映される -->
    <img src="/icon.png" alt="記事の画像1" width="64" height="64" />
    <div class="nested-content">
      <p>ネストされたコンテンツ</p>
      <!-- スタイルが反映されない -->
      <img src="/icon.png" alt="記事の画像2" width="64" height="64" />
    </div>
  </article>
  <!-- スタイルが反映されない -->
  <img src="/icon.png" alt="記事の画像3" width="64" height="64" />
</div>
```

```css demo="donut" selected
@scope (.article) to (.nested-content) {
  img {
    border: 4px solid steelblue;
    border-radius: 0.5rem;
  }
}

/* チェックを外しているあいだは、@scopeを使わない.article imgも当てる */
body:has(#scoped:not(:checked)) .article img {
  border: 4px solid steelblue;
  border-radius: 0.5rem;
}

.article,
.nested-content {
  margin-block: 0.5rem;
  padding-inline: 1rem;
  border: 1px dashed GrayText;
}
```

結果の欄でチェックを外して`.article img`に切り替えると、`.nested-content`の中の画像にもボーダーが付きます。

## :scope疑似クラス

`@scope`の中でスコープルート自身にスタイルを当てるときは、`:scope`疑似クラスを使います。

```css
@scope (.card) {
  :scope {
    background: var(--color-bg-subtle);
    padding: var(--spacing-lg);
    border-radius: var(--radius-lg);
  }

  h3 {
    margin-bottom: var(--spacing-sm);
  }
}
```

`:scope`は、スコープリミットのセレクタにも書けます。`to (:scope > .nested-content)`と書くと、スコープルートの直接の子の`.nested-content`だけが下限になります。

```css
@scope (.article) to (:scope > .nested-content) {
  img {
    border: 2px solid var(--color-border);
    border-radius: var(--radius-md);
  }
}
```

```html demo="limit"
<label><input type="checkbox" id="child" checked /> :scope &gt; を付ける</label>
<div class="container">
  <article class="article">
    <p>この記事の内容</p>
    <!-- スタイルが反映される -->
    <img src="/icon.png" alt="記事の画像1" width="64" height="64" />
    <div class="nested-content">
      <p>ネストされたコンテンツ</p>
      <!-- スタイルが反映されない -->
      <img src="/icon.png" alt="記事の画像2" width="64" height="64" />
    </div>
    <div>
      <div class="nested-content">
        <p>ネストされたコンテンツ</p>
        <!-- スタイルが反映される -->
        <img src="/icon.png" alt="記事の画像2" width="64" height="64" />
      </div>
    </div>
  </article>
  <!-- スタイルが反映されない -->
  <img src="/icon.png" alt="記事の画像3" width="64" height="64" />
</div>
```

```css demo="limit" selected
/* チェックを入れているあいだは、直接の子の.nested-contentだけを下限にする */
@scope (body:has(#child:checked) .article) to (:scope > .nested-content) {
  img {
    border: 4px solid steelblue;
    border-radius: 0.5rem;
  }
}

@scope (body:has(#child:not(:checked)) .article) to (.nested-content) {
  img {
    border: 4px solid steelblue;
    border-radius: 0.5rem;
  }
}

.article,
.nested-content {
  margin-block: 0.5rem;
  padding-inline: 1rem;
  border: 1px dashed GrayText;
}
```

1つ目の`.nested-content`は`.article`の直接の子なので、中の`<img>`にはスタイルが当たりません。2つ目は`<div>`を挟んだ孫なので下限にならず、中の`<img>`にもスタイルが当たります。

結果の欄でチェックを外して下限を`to (.nested-content)`に切り替えると、孫の`.nested-content`の中の画像からもボーダーが消えます。

## スコープの近接性

`@scope`で、カスケードにスコープの近接性という基準が加わりました。詳細度が同じスタイルがぶつかったときは、要素からスコープルートまでの階層が少ないほうのスタイルが勝ちます。

```css
@scope (.info-box) {
  .message {
    color: var(--color-fg-info);
    background-color: var(--color-bg-info);
  }
}

@scope (.warning-box) {
  .message {
    color: var(--color-fg-warning);
    background-color: var(--color-bg-warning);
  }
}
```

```html demo="proximity"
<label><input type="checkbox" id="scoped" checked /> @scopeを使う</label>
<div class="info-box">
  <p class="message">情報メッセージ</p>
  <div class="warning-box">
    <p class="message">警告メッセージ</p>
    <div class="info-box">
      <p class="message">ネストされた情報メッセージ</p>
    </div>
  </div>
</div>
```

```css demo="proximity" selected
@scope (.info-box) {
  .message {
    color: white;
    background-color: steelblue;
  }
}

@scope (.warning-box) {
  .message {
    color: black;
    background-color: gold;
  }
}

/* チェックを外しているあいだは、詳細度の高い子孫セレクタの規則が上の規則に勝つ */
body:has(#scoped:not(:checked)) {
  .info-box .message {
    color: white;
    background-color: steelblue;
  }

  .warning-box .message {
    color: black;
    background-color: gold;
  }
}

.info-box,
.warning-box {
  margin-block: 0.5rem;
  padding-inline: 1rem;
  border: 1px dashed GrayText;
}

.message {
  padding: 0.5rem;
}
```

いちばん内側の`.message`は、`.warning-box`より`.info-box`のほうが近いので、`.info-box`のスタイルになります。`@scope`を使わずに`.info-box .message`と`.warning-box .message`で書くと、詳細度が同じなので、後に書いた`.warning-box`のスタイルになります。

結果の欄でチェックを外して`@scope`を使わない書き方に切り替えると、いちばん内側のメッセージが警告の色に変わります。

近接性が効くのは、詳細度が同じときだけです。`@scope`の中の`h2`の詳細度は`h2`の分だけで、スコープルートの`.card`は足されません。

```css
.card h2 {
  color: blue;
}

@scope (.card) {
  h2 {
    color: red; /* 後に書いても、詳細度の高い.card h2の青が勝つ */
  }
}
```

`.card`の中の`h2`は青になります。`@scope`の中を`:scope h2`と書くと、`:scope`の分だけ詳細度が上がって`.card h2`と同じになり、近接性で赤が勝ちます。2つの規則を書く順を入れ替えても赤のままです。

## @scopeの注意点

### スタイルの継承は制限されない

`@scope`が限るのはセレクタが当たる範囲で、CSSの継承は止めません。Shadow DOMのようにスタイルを閉じ込めるのではなく、スタイルが当たる要素を絞るだけです。

```css
@scope (.container) to (.nested) {
  :scope {
    color: red;
  }
}
```

`.nested`には規則が当たりませんが、`.container`の`color`を継承するので、`.nested`の中の`<p>`も赤くなります。`:scope`ではなく`p { color: red; }`と書くと、`.nested`の中の`<p>`には規則が当たらず、親の`.nested`も赤くないので、赤くなりません。

### スコープ外の要素は選択できない

`@scope`の中のセレクタは、スコープルートの外の要素には当たりません。

```css
@scope (.card) {
  /* .cardの外の兄弟要素には当たらない */
  :scope + .sibling { }
}
```

`:scope + .sibling`は正しいセレクタとして`cssRules`に残りますが、`.card`の次の`.sibling`には当たりません。

## おわりに

`@scope`を使うと、命名規則やCSS Modulesに頼らずに、スタイルが当たる範囲を要素の中に限れます。`to`で入れ子の部分を外すドーナツスコープと、近いスコープのスタイルを勝たせる近接性は、子孫セレクタではできません。
