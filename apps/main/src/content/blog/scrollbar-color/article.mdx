# scrollbar-colorでスクロールバーの色をCSSで変える

<BrowserSupportStatus featureId="scrollbar-color"></BrowserSupportStatus>

## はじめに

`scrollbar-color`は、スクロールバーのつまみ（thumb）とトラック（track）の色を、2つの色で指定するCSSプロパティです。Safari 26.2が対応して、Baseline 2025に入りました。

これまでは、Safariが`scrollbar-color`に対応しておらず、Firefoxは`::-webkit-scrollbar`擬似要素に対応していないので、スクロールバーの色を変えるには両方を書いていました。今は、色を変えるだけなら`scrollbar-color`の1行で主要なブラウザすべてに効きます。幅や角の丸みまで変えるときは、これまでどおりChromeとSafari向けの`::-webkit-scrollbar`を使います。

## scrollbar-colorプロパティ

`scrollbar-color`には、つまみの色とトラックの色をこの順に書きます。

```css
.container {
  scrollbar-color: #6366f1 #e2e8f0;
}
```

色は2つとも書く必要があり、`scrollbar-color: red`のように1つだけ書くと無効になります。値を`auto`にすると、ブラウザの既定の色に戻ります。つまみの位置が見分けられるよう、つまみとトラックの色には十分なコントラストを付けます。

デモのカラーピッカーで色を選ぶと、下の枠のスクロールバーにすぐ反映されます。macOSで、スクロールしたときだけスクロールバーを出す設定にしていると、枠をスクロールしたときに色が見えます。Chromeでは、スクロールバーにマウスを合わせるまでトラックは描かれません。

### ダークモードに合わせる

`scrollbar-color`は継承されるので、`:root`に書くとページの中のスクロールする要素すべてに効きます。ダークモードの色は、`light-dark()`でテーマごとに書きます。

```css
:root {
  color-scheme: light dark;
  scrollbar-color: light-dark(#6366f1, #a5b4fc) light-dark(#e2e8f0, #1e293b);
}
```

`light-dark()`は`:root`の`color-scheme`で色が決まってから子に継承されるので、途中の要素で`color-scheme: dark`にしても、その中のスクロールバーの色は変わりません。

### ::-webkit-scrollbarとの併用

同じ要素に`::-webkit-scrollbar`と`scrollbar-color`を書くと、ChromeとSafariは`::-webkit-scrollbar`の指定を使いません。

```css
.container::-webkit-scrollbar {
  width: 30px;
}

.container {
  scrollbar-color: #6366f1 #e2e8f0;
}
```

この要素のスクロールバーは、幅30pxではなく既定の幅で描かれます。`::-webkit-scrollbar`で形を変えている要素に`scrollbar-color`を足すと、形の指定が消えます。

## おわりに

`scrollbar-color`を使うと、`::-webkit-scrollbar`を書かずに、主要なブラウザすべてでスクロールバーの色を1行で変えられます。ダークモードの色も、`light-dark()`と組み合わせて`:root`にまとめて書けます。
