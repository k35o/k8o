# scrollbar-colorでスクロールバーの色をCSSで変える

<BrowserSupportStatus featureId="scrollbar-color"></BrowserSupportStatus>

## はじめに

`scrollbar-color`は、スクロールバーのつまみ（thumb）とトラック（track）の色を、2つの色で指定するCSSプロパティです。Safari 26.2が対応して、Baseline 2025に入りました。

これまでは、Safariが`scrollbar-color`に対応しておらず、Firefoxは`::-webkit-scrollbar`擬似要素に対応していないので、スクロールバーの色を変えるには両方を書いていました。今は、色を変えるだけなら`scrollbar-color`の1行で主要なブラウザすべてに効きます。

## scrollbar-colorプロパティ

`scrollbar-color`には、つまみの色とトラックの色をこの順に書きます。

```css demo="picker"
.container {
  scrollbar-color: #6366f1 #e2e8f0;
}

.container {
  height: 12rem;
  overflow-y: scroll;
  padding-inline: 1rem;
  border: 1px solid GrayText;
}

label {
  margin-inline-end: 1rem;
}
```

```html demo="picker"
<label>
  つまみ（thumb）
  <input id="thumb" type="color" value="#6366f1" />
</label>
<label>
  トラック（track）
  <input id="track" type="color" value="#e2e8f0" />
</label>
<p><code id="declaration"></code></p>
<div class="container" tabindex="0"></div>
```

```js demo="picker"
const container = document.querySelector('.container');
const thumb = document.querySelector('#thumb');
const track = document.querySelector('#track');
const declaration = document.querySelector('#declaration');

for (let i = 1; i <= 20; i++) {
  const item = document.createElement('p');
  item.textContent = `アイテム ${i}`;
  container.append(item);
}

const update = () => {
  const value = `${thumb.value} ${track.value}`;
  container.style.scrollbarColor = value;
  declaration.textContent = `scrollbar-color: ${value};`;
};
thumb.addEventListener('input', update);
track.addEventListener('input', update);
update();
```

色は2つとも書く必要があり、`scrollbar-color: red`のように1つだけ書くと無効になります。値を`auto`にすると、ブラウザの既定の色に戻ります。つまみの位置が見分けられるよう、つまみとトラックの色には十分なコントラストを付けます。

結果の欄のカラーピッカーで色を選ぶと、下の枠のスクロールバーにすぐ反映されます。macOSで、スクロールしたときだけスクロールバーを出す設定にしていると、枠をスクロールしたときに色が見えます。Chromeでは、スクロールバーにマウスを合わせるまでトラックは描かれません。

### ダークモードに合わせる

`scrollbar-color`は継承されるので、`:root`に書くとページの中のスクロールする要素すべてに効きます。ダークモードの色は、`light-dark()`でテーマごとに書きます。

```css
:root {
  color-scheme: light dark;
  scrollbar-color: light-dark(#6366f1, #a5b4fc) light-dark(#e2e8f0, #1e293b);
}
```

`light-dark()`は`:root`の`color-scheme`で色が決まってから子に継承されるので、途中の要素で`color-scheme: dark`にしても、その中のスクロールバーの色は変わりません。

### スクロールバーの幅

30pxのような幅や角の丸みを決めるには、ChromeとSafari向けの`::-webkit-scrollbar`を使います。しかし、同じ要素に`scrollbar-color`も書くと、`::-webkit-scrollbar`の設定は打ち消されるので注意してください。代わりに標準で使える`scrollbar-width`もありますが、幅は`auto`と`thin`、`none`から選ぶことしかできません。

## おわりに

`scrollbar-color`を使うと、`::-webkit-scrollbar`を書かずに、主要なブラウザすべてでスクロールバーの色を1行で変えられます。ダークモードの色も、`light-dark()`と組み合わせて`:root`にまとめて書けます。
