# scrollbar-colorでスクロールバーの色をCSSで変える

<BrowserSupportStatus featureId="scrollbar-color"></BrowserSupportStatus>

## はじめに

`scrollbar-color`は、スクロールバーのつまみ（thumb）とトラック（track）の色を、2つの色で指定するCSSプロパティです。Safari 26.2が対応して、Baseline 2025に入りました。

これまでSafariは`scrollbar-color`に対応しておらず、スクロールバーの色を変えるには`::-webkit-scrollbar`擬似要素も書く必要がありました。Firefoxは`::-webkit-scrollbar`に対応していません。幅や角の丸みまで変えたいなら、今もChromeとSafari向けの`::-webkit-scrollbar`を使います。色を変えるだけなら、`scrollbar-color`の1行で主要なブラウザすべてに効きます。

## scrollbar-colorプロパティ

`scrollbar-color`プロパティを使うと、シンプルにスクロールバーの色を指定できます。

```css
/* デフォルトと同じ */
.container {
  scrollbar-color: auto;
}

.container {
  scrollbar-color: #6366f1 #e2e8f0;
}

/* デフォルトのscrollbarの色を変更 */
:root {
  scrollbar-color: var(--color-primary-fg) var(--color-primary-bg);
}
```

最初の値がつまみの色、2番目の値がトラックの色です。色を1つだけ書いた`scrollbar-color: red`は無効です。

デモのカラーピッカーでつまみとトラックの色を選ぶと、その下の枠のスクロールバーにすぐ反映されます。macOSのスクロールしたときだけスクロールバーを出す設定では、枠をスクロールすると色が見えます。このときChromeでは、つまみにだけ色が付き、トラックの色は描かれません。

`scrollbar-color`は継承されるので、`:root`に書くとページの中のスクロールする要素すべてに効きます。ダークモードに合わせるなら、`light-dark()`でテーマごとの色を書きます。

```css
:root {
  color-scheme: light dark;
  scrollbar-color: light-dark(#6366f1, #a5b4fc) light-dark(#e2e8f0, #1e293b);
}
```

`light-dark()`の色は`:root`の`color-scheme`で決まってから子に継承されます。途中の要素で`color-scheme: dark`にしても、その中のスクロールバーの色は変わりません。

`::-webkit-scrollbar`と一緒には使えません。`::-webkit-scrollbar { width: 30px; }`だけを書いた要素には、ChromeとSafariで幅30pxのスクロールバーが出ます。同じ要素に`scrollbar-color`を足すと`::-webkit-scrollbar`の指定は使われず、既定のスクロールバーに戻ります。既存の`::-webkit-scrollbar`で形を変えているページに足すと、形の指定が消えます。

スクロールバーの色を変更する際は、アクセシビリティを考慮してつまみとトラックで十分なコントラストを確保しましょう。

## おわりに

`scrollbar-color`プロパティを紹介しました。

従来の方法では、`::-webkit-scrollbar`擬似要素などを利用した、ブラウザごとに異なる実装が必要でした。
`scrollbar-color`プロパティにより、主要なブラウザすべてでスクロールバーの色を1行で変えられるようになりました。`::-webkit-scrollbar`と同じ要素に書くと形の指定が使われなくなる点には気をつけてください。

ダークモード対応やブランドカラーに合わせたデザインを実現するために活用してみてください。
