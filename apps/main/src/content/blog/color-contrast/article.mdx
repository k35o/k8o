# コントラスト比の計算式と相対輝度の求め方

## はじめに

背景色とテキスト色のコントラスト比には、WCAG 2.1の[AA基準](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html)と[AAA基準](https://www.w3.org/WAI/WCAG21/Understanding/contrast-enhanced)という2つの達成基準があります。
AA基準は通常のテキストに4.5:1以上、大きなテキストに3:1以上を求め、AAA基準はそれぞれに7:1以上と4.5:1以上を求めます。ここでの大きなテキストは、18pt（24px）以上か、太字で14pt（約18.66px）以上の文字のことで、それより小さい文字は通常のテキストとして扱います。
どちらの基準も、コントラストを補う支援技術を使わない中程度の弱視の人が、テキストを読めるように設けられています。

この基準を満たしているかは、[WebAIMのチェッカー](https://webaim.org/resources/contrastchecker/)や[Storybookのa11yアドオン](https://storybook.js.org/addons/@storybook/addon-a11y)のようなツールで確かめられるので、計算方法を知らなくても困りません。
ただ、計算方法を知っておくと、色を選ぶ段階での判断に役立ちます。私自身、以前はツールに頼りきりでしたが、計算方法を知ってその大切さに気づきました。

## 計算式

コントラスト比は、2つの色の相対輝度から求めます。輝度とは、広がりを持つ光源からある方向へ出る光について、面積あたりの明るさを表す物理量です[^1]。その相対輝度を$L$で表すと、コントラスト比$C$は次の式で計算します。

```math
C = \frac{(L_1 + 0.05)}{(L_2 + 0.05)}
```

$L_1$には明るいほうの色の相対輝度を、$L_2$には暗いほうの色の相対輝度を入れます。明るい色ほど輝度が大きいので、この式の値は$1$以上になります。分母と分子に足している$0.05$は周囲光の影響を表すもので、分子と分母が$0$になるのも防いでいます。
後で求め方を見るように相対輝度$L$は$0 \sim 1$の値をとるので、コントラスト比は$1 \sim 21$の値になります。

相対輝度は、色空間の中の任意の点の相対的な明るさで、`#000000`が$0$、`#ffffff`が$1$になるように正規化されています。
計算には、赤、緑、青の各成分を$0\sim1$の数値で表した$(R,G,B)$を使います。たとえば`#4080c0`なら、各成分の16進数を10進数に直した$(64, 128, 192)$を$255$で割り、$(0.251, 0.502, 0.753)$とします。この各成分を、次の式で変形します。

```math
    F(x) =
        \begin{cases}
            \frac{x}{12.92}, & x \leqq 0.04045 \\
            \left(\frac{x + 0.055}{1.055}\right)^{2.4}, & x > 0.04045
        \end{cases}
```

$F(x)$は単調増加関数なので、$x$が$0\sim1$の範囲なら、$F(x)$も$F(0) = 0$から$F(1) = 1$までの$0\sim1$の値をとります。

sRGBの値は、人間の視覚が明るさを非線形に捉える特性に合わせて割り振られていて、光の量には比例しません。この変形は、その値を光の量に比例する値に戻すためのものです。

ただし、$0.04045$以下の暗い色ではべき乗の曲線がほぼ平らになり、値の違いが輝度にほとんど表れません。そのため、この範囲だけは$12.92$で割る直線の式にしています。

変形した赤、緑、青の値を、それぞれの見え方に合わせた重みで足し合わせると相対輝度が求まります。

```math
 L = 0.2126 \times R + 0.7152 \times G + 0.0722 \times B
```

重みの合計が1なので、$L$も$0\sim1$の値をとります。重みは、人間の目が色ごとに明るさをどれだけ感じやすいかに合わせて決められています。人間の目は緑に最も敏感で、赤、青と順に鈍くなります。そのため緑の重みが最も大きく、青の重みが最も小さくなっています。

## コード

計算式が分かったので、コードに落とし込みます。まずは、各成分を補正する関数です。

```ts
const applyCorrection = (color: number): number => {
  if (color <= 0.04045) {
    return color / 12.92;
  }

  return Math.pow((color + 0.055) / 1.055, 2.4);
};
```

`color`には$0\sim1$の範囲外の数値も渡せますが、この記事ではそうした値は考えません。

次に、相対輝度を求める関数です。

```ts
type RGB = [number, number, number];

const computeRelativeLuminance = (rgb: RGB): number => {
  const [r, g, b] = rgb;
  return (
    0.2126 * applyCorrection(r) +
    0.7152 * applyCorrection(g) +
    0.0722 * applyCorrection(b)
  );
};
```

`RGB`は、`number`型の要素を3つ持つタプル型です。

最後に、コントラスト比を求める関数です。

```ts
const computeContrastRatio = (rgb1: RGB, rgb2: RGB): number => {
  const l1 = computeRelativeLuminance(rgb1);
  const l2 = computeRelativeLuminance(rgb2);
  return (Math.max(l1, l2) + 0.05) / (Math.min(l1, l2) + 0.05);
};
```

相対輝度を計算するまでどちらが明るいか分からないので、計算した後で大きいほうを分子に、小さいほうを分母に置いています。

## さいごに

計算式を追うと、人間の視覚が感じやすい色や、緑の成分を強めると青の成分を強めるより約10倍も相対輝度が上がることなど、ツールで調整するだけでは分からなかったことが読み取れます。
これからもツールに頼りきりにならず、その値がどう導かれるのかまで理解していきたいです。
