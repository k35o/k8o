# baseline-shiftでSVGの文字を上付き・下付きにする

<BrowserSupportStatus featureId="baseline-shift" />

## はじめに

`baseline-shift`は、文字が並ぶ基準の線（ベースライン）を、親の文字に対して上下にずらすCSSプロパティです。SVGの`<text>`の中の`<tspan>`に指定すると、化学式や単位の数字のように、その部分だけを上付きや下付きにできます。Firefox 149が対応して、Baseline 2026に入りました。

HTMLの文章では、`<sub>`や`<sup>`、`vertical-align`で文字の高さをずらせます。SVGの`<text>`の中では、ChromeとSafariで`vertical-align`が効きません。`<tspan>`の`dy`属性でもずらせますが、後ろの文字まで一緒にずれるので、戻すための`dy`がもう1つ要ります。後ろの文字を元の高さに残したまま、その部分だけをずらせるのが`baseline-shift`です。

SVGには古くから`baseline-shift`属性があり、`<text>`や`<tspan>`に書けばずらせました。この属性は、同じ名前のCSSプロパティの値を決めるプレゼンテーション属性なので、CSSから`baseline-shift`を指定しても同じようにずれます。

## 基本の使い方

SVGの`<text>`の中の`<tspan>`に`baseline-shift`を当てると、その部分だけベースラインが動きます。

```html
<svg viewBox="0 0 360 100" width="360" height="100">
  <text x="0" y="40" font-size="28">
    水の化学式は H<tspan class="sub">2</tspan>O です。
  </text>
  <text x="0" y="85" font-size="28">
    面積は 10 m<tspan class="sup">2</tspan> です。
  </text>
</svg>
```

```css
/* [!og] */
.sub {
  /* [!hl] */
  baseline-shift: sub;
  font-size: 0.8em;
}

.sup {
  /* [!hl] */
  baseline-shift: super;
  font-size: 0.8em;
}
```

長さで指定するときは、文字の大きさに合わせて変わる`em`を使います。

```css
.note {
  baseline-shift: 0.3em;
  font-size: 0.75em;
}
```

CSSで書けば、`<tspan>`ごとに属性を書かずにクラスでまとめて指定できます。属性とCSSの両方があるときは、CSSが優先されます。

セレクトで値を切り替えると、赤い数字が灰色の破線（親の`<text>`のベースライン）から上下に動きます。`sub`と`super`は、開いたブラウザによってずれる量が変わります。

## プロパティの値

`baseline-shift`は、インラインの要素とSVGのテキストの要素（`<tspan>`や`<textPath>`）に効き、親のベースラインからずらします。ただしHTMLのインライン要素に指定してずれるのはFirefoxだけで、ChromeとSafariでは位置が変わらないので、SVGのテキストで使います。取る値は次の3種類で、初期値は`0`（ずらさない）です。

- 長さか割合：その分だけずらす。`em`や`px`、`%`で書く。正の値で上に、負の値で下に動く
- `sub`：親のフォントで決まっている下付きの位置までずらす
- `super`：親のフォントで決まっている上付きの位置までずらす

`sub`と`super`でずれる量はブラウザで違い、特に`sub`は、ChromeとSafariの方がFirefoxより大きく下がります。ブラウザの間で揃えたいときは、`0.3em`のような長さで指定します。

## vertical-alignとの関係

CSS Inline Layout 3では、`vertical-align`は`baseline-source`、`alignment-baseline`、`baseline-shift`の3つを束ねるショートハンドとして定義されています。SVG 2の草案も、新しく書くなら`vertical-align`を使うよう勧めています。ただ、今`vertical-align`をショートハンドとして扱うのはFirefoxだけです。ChromeとSafariでは、`<tspan>`に`vertical-align: 0.3em`や`vertical-align: super`を指定しても位置が変わらず、`baseline-shift`の計算値もそのままです。SVGのテキストをずらすなら、今は`baseline-shift`を書きます。

```css
/* ショートハンド。ChromeとSafariのtspanでは効かない */
text .note {
  vertical-align: 0.3em;
}

/* ロングハンド。3つのブラウザで効く */
text .note {
  baseline-shift: 0.3em;
}
```

## おわりに

`baseline-shift`を使うと、SVGの`<text>`の中で、化学式や単位の数字を、後ろの文字を動かさずに上付きや下付きにできます。HTMLの文章や`vertical-align`のショートハンドとしては、今はFirefoxでしか効かないので、SVGのテキストで`baseline-shift`を書きます。
