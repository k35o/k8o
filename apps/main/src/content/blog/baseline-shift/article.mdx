# baseline-shiftでSVGの文字を上付き・下付きにする

<BrowserSupportStatus featureId="baseline-shift" />

## はじめに

`baseline-shift`は、文字が並ぶ基準の線（ベースライン）を、親の文字に対して上下にずらすCSSプロパティです。SVGの`<text>`の中の`<tspan>`に指定すると、化学式や単位の数字のように、その部分だけを上付き・下付きにできます。Firefox 149が対応して、Baseline 2026に入りました。

HTMLの文章なら、今までどおり`<sub>`・`<sup>`や`vertical-align`で足ります。SVGの`<text>`の中では、ChromeとSafariで`vertical-align`が効きません。`<tspan>`の`dy`属性でもずらせますが、後ろの文字まで一緒にずれるので、戻すための`dy`がもう1つ要ります。ずらした部分の後ろを元の高さに残したまま上付き・下付きにできるのは`baseline-shift`です。

SVGには古くから`baseline-shift`という属性があり、`<text>`や`<tspan>`の属性として書けばずらせました。この属性は同じ名前のCSSプロパティの値を決めるプレゼンテーション属性で、CSSから`baseline-shift`を指定しても同じようにずれます。

## 基本の使い方

SVGの`<text>`の中で`<tspan>`に`baseline-shift`を当てると、その部分だけベースラインが動きます。化学式や単位の上付き・下付きをCSSで揃えて書きたい場面で使えます。

```html
<svg viewBox="0 0 360 100" width="360" height="100">
  <text x="0" y="40" font-size="28">
    水の化学式は H<tspan class="sub">2</tspan>O です。
  </text>
  <text x="0" y="85" font-size="28">
    面積は 10 m<tspan class="sup">2</tspan> です。
  </text>
</svg>
```

```css
/* [!og] */
.sub {
  /* [!hl] */
  baseline-shift: sub;
  font-size: 0.8em;
}

.sup {
  /* [!hl] */
  baseline-shift: super;
  font-size: 0.8em;
}
```

長さで微調整したいときは`em`が使いやすいです。

```css
.note {
  baseline-shift: 0.3em;
  font-size: 0.75em;
}
```

CSSプロパティとして書くことで、SVGの`baseline-shift`属性を直接書くより一貫した記述ができます。属性とCSSの両方が効く場合、CSSの方が優先されます。

セレクトで値を切り替えると、赤い数字が灰色の破線（親の`<text>`のベースライン）から上下に動きます。`sub`と`super`は、開いたブラウザによってずれる量が変わります。

## プロパティの値

`baseline-shift`はインラインレベルボックスとSVGテキスト要素（`<tspan>`や`<textPath>`）に適用されるプロパティで、対象要素のドミナントベースラインを親のベースラインから相対的に動かします。ただしHTMLのインライン要素に指定してずれるのはFirefoxだけで、ChromeとSafariでは位置が変わりません。実用上はSVGテキストでの利用が中心になります。CSS Inline Layout Module Level 3で定義されている値は次の通りです。初期値は`0`（ずらさない）です。

- `<length-percentage>` - 任意の長さや割合でずらす。`em` / `px` / `%`などが使える。正の値で上、負の値で下に動く
- `sub` - 親フォントに定義されている下付き位置までずらす
- `super` - 親フォントに定義されている上付き位置までずらす

`sub`と`super`でずれる量はブラウザで違い、特に`sub`は、ChromeとSafariの方がFirefoxより大きく下がります。ブラウザの間で揃えたいときは、`0.3em`のような長さで指定します。

## vertical-alignとの関係

CSS Inline Layout 3では、`vertical-align`は`baseline-source`、`alignment-baseline`、`baseline-shift`の3つを束ねるショートハンドとして定義されています。SVG 2の草案も、新しく書くなら`vertical-align`を使うよう勧めています。ただ、今`vertical-align`をショートハンドとして扱うのはFirefoxだけです。ChromeとSafariでは、`<tspan>`に`vertical-align: 0.3em`や`vertical-align: super`を指定しても位置が変わらず、`baseline-shift`の計算値もそのままです。SVGのテキストをずらすなら、今は`baseline-shift`を書きます。

```css
/* ショートハンド。ChromeとSafariのtspanでは効かない */
text .note {
  vertical-align: 0.3em;
}

/* ロングハンド。3つのブラウザで効く */
text .note {
  baseline-shift: 0.3em;
}
```

## おわりに

`baseline-shift`はSVGテキストのベースラインをずらすCSSプロパティです。化学式・数式・図中ラベルなど、SVGの`<text>`に細かい上付き・下付きを入れたい場面で素直に書ける選択肢です。

ただ、HTMLのインライン要素への適用や、`vertical-align`をショートハンドとして扱うことは、今のところFirefoxだけが対応しています。SVGのテキストをずらす用途なら今すぐ使えますが、HTMLの文章で`vertical-align`の代わりに使えるのはもう少し先になりそうです。
