# :open疑似クラスで開いている要素をまとめてスタイリングする

<BrowserSupportStatus featureId="open-pseudo" />

## はじめに

`:open`疑似クラスは、開いている`<dialog>`と`<details>`、`<select>`、ピッカーを持つ`<input>`にマッチするセレクタです。`<select>`なら選択肢の一覧を、`<input type="color">`なら色を選ぶ画面を開いているあいだ当たります。Safari 26.5が対応して、Baseline 2026に入りました。

`<dialog>`と`<details>`の開いた状態は、`dialog[open]`や`details[open]`のように、`open`属性のセレクタで選べます。`<select>`や`<input>`のピッカーには、開いている状態を選ぶセレクタがありませんでした。`:open`は、これらをまとめて表せます。

```html
<style>
  :open {
    outline: 2px solid red;
  }
</style>
<details>
  <summary>開く</summary>
  中身
</details>
<select>
  <option>選択肢1</option>
  <option>選択肢2</option>
</select>
```

detailsを開くと赤い枠が付き、閉じると消えます。selectは、選択肢の一覧を開いているあいだだけ枠が付きます。

## マッチする要素

`:open`の対象になるのは、次の要素です。

- `<dialog>`：`open`属性が付いているとき
- `<details>`：`open`属性が付いているとき
- `<select>`：選択肢の一覧が開いているとき
- ピッカーを持つ`<input>`（`color`や`date`など）：ピッカーが開いているとき

`<dialog>`は、`show()`で開いても`showModal()`で開いてもマッチします。`<select>`はクリックして一覧を開くとマッチし、一覧を出さない`multiple`付きの`<select>`はクリックしてもマッチしません。`<input type="color">`は色を選ぶ画面を、`<input type="date">`はカレンダーを開いているあいだマッチします。`popover`属性を持つ要素は`:open`には当たらず、`:popover-open`で選びます。

## 使い方

開いている要素に枠線を付けるだけなら、`:open`の1つで書けます。

```css
:open {
  /* [!hl] */
  outline: 2px solid var(--color-accent);
  outline-offset: 4px;
}
```

要素を絞るときは、要素のセレクタと組み合わせます。

```css
/* [!og] */
/* dialogとdetailsが開いているとき */
dialog:open,
details:open {
  border-color: var(--color-accent);
}

/* selectのピッカーが開いているとき */
select:open {
  box-shadow: 0 10px 30px rgb(0 0 0 / 0.2);
}
```

`<select>`や`<input>`のピッカーは要素に重なって開くので、要素に付けた枠線は見えにくくなります。下の例では、親に`:has(:open)`で背景色を付けて、開いていることが分かるようにしています。

```css demo="open"
:open {
  outline: 2px solid tomato;
  outline-offset: 4px;
}

/* ピッカーが開いているあいだ、親の背景に色を付ける */
section:has(:open) {
  background-color: light-dark(lavender, darkslateblue);
}

section {
  padding: 1rem;
}
```

```html demo="open"
<section>
  <details>
    <summary>details</summary>
    <p>開いているあいだ、details:openが当たります。</p>
  </details>
</section>
<section>
  <button type="button" id="show">dialogを開く</button>
  <dialog>
    <p>このdialogにも:openが当たっています。</p>
    <form method="dialog"><button>閉じる</button></form>
  </dialog>
</section>
<section>
  <label>
    select
    <select>
      <option>選択肢1</option>
      <option>選択肢2</option>
      <option>選択肢3</option>
    </select>
  </label>
</section>
<section>
  <label>input <input type="color" value="#3b82f6" /></label>
</section>
```

```js demo="open"
document.querySelector('#show').addEventListener('click', () => {
  document.querySelector('dialog').showModal();
});
```

## おわりに

`<dialog>`と`<details>`は`open`属性のセレクタでも選べますが、`<select>`とピッカーを持つ`<input>`が開いている状態を選べるのは`:open`だけです。要素を絞るときは`select:open`のように組み合わせ、ピッカーが要素に重なるときは親に`:has(:open)`を付けます。
