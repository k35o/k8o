# abs()とsign()でCSSの値の絶対値と符号を求める

<BrowserSupportStatus featureId="abs-sign"></BrowserSupportStatus>

## はじめに

`abs()`と`sign()`は、`calc()`と同じように値を計算するCSSの数学関数です。`abs()`は値の絶対値を返し、`sign()`は値が正なら`1`、負なら`-1`、0なら`0`を返します。Chrome 138が対応して、Baseline 2025に入りました。

絶対値は、これまでも`max(var(--x), -1 * var(--x))`のように書けば求められ、`abs()`はそれを短く書けるだけです。正か負かで色や向きを切り替えるときは、`sign()`が返す`-1`か`0`か`1`を掛ければ、1つの式で書けます。

## abs()

`abs()`は、負の値を正の値にし、正の値はそのまま返します。

```css
/* [!og] */
.element {
  width: abs(-100px); /* 100px */
  height: abs(50px); /* 50px */
  margin: abs(calc(-20px + 10px)); /* 10px */
  --offset: -30px;
  padding: abs(var(--offset)); /* 30px */
}
```

`%`を含む式も渡せます。幅200pxの親の中で`width: abs(50% - 300px)`とすると、`%`が100pxに解決されてから絶対値が取られ、幅は200pxになります。

中心からの距離を使うと、並んだ要素を真ん中から外側へ順に出すアニメーションを書けます。

```html
<ul class="dots">
  <li style="--i: 0"></li>
  <li style="--i: 1"></li>
  <li style="--i: 2"></li>
  <li style="--i: 3"></li>
  <li style="--i: 4"></li>
  <li style="--i: 5"></li>
  <li style="--i: 6"></li>
</ul>
```

```css
@keyframes pop {
  from {
    scale: 0;
  }
}

.dots li {
  animation: pop 0.4s both;
  /* 真ん中の--i: 3から離れるほど遅れて出る */
  animation-delay: calc(abs(var(--i) - 3) * 50ms);
}
```

`animation-delay`は、端の0.15sから0.05sずつ短くなって真ん中で0sになり、反対の端に向かってまた0.05sずつ長くなります。

## sign()

`sign()`は、値の符号に応じて次の数を返します。

- 正の値：`1`
- 負の値：`-1`
- ゼロ：`0`（`-0px`のような負のゼロには`-0`）

```css
.element {
  --positive: sign(50px); /* 1 */
  --negative: sign(-30px); /* -1 */
  --zero: sign(0px); /* 0 */
}
```

`sign()`が返すのは単位の無い数なので、色相や角度に掛けて使います。前日比のような増減を`--delta`に入れると、増えたら緑の上向き、減ったら赤の下向き、変わらなければ黄色の右向きの矢印になります。

```html
<span class="change" style="--delta: -2.5">-2.5%</span>
```

```css
.change {
  /* sign()が-1、0、1のとき、色相は0、60、120 */
  color: hsl(calc(sign(var(--delta)) * 60 + 60) 70% 40%);
}

.change::before {
  content: '▲';
  display: inline-block;
  /* sign()が-1、0、1のとき、180deg、90deg、0deg */
  rotate: calc((1 - sign(var(--delta))) * 90deg);
}
```

## おわりに

中心からの距離で遅れや大きさを決めるときは`abs()`を、値の正負で色や向きを切り替えるときは`sign()`を使うと、JavaScriptでクラスを付け替えずにCSSだけで書けます。
