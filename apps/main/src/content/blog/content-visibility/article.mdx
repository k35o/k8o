# content-visibilityで長いページの描画を速くする

<BrowserSupportStatus featureId="content-visibility" />

## はじめに
`content-visibility`は、要素の中身のレイアウトと描画を行うかどうかを決めるCSSプロパティです。`auto`を指定すると、画面の外にある要素の中身の処理を、画面に近づくまで省けます。Safari 26が`auto`に対応し、Baseline 2025になりました。

画像やiframeの読み込みを遅らせるだけなら、`loading="lazy"`で足ります。DOMにはすでにある長いページの、画面外の部分のレイアウトと描画を省けるのは`content-visibility: auto`だけです。記事の一覧やドキュメントのように節の多いページでは、節ごとに次のように書きます。

```css
section {
  content-visibility: auto;
  contain-intrinsic-size: auto 500px;
}
```

画面外の節は中身が描かれず、中身の高さを500pxとして扱います。3000節のページで試すと、節を入れてからレイアウトが終わるまでの時間は、この指定が無いとChrome 156で約120ms、あると約8msでした。Safari 27.2では約100msと約20ms、Firefox 159では約80msと約5msでした。

## visibleとhidden
`content-visibility`プロパティは、要素の内容が表示されるかどうかを制御します。

`visible`は付与していない時と同じように要素が表示されます。付与しても効果が全くありません。

`hidden`はその要素の中身のレンダリング処理が行われません。スクリーンリーダーやブラウザ検索からのアクセスも不可になります。
要素自体の箱は残り、高さは中身が無いものとして決まります。`padding: 10px`と2pxの枠を持つdivに高さ300pxの中身を入れて`hidden`にすると、divの高さはChrome 156、Safari 27.2、Firefox 159のどれでも24px（余白と枠だけ）になりました。
`display: none`と似ていますが、`content-visibility: hidden`は中身のレンダリングの状態を残しておくので、要素を再び表示するときの処理が`display: none`より軽くなるという違いがあります。

## auto
`auto`はビューポート内やトップレイヤーに表示されたり、フォーカスや要素の選択がない限り、要素の中身のレンダリング処理が行われません。
逆に、要素がビューポート内に入ったり、トップレイヤーに表示されたり、フォーカスや要素の選択が行われた場合にレンダリング処理が行われます。

そして非表示の間も`hidden`とは異なり、アクセシビリティツリーに表示されるのでスクリーンリーダーからの検出は行われます。ページ内の検索でも見つかります。画面外の`auto`の中身の文字列は`window.find()`で見つかり、`hidden`の中身は見つかりませんでした（Chrome 156、Safari 27.2、Firefox 159）。

上記のデモでは、`hidden`と`auto`の違いを実際に確認できます。
ブラウザの検索機能や開発者ツールでアクセシビリティツリーを確認してみると、`auto`の方だけ検索できることがわかります。

要素が読み飛ばされている間は中身の高さが0として扱われるので、読み込まれたタイミングでスクロールバーの位置がズレる可能性があります。
これらの問題は要素のスタイルに適切な`contain-intrinsic-size`を付与して、あらかじめブラウザにレイアウトのサイズが伝わるようにして防ぎます。

`padding: 10px`と2pxの枠を持ち、高さ300pxの中身を入れたdivを画面外に置くと、`contain-intrinsic-size`が無ければ高さは24px（余白と枠だけ）、`contain-intrinsic-size: auto 500px`なら524pxでした。値の前の`auto`は、一度描いたときの高さを覚えさせる指定です。画面に入れてから外に戻すと、高さは実際の324pxのままでした（3つのブラウザで同じ）。

## おわりに
`content-visibility: auto`は、Safari 26の対応で主要なブラウザすべてで使えるようになりました。
サポートされていないブラウザであっても、このプロパティは付与されていないものと振る舞うだけです。節の多い長いページでは、`contain-intrinsic-size`と一緒に指定してみてください。
