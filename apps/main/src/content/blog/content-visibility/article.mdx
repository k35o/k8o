# content-visibilityで長いページの描画を速くする

<BrowserSupportStatus featureId="content-visibility" />

## はじめに
`content-visibility`は、要素の中身のレイアウトと描画を行うかどうかを決めるCSSプロパティです。`auto`を指定すると、画面の外にある要素の中身の処理を、画面に近づくまで省けます。Safari 26が`auto`に対応して、Baseline 2025に入りました。

画像やiframeの読み込みを遅らせるだけなら、`loading="lazy"`で足ります。しかし、DOMにすでにある長いページの、画面外の部分のレイアウトと描画を省けるのは`content-visibility: auto`だけです。記事の一覧やドキュメントのように節の多いページでは、節ごとに次のように書きます。

```css
section {
  content-visibility: auto;
  contain-intrinsic-size: auto 500px;
}
```

画面外の節は中身が描かれず、中身の高さを500pxとして扱います。

## visibleとhidden
`visible`は初期値で、指定しないときと同じように中身が描かれます。

`hidden`を指定すると、要素の中身は描かれず、スクリーンリーダーにもページ内検索にも見つかりません。省かれるのは中身だけで、要素自身のボーダーと背景は描かれ、高さは中身が無いものとして決まります。`padding: 10px`と2pxのボーダーを持つdivに高さ300pxの中身を入れて`hidden`にすると、divの高さは余白とボーダーだけの24pxになります。

`display: none`と似ていますが、`hidden`は中身の描画の状態を残しておくので、もう一度表示するときの処理が`display: none`より軽く済みます。

## auto
`auto`の要素の中身は、要素が画面に近づくか、トップレイヤーに表示されるか、中身にフォーカスや選択が入るまで描かれません。

描かれていない間も、`hidden`と違って中身はアクセシビリティツリーに残るので、スクリーンリーダーは読めます。ページ内検索でも見つかり、画面外の`auto`の中身の文字列は`window.find()`で見つかりますが、`hidden`の中身は見つかりません。

`hidden`のカードは中身が描かれず、空のままです。`auto`のカードは画面の中にあるので、中身が描かれます。

ページ内検索でサンプルコンテンツを探すと、見つかるのは`auto`のカードだけです。カードの上のボタンを押すと、それぞれ`visible`に切り替わります。

### contain-intrinsic-size
`auto`で中身が描かれていない間は、要素の高さは中身が無いものとして決まります。そのため、画面に近づいて中身が描かれたときに高さが変わり、スクロールバーの位置がずれます。これは、`contain-intrinsic-size`で描かれていない間の大きさを決めて防ぎます。

`padding: 10px`と2pxのボーダーを持ち、高さ300pxの中身を入れたdivを画面外に置くと、`contain-intrinsic-size`が無ければ高さは余白とボーダーだけの24pxに、`contain-intrinsic-size: auto 500px`なら524pxになります。値の前の`auto`は、一度描いたときの大きさを覚えさせる指定です。画面に入れてから外に戻すと、高さは実際の324pxのままです。

## おわりに
`content-visibility: auto`を使うと、DOMにある長いページでも、画面の外の節のレイアウトと描画を省けます。中身が描かれたときに高さがずれないよう、`contain-intrinsic-size`と一緒に節ごとに指定します。
