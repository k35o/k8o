# getComposedRangesでShadow DOM内の選択を取得

<BrowserSupportStatus featureId="composed-ranges" />

## はじめに

`getComposedRanges`メソッドは、ユーザーが選択した範囲を、Shadow DOMの中のノードの位置まで含めて返す`Selection`オブジェクトのメソッドです。中を見てよい`ShadowRoot`を渡すと、その中のテキストノードと文字の位置が`StaticRange`で返ります。Firefox 142が対応して、Baseline 2025に入りました。

選択範囲がふつうのDOMの中にあるときは、`getRangeAt(0)`で範囲が取れます。Shadow DOMの中を選んだときや、外から中へまたいで選んだときは、`getRangeAt(0)`が返す範囲がブラウザによって違い、Shadow DOMの中の位置が分からないことがあります。たとえばChromeでマウスを使って外から中へ選ぶと、`getRangeAt(0)`の終わりはホスト要素の位置になり、`toString()`の結果にもShadow DOMの中の文字が入りません。`getComposedRanges`メソッドなら、どのブラウザでも中の位置まで取れます。

```html
<p id="host"></p>
<script>
  const host = document.getElementById('host');
  const shadowRoot = host.attachShadow({ mode: 'open' });
  shadowRoot.textContent = 'Shadow DOMの中の文字';

  document.addEventListener('selectionchange', () => {
    const selection = document.getSelection();
    const [range] = selection.getComposedRanges({ shadowRoots: [shadowRoot] });
    console.log(range?.startContainer, range?.startOffset, range?.endOffset);
  });
</script>
```

Shadow DOMの中の文字を選ぶと、コンソールにShadow DOMの中のテキストノードと、選んだ文字の始まりと終わりの位置が出ます。

## Selection

`Selection`は、ユーザーが選択したテキストの範囲やキャレットの位置を表すオブジェクトです。`window.getSelection()`で取り出し、`toString()`で選んだ文字列を、`getRangeAt(0)`で選択範囲を`Range`として取り出せます。選択範囲が変わるたびに、`document`に`selectionchange`イベントが届きます。

```ts
document.addEventListener('selectionchange', () => {
  const selection = window.getSelection();
  if (!selection || selection.rangeCount === 0) return;
  console.log(selection.toString(), selection.getRangeAt(0));
});
```

## getComposedRanges

`getComposedRanges()`は、Shadow DOMの境界をまたいで選んだ範囲を、Shadow DOMの中の位置まで含めて返します。

```ts
const ranges = window.getSelection()?.getComposedRanges({ shadowRoots: [shadowRoot1, shadowRoot2] });
```

戻り値は`StaticRange`の配列です。`Range`はDOMが変わると位置が追従しますが、`StaticRange`は作った時点の位置のままです。

オプションの`shadowRoots`には、中の位置を見てよい`ShadowRoot`の配列を渡します。渡した`ShadowRoot`の中にある端は、Shadow DOMの中の位置で返ります。渡していない`ShadowRoot`の中にある端はShadow DOMの外に出され、ホスト要素の親と、その中でのホスト要素の位置で返ります。


```js demo="compare"
const sample = document.querySelector('#sample');
const heading = document.querySelector('#heading');
const host = document.querySelector('#host');

// 本文のテキストノードを、閉じたShadow DOMの中へ移す
const body = host.firstChild;
const shadowRoot = host.attachShadow({ mode: 'closed' });
shadowRoot.append(body);

const headingLength = heading.textContent.length;
const text = heading.textContent + body.data;

// 範囲の端を、見出しと本文をつないだ文字列の中の位置に直す
const toIndex = (node, offset) => {
  if (node === heading.firstChild) return offset;
  if (node === body) return headingLength + offset;
  if (node === heading) return offset * headingLength;
  if (node === shadowRoot) return headingLength + offset * body.length;
  if (node === host) return headingLength;
  // 残りは #sample か、その子の空白のテキストノード。手前にある子から数える
  const children = [...sample.childNodes];
  const before = children.slice(0, node === sample ? offset : children.indexOf(node));
  return (
    (before.includes(heading) ? headingLength : 0) +
    (before.includes(host) ? body.length : 0)
  );
};

const covered = (range) =>
  text.slice(
    toIndex(range.startContainer, range.startOffset),
    toIndex(range.endContainer, range.endOffset),
  );

const describe = (range) => {
  if (!range) return 'rangeCountが0で、取り出せません';
  return covered(range) || '（空の範囲）';
};

document.addEventListener('selectionchange', () => {
  const selection = document.getSelection();
  const [composed] = selection.getComposedRanges({ shadowRoots: [shadowRoot] });
  // 見出しと本文を選んでいないときは、前の結果を残す
  if (!composed || covered(composed) === '') return;

  document.querySelector('#range-at').textContent = describe(
    selection.rangeCount > 0 ? selection.getRangeAt(0) : undefined,
  );
  document.querySelector('#with-roots').textContent = describe(composed);
  document.querySelector('#without-roots').textContent = describe(
    selection.getComposedRanges()[0],
  );
});
```

結果の欄の本文は、閉じたShadow DOM（`mode: 'closed'`）の中にあります。本文の一部を選ぶと、3つの方法で取り出した範囲が、どの文字を指しているかが出ます。`getRangeAt(0)`は、Firefoxでは選んだ文字を指しますが、ChromeとSafariでは空の範囲になり、どこを選んだのか分かりません。`ShadowRoot`を渡した`getComposedRanges()`は、選んだ文字をそのまま指します。渡さないと、範囲の端がShadow DOMの外に出され、本文の段落まるごとを指します。

見出しから本文までまたいで選ぶと、`getRangeAt(0)`の結果はブラウザでばらばらです。Chromeでは見出しの文字だけを、Firefoxでは本文の文字だけを指し、Safariでは`rangeCount`が0になって取り出せません。`ShadowRoot`を渡した`getComposedRanges()`なら、見出しの文字から本文の選んだ文字までを指します。

`getComposedRanges(shadowRoot)`のように、`ShadowRoot`をオブジェクトに入れずに渡す古い書き方もあります。SafariとFirefoxでは中の位置が返りますが、Chromeでは無視され、渡さないときと同じ結果になります。TypeScriptでも型エラーになるので、`{ shadowRoots: [...] }`の形で渡します。

## おわりに

`getComposedRanges()`を使うと、Shadow DOMの中や境界をまたいで選んだ範囲を、中のテキストノードと文字の位置で受け取れます。`ShadowRoot`は`{ shadowRoots: [...] }`の形で渡し、渡した`ShadowRoot`の中の端だけが中の位置で返ります。
