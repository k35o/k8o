# contrast-color()で背景色に合わせて文字色を白か黒にする

<BrowserSupportStatus featureId="contrast-color"></BrowserSupportStatus>

## はじめに

`contrast-color()`は、渡した色を背景にしたときにコントラストが高くなる方の白か黒を返すCSS関数です。`color: contrast-color(var(--bg))`のように書くと、背景色に合わせて文字色が白か黒に切り替わります。Chrome 147が対応して、Baseline 2026に入りました。

背景色が決まっているときは、背景色と文字色をペアで決めておきます。テーマカラーやユーザーが選んだ色のように背景色が後から変わる場面では、これまで背景色ごとに読みやすい文字色をデザイントークンやCSSカスタムプロパティで持ち回るか、JavaScriptで輝度を計算する必要がありました。`contrast-color()`なら、背景色を渡すだけで文字色をCSSの中で決められます。

## 書き方

引数には、背景に使う色を1つ渡します。`white`と`black`のうち背景色とのコントラストが高い方を返し、等しいときは`white`を返します。

```css
.button {
  background-color: lightblue;
  color: contrast-color(lightblue);
}
```

背景色をカスタムプロパティに入れておくと、背景色を変えるだけで文字色も追従します。

```css
/* [!og] */
.button {
  --button-bg: #2563eb;
  background-color: var(--button-bg);
  color: contrast-color(var(--button-bg));
}
```

カラーピッカーかHEXの欄で背景色を変えると、文字色が白と黒で切り替わります。`#2563eb`では白、少し明るい`#2277d3`では黒になります。

背景色に透明度があっても、`contrast-color()`は下に透けて見える色を見ずに判定します。`rgb(0 0 0 / 0.2)`には白、`rgb(255 255 255 / 0.2)`には黒を返します。白いページに重ねた`rgb(0 0 0 / 0.2)`は薄い灰色に見えるので、白い文字では読めません。半透明の背景色には、下に重なる色と`color-mix()`で混ぜた色を渡します。

```css
.badge {
  background-color: rgb(0 0 0 / 0.2);
  /* 白いページに重ねたときの色を渡す */
  color: contrast-color(color-mix(in srgb, black 20%, white));
}
```

## 中間の明るさの背景色で得られるコントラスト比

返すのは白か黒だけなので、中間の明るさの背景色では、どちらを返しても高いコントラスト比は得られません。

仕様は、白と黒のどちらを返すかの判定方法をブラウザに任せていて、WCAG 2.1の式をそのまま使わないよう勧めています。ただ、灰色の背景を`rgb(0 0 0)`から`rgb(255 255 255)`まで1ずつ変えると、どのブラウザも`rgb(117 117 117)`までは白、`rgb(118 118 118)`からは黒を返します。WCAG 2.1の式で黒と白のコントラスト比が入れ替わる位置と同じなので、今のところ次の計算がそのまま当てはまります。

[色のコントラスト比](/blog/color-contrast)の記事で紹介したWCAG 2.1の式で、背景色の相対輝度を $L$ ($0 \leqq L \leqq 1$) とすると、黒とのコントラスト比 $C_b$ と白とのコントラスト比 $C_w$ は次のようになります。

```math
C_b = \frac{L + 0.05}{0.05}, \quad C_w = \frac{1.05}{L + 0.05}
```

2つを掛けると $L + 0.05$ が打ち消し合い、$L$ によらない定数になります。

```math
C_b \cdot C_w = \frac{1.05}{0.05} = 21
```

積が21で一定なので、2つがともに $\sqrt{21}$ を下回ることはなく、大きい方は常に $\sqrt{21}$ 以上になります。

```math
\max(C_b, C_w) \geqq \sqrt{C_b \cdot C_w} = \sqrt{21} \approx 4.58
```

大きい方がちょうど $\sqrt{21}$ になるのは、$C_b = C_w$ となる $L \approx 0.179$ のときです。`contrast-color()`が返す色のコントラスト比は4.58:1を下回りませんが、この明るさの背景色ではそれより高くなりません。

たとえば`#2277d3`は、黒で4.65:1、白で4.52:1で、WCAGのAA（4.5:1）をかろうじて満たします。AAAの7:1に届くのは、相対輝度が0.1以下か0.3以上の背景色だけで、その間の背景色では黒と白のどちらを返しても7:1に届きません。読みやすさに余裕を持たせるには、`contrast-color()`に渡す背景色を、明るい側か暗い側に寄せておきます。

## おわりに

`contrast-color()`を使うと、テーマカラーやユーザーが選んだ色の背景でも、背景色に合わせた白か黒の文字色をCSSだけで決められます。ただし、中間の明るさの背景色では白と黒のどちらでも高いコントラスト比にならないので、背景色を明るい側か暗い側に寄せておきます。
