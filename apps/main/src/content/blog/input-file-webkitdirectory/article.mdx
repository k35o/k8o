# webkitdirectoryでinputからフォルダを選択する

<BrowserSupportStatus featureId="input-file-webkitdirectory" />

## はじめに
`webkitdirectory`は、`<input type="file">`でファイルの代わりにフォルダ（ディレクトリ）を選ばせる属性です。選んだフォルダの中のファイルがサブフォルダの中まで`files`に入り、各ファイルの`webkitRelativePath`には、選んだフォルダの名前から始まるパスが入ります。Firefox Androidが対応して、Baseline 2025に入りました。

ファイルを1つ、または`multiple`で複数選ばせるのは、`type="file"`でできます。`<input>`でフォルダを丸ごと選ばせて、どのファイルがどのサブフォルダにあったかまで受け取るのは、`webkitdirectory`でしかできません。

```html
<!-- [!og] -->
<!-- ディレクトリ選択 -->
<input type="file" webkitdirectory />
```

<WebkitDirectoryInputExample />

ボタンを押すと、ファイルではなくフォルダを選ぶダイアログが開きます。フォルダを選ぶと、中のファイルがまとめて`files`に入ります。

## webkitdirectory属性
`webkitdirectory`は真偽値の属性で、付けるとディレクトリの選択になり、付けなければファイルの選択になります。
値は見ないので、`webkitdirectory="false"`と書いてもディレクトリの選択になります。JavaScriptから切り替えるときは、プロパティに`true`か`false`を入れると属性が付け外しされます。

### ファイルの取得
`webkitdirectory`属性を付けた`<input>`要素で選んだファイルも、`multiple`属性を付けたときと同じく`files`プロパティから取り出します。

`files`プロパティは`FileList`オブジェクトまたは`null`を返します。

`FileList`オブジェクトは`File`オブジェクトの集合体で、`File`は添え字からのアクセスと`item()`メソッドでアクセスできます。また、`FileList`はイテレーターとしての機能も持っています。

```ts
const files = inputElement.files;

// 選択されたファイル数
console.log(files?.length);
// 添え字でのアクセス
console.log(files?.[0]);
// item()メソッドでのアクセス なければnullを返す
console.log(files?.item(0));
// イテレーターでのアクセス
for (const file of files ?? []) {
  console.log(file);
}
```

`webkitdirectory`属性を付与した`<input>`要素から入力された`File`は書き換え不可な`webkitRelativePath`プロパティを持ちます。
このプロパティには、選択されたファイルの相対パスが格納されます。

```ts
const files = inputElement.files;

for (const file of files ?? []) {
  console.log(file.webkitRelativePath);
}
```

Chromeで、`a.txt`と`.hidden`のほかにサブフォルダと空のフォルダを置いた`photos`フォルダを選ぶと、上のコードは次の4行を出しました。

```txt
photos/.hidden
photos/a.txt
photos/sub/b.txt
photos/sub/deeper/c.txt
```

パスは選んだフォルダの名前から始まり、`.`で始まるファイルも入りますが、空のフォルダ（`photos/empty`）は入りません。`multiple`属性を付けなくても、サブフォルダの中のファイルまで入ります。そのままフォームで送ると、multipartの`filename`にも`photos/sub/b.txt`のようなパスが入ります。

テストで`DataTransfer`を使って`files`に`File`を入れても、`webkitRelativePath`は空文字のままです。`webkitRelativePath`を使う処理をテストするときは、Playwrightの`setInputFiles()`にフォルダのパスを渡して、ブラウザにフォルダを選ばせます。

## おわりに
`input`要素でファイルを扱う際に、`webkitdirectory`属性を利用することでディレクトリごと選択可能になり、中のファイルを`webkitRelativePath`のパスと一緒に受け取れるようになりました。

`webkitdirectory`属性のような`webkit`prefixがついている機能は利用を躊躇いますが、Baseline 2025に追加されたことで安心して利用できるようになったのではないでしょうか。
