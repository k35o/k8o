# Invoker Commands APIでモーダルをJSなしで開く

<BrowserSupportStatus featureId="invoker-commands"></BrowserSupportStatus>

## はじめに

Invoker Commands APIは、`<button>`に`commandfor`属性と`command`属性を書くだけで、ほかの要素を操作できるAPIです。`<dialog>`をモーダルで開く・閉じる、ポップオーバーを開閉するといった操作を、JavaScriptなしで実行できます。Safari 26.2が対応して、Baseline 2025に入りました。

ポップオーバーの開閉だけなら、これまでの`popovertarget`属性で足ります。一方で、Dialogをモーダルで開くには、JavaScriptで`<dialog>`要素の`showModal()`メソッドを呼び出す必要がありました。

```js
openButton.addEventListener('click', () => {
  dialog.showModal();
});
```

Invoker Commands APIを使えば、これをHTMLの属性だけで書けます。

```html
<button commandfor="my-dialog" command="show-modal">開く</button>

<dialog id="my-dialog">Dialogの内容</dialog>
```

開くを押すと、`showModal()`を呼んだときと同じく、Dialogがモーダルで開きます。Popover APIの`popovertarget`属性と`popovertargetaction`属性と同じ考え方を、Dialogなどにも広げたものです。

## 基本的な使い方

Invoker Commands APIは`commandfor`と`command`の2つの属性で構成されます。`commandfor`は操作対象の要素の`id`を指定、`command`は実行するアクションを指定します。

`command`は現在カスタム値を除いて、Dialogの`show-modal`・`close`・`request-close`、Popoverの`show-popover`・`hide-popover`・`toggle-popover`が使えます。

ボタンをクリックすると、`commandfor`で指定した要素に対してJavaScriptの`showModal()`・`close()`・`requestClose()`、`showPopover()`・`hidePopover()`・`togglePopover()`メソッド相当の動作が実行されます。

### Dialogの操作

```html
<button commandfor="dialog" command="show-modal">Dialogを開く</button>

<dialog id="dialog">
  <p>Dialogの内容</p>
  <button commandfor="dialog" command="close">閉じる</button>
</dialog>
```

<PlaygroundEmbed demo="Dialogの操作" headingLevel="h5" sectionId="invoker-commands" />

組み込みのコマンドでも、操作の前に`commandfor`で指定した要素へ`command`イベントが届きます。`event.command`は`show-modal`、`event.source`は押したボタンで、`preventDefault()`を呼ぶとDialogは開きません。`close`のボタンに`value`属性を書くと、その値が閉じたあとの`returnValue`になります。

`<form>`の中に置くボタンには`type="button"`を書きます。`type`を書かずに`commandfor`と`command`を付けたボタンは、押してもフォームを送信せず、コマンドも実行しません。`type="submit"`ではフォームを送信するだけで、コマンドは実行されません。`<form method="dialog">`の中のキャンセルボタンも同じです。

```html
<dialog id="edit-dialog">
  <form method="dialog">
    <input name="name" />
    <button type="button" commandfor="edit-dialog" command="close">キャンセル</button>
    <button>保存</button>
  </form>
</dialog>
```

### Popoverの操作

```html
<button commandfor="popover" command="toggle-popover">メニュー</button>

<div id="popover" popover>
  ポップオーバーの内容
</div>
```

ポップオーバーの場合、従来の`popovertarget`と`popovertargetaction`属性でも同じことができます。

```html
<button popovertarget="popover" popovertargetaction="toggle">メニュー</button>

<div id="popover" popover>
  ポップオーバーの内容
</div>
```

## カスタムコマンド

`show-modal`や`toggle-popover`のような組み込みコマンドだけでなく、独自のコマンドを定義することもできます(これにはJavaScriptが必要です)。
カスタムコマンドは`--`で始まる名前で定義します。

```html
<button commandfor="my-image" command="--zoom-in">拡大</button>
<button commandfor="my-image" command="--zoom-out">縮小</button>
<button commandfor="my-image" command="--reset">リセット</button>
<img id="my-image" src="photo.jpg" alt="写真" />
```

カスタムコマンドは`command`イベントで処理します。

```javascript
// [!og]
const image = document.getElementById('my-image');
let scale = 1;

image.addEventListener('command', (event) => {
  if (event.command === '--zoom-in') {
    scale = Math.min(scale + 0.25, 2);
  } else if (event.command === '--zoom-out') {
    scale = Math.max(scale - 0.25, 0.5);
  } else if (event.command === '--reset') {
    scale = 1;
  }
  image.style.scale = `${scale}`;
});
```

`command`に応じた自由な動作を実装できます。`--`で始まらない名前は、組み込みのコマンドでなければ無視され、`command`イベントも発火しません。`command="zoom-in"`のボタンを押すと`command`イベントは届かず、ボタンの`command`プロパティは空文字列を返します。

## おわりに

Invoker Commands APIを紹介しました。

`commandfor`と`command`属性を使うことで、JavaScriptを書かずにDialogやPopoverを宣言的に操作できます。Popover APIの`popovertarget`属性と同じ考え方が、Dialogにも適用できるようになったのは嬉しいですね。`<form>`の中のボタンには`type="button"`を書いてください。

また、`--`で始まるカスタムコマンドと`command`イベントを組み合わせれば、組み込みコマンドでカバーできない独自の操作も実装できます。

Baseline 2025で全ブラウザ対応となったので、ぜひ活用してみてください。
