# Invoker Commands APIでモーダルをJSなしで開く

<BrowserSupportStatus featureId="invoker-commands"></BrowserSupportStatus>

## はじめに

Invoker Commands APIは、`<button>`に`commandfor`属性と`command`属性を書くだけで、ほかの要素を操作できるAPIです。Dialogをモーダルで開いたり閉じたり、Popoverを開閉したりする操作を、JavaScriptなしで書けます。Safari 26.2が対応して、Baseline 2025に入りました。

Popoverの開閉だけなら、これまでの`popovertarget`属性で足ります。一方で、Dialogをモーダルで開くには、JavaScriptで`<dialog>`要素の`showModal()`メソッドを呼び出す必要がありました。

```js
openButton.addEventListener('click', () => {
  dialog.showModal();
});
```

Invoker Commands APIを使えば、これをHTMLの属性だけで書けます。

```html
<button commandfor="my-dialog" command="show-modal">開く</button>

<dialog id="my-dialog">Dialogの内容</dialog>
```

開くを押すと、`showModal()`を呼んだときと同じく、Dialogがモーダルで開きます。Popover APIの`popovertarget`属性と`popovertargetaction`属性の考え方を、Dialogなどにも広げたものです。

## 基本的な使い方

`commandfor`には操作する要素の`id`を、`command`には実行するコマンドを書きます。組み込みのコマンドは次の6つで、押すとそれぞれのメソッドを呼んだのと同じ動作をします。

- `show-modal`：Dialogの`showModal()`
- `close`：Dialogの`close()`
- `request-close`：Dialogの`requestClose()`
- `show-popover`：Popoverの`showPopover()`
- `hide-popover`：Popoverの`hidePopover()`
- `toggle-popover`：Popoverの`togglePopover()`

### Dialogの操作

```html
<button commandfor="dialog" command="show-modal">Dialogを開く</button>

<dialog id="dialog">
  <p>Dialogの内容</p>
  <button commandfor="dialog" command="close">閉じる</button>
</dialog>
```

<PlaygroundEmbed demo="Dialogの操作" headingLevel="h5" sectionId="invoker-commands" />

組み込みのコマンドでも、操作の前に`commandfor`で指定した要素へ`command`イベントが届きます。`event.command`は`show-modal`のようなコマンドの名前、`event.source`は押したボタンで、`preventDefault()`を呼ぶとDialogは開きません。`close`のボタンに`value`属性を書くと、その値が閉じたあとの`returnValue`になります。

`<form>`の中に置くボタンには`type="button"`を書きます。`type`を書かずに`commandfor`と`command`を付けたボタンは、押してもフォームを送信せず、コマンドも実行しません。`type="submit"`ではフォームを送信するだけで、コマンドは実行されません。`<form method="dialog">`の中のキャンセルボタンも同じです。

```html
<dialog id="edit-dialog">
  <form method="dialog">
    <input name="name" />
    <button type="button" commandfor="edit-dialog" command="close">キャンセル</button>
    <button>保存</button>
  </form>
</dialog>
```

### Popoverの操作

```html
<button commandfor="popover" command="toggle-popover">メニュー</button>

<div id="popover" popover>
  ポップオーバーの内容
</div>
```

Popoverなら、これまでの`popovertarget`属性と`popovertargetaction`属性でも同じことができます。

```html
<button popovertarget="popover" popovertargetaction="toggle">メニュー</button>

<div id="popover" popover>
  ポップオーバーの内容
</div>
```

## カスタムコマンド

組み込みのコマンドのほかに、`--`で始まる名前で独自のコマンドを作れます。動作はJavaScriptで書きます。

```html
<button commandfor="my-image" command="--zoom-in">拡大</button>
<button commandfor="my-image" command="--zoom-out">縮小</button>
<button commandfor="my-image" command="--reset">リセット</button>
<img id="my-image" src="photo.jpg" alt="写真" />
```

ボタンを押すと`commandfor`の要素に`command`イベントが届くので、`event.command`で分けて処理します。

```javascript
// [!og]
const image = document.getElementById('my-image');
let scale = 1;

image.addEventListener('command', (event) => {
  if (event.command === '--zoom-in') {
    scale = Math.min(scale + 0.25, 2);
  } else if (event.command === '--zoom-out') {
    scale = Math.max(scale - 0.25, 0.5);
  } else if (event.command === '--reset') {
    scale = 1;
  }
  image.style.scale = `${scale}`;
});
```

`--`で始まらない名前は、組み込みのコマンドでなければ無視されます。`command="zoom-in"`のボタンを押しても`command`イベントは届かず、ボタンの`command`プロパティは空文字列を返します。

## おわりに

`commandfor`と`command`を使うと、JavaScriptを書かずにDialogをモーダルで開いたり、Popoverを開閉したりできます。`--`で始まるカスタムコマンドと`command`イベントを組み合わせれば、組み込みのコマンドに無い操作も、同じボタンの書き方で呼べます。
