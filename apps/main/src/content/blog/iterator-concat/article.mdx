# Iterator.concatでイテレータを配列にせずに結合する

<BrowserSupportStatus featureId="iterator-concat" />

## はじめに

`Iterator.concat()`は、複数のIterableを受け取り、それらの値を順に返す1つのイテレータを作る静的メソッドです。値は配列にまとめず、取り出すときに1つずつ読みます。Safari 26.4が対応して、Baseline 2026に入りました。

値の数が少なく全部を使うときは、スプレッド構文で配列にして結合します。大きな配列や終わりの無いジェネレータをつなぎ、先頭やつなぎ目のあたりだけを使うときに、`Iterator.concat()`が要ります。[Iterator Helpers](/blog/iterator-methods)の`take`や`drop`と組み合わせると、つないだ値を配列にせずに切り出せます。

```js
const first = Array.from({ length: 1_000_000 }, (_, i) => i);
const second = ['a', 'b', 'c'];
console.log(Iterator.concat(first, second).drop(999_998).take(4).toArray());
// [999998, 999999, 'a', 'b']
```

100万要素の配列をコピーせずに、つなぎ目の前後の4つだけを取り出しています。

## これまでの方法

これまでは、スプレッド構文で配列にしてからつなぐか、ジェネレータ関数で`yield*`を使っていました。

```js
// スプレッド構文で配列に変換する方法
const combined = [...[1, 2, 3], ...[4, 5, 6]];
// [1, 2, 3, 4, 5, 6]
```

スプレッド構文は短く書けますが、すべての値をその場で配列に展開します。

```js
// ジェネレータ関数を使う方法
function* concat(...iterables) {
  for (const iterable of iterables) {
    yield* iterable;
  }
}

const combined = concat([1, 2, 3], [4, 5, 6]);
```

ジェネレータ関数なら値を1つずつ読めますが、つなぐためだけに関数を定義することになります。`Iterator.concat()`なら、関数を定義せずにIterableをつなげます。

## Iterator.concat()

`Iterator.concat()`が返すイテレータは、`next()`を呼ぶたびに、渡したIterableの値を前から順に返します。

```js
const iter = Iterator.concat([1, 2, 3], [4, 5, 6]);
console.log(iter.next()); // { value: 1, done: false }
console.log(iter.next()); // { value: 2, done: false }
console.log(iter.next()); // { value: 3, done: false }
console.log(iter.next()); // { value: 4, done: false }
console.log(iter.next()); // { value: 5, done: false }
console.log(iter.next()); // { value: 6, done: false }
console.log(iter.next()); // { value: undefined, done: true }
```

引数にはいくつでもIterableを渡せます。配列と`Set`や`Map`のように、種類の違うIterableを混ぜても構いません。

```js
// [!og]
const array = [1, 2];
const set = new Set([3, 4]);
const map = new Map([['a', 5], ['b', 6]]);

const iter = Iterator.concat(array, set, map);

for (const value of iter) {
  console.log(value);
}
// 1 2 3 4 ['a', 5] ['b', 6]
```

`Map`はそのまま渡すと`[key, value]`のペアが返ります。

## 遅延評価

`Iterator.concat()`は、`next()`が呼ばれたときに初めて、渡したIterableから値を取り出します。

```js
function* generateNumbers(label, count) {
  for (let i = 0; i < count; i++) {
    console.log(`${label}: ${i}`);
    yield i;
  }
}

const iter = Iterator.concat(
  generateNumbers('A', 2),
  generateNumbers('B', 2),
);

// この時点ではまだ何も評価されていない

console.log(iter.next());
// A: 0
// { value: 0, done: false }

console.log(iter.next());
// A: 1
// { value: 1, done: false }

console.log(iter.next());
// B: 0
// { value: 0, done: false }

console.log(iter.next());
// B: 1
// { value: 1, done: false }
```

1つ目のIterableの値を返し終えてから、2つ目のIterableの値を読み始めます。そのため、先頭に終わりの無いIterableを渡すと、後ろのIterableには届きません。

100万要素の配列を2つつないで先頭の10個を取るなら、スプレッド構文で配列にするより、`Iterator.concat()`と`take()`の方がずっと速く終わります。全部の値を`for...of`で取り出すときは、スプレッド構文の方が速くなります。

## 渡せる値

`Iterator.concat()`に渡せるのは、`[Symbol.iterator]`を持つオブジェクトです。配列や`Set`、`Map`、ジェネレータオブジェクトはそのまま渡せます。

文字列はIterableですが、オブジェクトではないので渡せません。`Iterator.concat('abc')`は`TypeError`になります。文字列をつなぐときは、`Iterator.from('abc')`でイテレータにしてから渡します。

```js
Iterator.concat('abc'); // TypeError
Iterator.concat(Iterator.from('abc'), ['d']).toArray(); // ['a', 'b', 'c', 'd']
```

自分で作ったオブジェクトも、`[Symbol.iterator]`を持っていれば渡せます。`next`メソッドだけを持つオブジェクトはIterableではないので、`TypeError`になります。

```js
// [Symbol.iterator]を持つオブジェクトはIterableなので渡せる
const iterable = {
  [Symbol.iterator]() {
    let count = 0;
    return {
      next() {
        if (count < 3) {
          return { value: count++, done: false };
        }
        return { value: undefined, done: true };
      },
    };
  },
};
Iterator.concat(iterable); // OK

// nextメソッドだけを持つオブジェクトはIterableではない
const rawIterator = {
  count: 0,
  next() {
    if (this.count < 3) {
      return { value: this.count++, done: false };
    }
    return { value: undefined, done: true };
  },
};
Iterator.concat(rawIterator); // TypeError
Iterator.concat(Iterator.from(rawIterator)); // OK
```

`next`メソッドだけを持つオブジェクトは、`Iterator.from()`で包むと渡せます。

`[Symbol.iterator]`があるかは、`Iterator.concat()`を呼んだ時点で、すべての引数について確かめます。`for...of`を`break`で抜けると、そのとき読んでいたイテレータの`return()`が呼ばれます。

## おわりに

`Iterator.concat()`を使うと、ジェネレータ関数を書かず、配列にもせずに、複数のIterableをつなげます。`drop`や`take`と組み合わせれば必要な範囲だけを取り出せますが、全部の値を使うときはスプレッド構文の方が速くなります。
